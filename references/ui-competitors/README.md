## Design Takeaways To Extract

- Child home: one primary action, visible progress, friendly companion, low text.
- Tutor: structured hints and whiteboard beat free-form chat density.
- Review/game: path, streak, badges, next challenge instead of dense evidence logs.
- Parent/report: evidence summarized first; detailed proof behind drill-down.
- Upload: material-type routing, not one giant form.
