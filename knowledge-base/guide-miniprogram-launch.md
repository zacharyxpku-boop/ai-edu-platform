# 微信小程序上架指南
> AI学伴小程序从开发到审核通过的全流程

---

## 一、注册小程序

### Step 1: 注册账号
1. 打开 https://mp.weixin.qq.com/
2. 点击「立即注册」→ 选择「小程序」
3. 用公司邮箱注册（不能用已注册公众号的邮箱）
4. 主体类型选「企业」或「个体工商户」
5. 完成微信认证（¥300/年）

### Step 2: 获取AppID
- 登录小程序后台 → 设置 → 基本设置 → AppID
- 记录AppID和AppSecret

### Step 3: 完善信息
- 小程序名称：原点AI学伴
- 小程序简称：原点学伴
- 头像：元元(灵珠)图标
- 简介：AI不给答案，教你自己想明白 | 苏格拉底式学习伙伴
- 服务类目：**教育 → 在线教育**（重要！选错会被拒）

## 三、审核要点（避免被拒）

### 常见被拒原因及应对

| 被拒原因 | 应对 |
|---------|------|
| 类目不符 | 选「教育→在线教育」，不要选「工具」 |
| 含有AI对话功能未备案 | 需要通过「算法备案」（见下方） |
| 隐私政策不完整 | 必须有完整的隐私政策弹窗 |
| 未成年人保护 | 必须有家长授权+防沉迷+22:00禁用 |
| 内容安全 | 必须接入内容安全API（过滤敏感词） |
| 诱导分享 | 分享功能不能强制（"分享后解锁"不允许） |

### 算法备案（AI类小程序必须）
1. 打开 https://beian.cac.gov.cn/
2. 选择「互联网信息服务算法备案」
3. 填写算法名称、功能描述、应用场景
4. 提交审核（约20个工作日）
5. 获得备案号后在小程序内展示

### 隐私政策必须包含
```
《原点AI学伴隐私政策》

1. 我们收集什么信息：微信昵称、年级、学科偏好、对话记录
2. 为什么收集：提供个性化学习引导服务
3. 如何存储：数据加密存储在中国境内服务器
4. 如何使用：仅用于提供学习服务，不会分享给第三方
5. 用户权利：您可以随时查看、导出或删除个人数据
6. 未成年人保护：使用需家长授权，每日限时45分钟
7. 联系方式：business@yuandianzhixue.com
```

## 四、提交审核前Checklist

- [ ] 隐私政策弹窗已实现（首次打开时弹出）
- [ ] 用户协议已编写并可查看
- [ ] 防沉迷已实现（45分钟提醒+22:00禁用）
- [ ] 家长授权流程已实现
- [ ] 内容安全过滤已接入（微信内容安全API或自建）
- [ ] 所有页面无空白/报错
- [ ] 核心流程走通（注册→对话→报告→分享）
- [ ] 分享功能非强制
- [ ] 服务器域名已配置
- [ ] 算法备案已提交或通过
- [ ] 测试账号已准备（审核员用）

---

## 五、审核时间线

| 阶段 | 时间 |
|------|------|
| 算法备案申请 | 提前20-30个工作日 |
| 小程序开发 | 8周（参考tech-architecture.md） |
| 内部测试 | 1周 |
| 提交审核 | 1-7个工作日 |
| 如被拒修改后重提 | +3-5个工作日 |
| **总计** | **约12-14周** |

**建议：开发第1周就提交算法备案，不要等开发完才备案！**
