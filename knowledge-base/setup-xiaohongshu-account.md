## 二、内容策略

### 4种内容类型配比
| 类型 | 占比 | 目标 | 代表选题 |
|------|------|------|---------|
| 干货/方法论 | 40% | 收藏+涨粉 | Prompt公式/防投毒3招/错题分析法 |
| 案例/故事 | 30% | 信任+转化 | 70→85分/孩子做了研究报告 |
| 观点/争议 | 20% | 互动+破圈 | AI时代不让孩子考第一/编程班没用了 |
| 招生/产品 | 10% | 转化 | 速成班预告/名额倒计时 |

### 发布频率与时间
- 频率：每周3篇（周一/周三/周六）
- 时间：晚8:00-10:00（家长哄睡孩子后刷手机的黄金时间）
- 重要：不要每天发，频率太高会被限流

### 封面图设计规范
| 规范 | 要求 |
|------|------|
| 尺寸 | 3:4竖版（1080×1440px） |
| 文字 | 大字标题（≤10字）+ 小字副标题 |
| 颜色 | 暖色系为主（橙/米/暖白），避免紫蓝 |
| 字体 | 思源黑体/阿里巴巴普惠体（免费商用） |
| 风格 | 干净清爽，不要太花哨 |
| 工具 | Canva/稿定设计/醒图 |

### 正文写作公式

**万能结构：**
```
第1行：钩子（数据冲击/反常识/共情）
第2-3行：痛点描述（你是不是也……）
第4-8行：方法/案例/观点（核心内容）
倒数2行：总结一句话
最后1行：CTA + 标签
```

**去AI味检查（发之前必过）：**
- [ ] 读出来像真人说的话吗？
- [ ] 有没有"赋能""一站式""智能洞察"？
- [ ] 每段不超过3行吗？（手机上太长不看）
- [ ] 有没有用"你"而不是"我们"开头？
- [ ] 标题≤15字且有悬念吗？

## 三、互动策略

### 评论管理
- 发布后2小时内回复所有评论
- 回复时带问题引导继续互动（"你家孩子几年级？"）
- 负面评论不删，礼貌回应
- 点赞每一条评论（增加热度）

### 私信管理
- 设置自动回复：「感谢关注！回复"模板"领50个AI学习Prompt」
- 每天查看私信，24小时内回复
- 咨询速成班的家长 → 1v1详聊（参考家长答疑30问）

### 引流到私域
- 每篇帖结尾：「更多模板→私信"模板"」或「想进家长群→私信"社群"」
- 不要在帖子里直接放微信号（会被限流）
- 用置顶笔记或个人简介引导

## 六、避坑清单

| 坑 | 怎么避 |
|---|--------|
| 被限流 | 不要每天发；不要在正文放微信号/二维码；不要用违禁词 |
| 被举报 | 不要攻击竞品；不要用虚假数据；不要贩卖焦虑 |
| 内容同质化 | 保持爸爸视角的差异化；多用真实案例而非理论 |
| 涨粉慢 | 正常，教育号涨粉本来就慢。坚持3个月，质量>数量 |
| 热度过后沉寂 | 保持每周3篇的节奏，不要断更 |
