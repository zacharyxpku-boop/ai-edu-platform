# 原点智学 · 法律合规检查清单
> 上线前必须过一遍，不过不能上

---

## 一、未成年人保护（最高优先级）

- [ ] AI学伴小程序实名认证（未成年人使用需家长授权）
- [ ] 防沉迷系统：每日45分钟提醒+22:00-7:00禁用
- [ ] 不收集未成年人敏感信息（住址/身份证/学校名称）
- [ ] 对话内容不涉及暴力/色情/毒品/自杀
- [ ] AI回复检测：如学生表达负面情绪→引导联系家长+12355热线
- [ ] 家长可随时查看孩子的使用数据
- [ ] 家长可随时删除孩子数据

## 二、个人信息保护法（个保法）

- [ ] 隐私政策文档上线（小程序内+官网）
- [ ] 首次使用时弹出隐私政策同意弹窗
- [ ] 明确告知收集哪些数据/用途/存储方式
- [ ] 用户可以随时撤回授权
- [ ] 用户可以要求删除个人数据
- [ ] 数据存储在中国境内服务器（Supabase中国区/阿里云/腾讯云）
- [ ] 不向境外传输用户数据
- [ ] 数据加密传输（HTTPS）
- [ ] 密码/API Key加密存储（不明文）

## 三、双减政策合规

- [ ] 产品定位为"AI素养教育"而非"学科辅导"
- [ ] 所有对外材料不使用"补习""辅导""提分保证"等字样
- [ ] 课程内容强调"思维培养""能力提升"而非"考试提分"
- [ ] 不在节假日/寒暑假进行学科类培训（如果被认定为学科类）
- [ ] 关注教育部最新政策通知，及时调整

## 四、广告法/消费者权益

- [ ] 不使用"最好""第一""保证"等绝对化用语
- [ ] 不使用虚假案例/虚假数据

- [ ] 退款政策明确且执行到位
- [ ] 不进行诱导消费（特别是面向未成年人）
