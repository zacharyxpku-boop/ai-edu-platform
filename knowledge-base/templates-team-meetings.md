# 原点智学 · 团队会议模板
> 三人团队 · 高效沟通 · 不浪费时间

---

## 一、每周站会（15分钟·周一上午）

### 格式
- 腾讯会议/微信语音，不用视频
- 严格15分钟，超时下次再聊
- 每人5分钟

### 每人必答3个问题
```
1. 上周做了什么？（30秒，只说结果不说过程）
2. 这周要做什么？（30秒，只说最重要的1-2件事）
3. 有什么卡住了需要帮忙？（如果没有就说"没有"）
```

### 模板（群里文字版，可替代语音会）
```
【周一站会 · X月X日】

甲方(Zack)：
✅ 上周：[完成了什么]
🎯 本周：[要做什么]
🚧 卡点：[无 / 需要XX帮忙]

乙方(增长)：
✅ 上周：[完成了什么]
🎯 本周：[要做什么]
🚧 卡点：[无 / 需要XX帮忙]

丙方(交付)：
✅ 上周：[完成了什么]
🎯 本周：[要做什么]
🚧 卡点：[无 / 需要XX帮忙]
```

## 二、月度复盘会（60分钟·每月最后一个周五晚8点）

### 议程模板

**0:00-0:05 开场（甲方主持）**
```
"今天是X月复盘。按老规矩：
先看数据，再看KPI，然后互评打分，最后分钱。
控制在1小时内。"
```

**0:05-0:15 数据回顾（甲方展示）**
```
本月数据：
- 总收入：¥_______
- 总成本：¥_______
- 毛利润：¥_______
- 储备金(10%)：¥_______
- 可分配利润：¥_______

关键指标：
- 私域新增：___ 人
- 速成班/成长课报名：___ 人
- AI学伴MAU：___
- 小红书粉丝：___
- NPS：___
```

**0:15-0:30 各自KPI达成情况（每人5分钟）**
```
甲方KPI达成：
- [指标1]：目标X → 实际X → 达成/未达成
- [指标2]：...

乙方KPI达成：
- 招生人数：目标X → 实际X
- 内容发布量：目标X → 实际X
- 私域新增：目标X → 实际X

丙方KPI达成：
- 课件交付：完成/未完成
- 教学满意度：目标X → 实际X
- 渠道对接：目标X → 实际X
```

**0:30-0:40 互评打分（每人2分钟思考+发送）**
```
规则：
- 只给其他两人打分（0-100），不给自己打
- 在微信私信发给甲方，不在群里公开
- 打分维度：贡献度(40%) + 配合度(30%) + 超预期(30%)

甲方收到后当场公布：
- 互评权重60% + 甲方裁量40% = 最终分配比例
- 如有争议，当场讨论解决
```

**0:40-0:50 利润分配确认**
```
本月可分配利润：¥_______

分配结果：
- 甲方(XX%)：¥_______
- 乙方(XX%)：¥_______
- 丙方(XX%)：¥_______

三方确认后5个工作日内打款。
确认请回复"确认"。
```

**0:50-0:60 下月重点**
```
下月最重要的3件事：
1. [是什么] → 谁负责 → 什么时候完成
2. [是什么] → 谁负责 → 什么时候完成
3. [是什么] → 谁负责 → 什么时候完成
```

## 三、季度战略会（2小时·每季度末）

### 议程
1. **过去90天回顾**（30分钟）
   - 什么做得好？为什么？
   - 什么做得差？为什么？
   - 最大的意外/惊喜？

2. **数据深挖**（30分钟）
   - 哪个产品线贡献最多收入？
   - 哪个渠道获客效率最高？
   - 用户留存/续费数据怎么样？

3. **下季度方向**（30分钟）
   - 重点做什么？砍掉什么？
   - 团队分工需要调整吗？
   - 需要新增什么资源？

4. **产品路线图更新**（30分钟）
   - 下季度上什么新产品/功能？
   - 优先级排序

## 四、日常沟通规范

### 微信群规则
```
群名：原点智学·核心团队

规则：
1. 任务接受24h内确认，72h内提交方案
2. 重要事项群内@相关人
3. 超过3条消息的讨论 → 开语音/视频
4. 决策事项截图存档
5. 紧急事项直接打电话，不等回微信
```

### 什么事用什么方式沟通

| 事情 | 沟通方式 | 响应时限 |
|------|---------|---------|
| 日常进展同步 | 微信群文字 | 24h |
| 需要讨论的问题 | 微信语音/腾讯会议 | 当天 |
| 紧急问题 | 打电话 | 立即 |
| 正式决策 | 群里文字+确认截图 | 24h |
| 月度复盘 | 腾讯会议60分钟 | 固定时间 |

## 五、决策机制

```
日常运营决策（<¥1000）：各自负责领域自行决策
产品/定价调整（¥1000-10000）：群内讨论，2/3同意即执行
重大方向调整（>¥10000或战略级）：三方视频会，甲方最终拍板
```
