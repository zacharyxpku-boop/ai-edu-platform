## 二、注册流程

### Step 1: 选身份
**标题**: 你是谁？
- 🧒 我是学生（进入学生注册）
- 👩 我是家长（进入家长注册）

### Step 2a: 学生注册
**标题**: 告诉元元你的情况

| 字段 | 提示文字 | 必填 |
|------|---------|------|
| 昵称 | 给自己起个名字 | ✓ |
| 年级 | 选择你的年级（3-9年级） | ✓ |
| 教材版本 | 人教版/北师大版/苏教版/其他 | ✓ |
| 最想提高的科目 | 数学/语文/英语（可多选） | ✓ |

**按钮**: 认识元元 →

### Step 2b: 家长注册
**标题**: 绑定孩子的账号

| 字段 | 提示文字 |
|------|---------|
| 称呼 | 怎么称呼您 |
| 孩子昵称 | 输入孩子注册时的昵称 |
| 绑定方式 | 扫码绑定 / 输入邀请码 |

**说明文字**: 绑定后你可以查看孩子的学习报告和成长档案。

## 四、主页文案

### 首页布局文案

**问候语**（根据时间变化）:
- 早上(6-11): 「早上好，{昵称}！今天想挑战什么？」
- 中午(11-14): 「午休时间~来跟元元聊5分钟？」
- 下午(14-18): 「下午好！作业遇到问题了吗？」
- 晚上(18-22): 「晚上好！今天学到了什么新东西？」
- 深夜(22-6): 「太晚了，明天再来吧~ 💤」(22:00后禁用)

**功能入口文案**:
| 功能 | 入口名称 | 副标题 |
|------|---------|--------|
| 苏格拉底对话 | 一起想明白 | 问我问题，我帮你自己找到答案 |
| 学习诊断 | 测一测你在哪 | 10道题，找到你的薄弱点 |
| 提示词模板 | Prompt宝箱 | 50个拿来就用的学习模板 |
| 成长档案 | 我的成长 | 你的作品、进步、成就都在这里 |

**元元状态栏**:
- 「元元·灵种 | 经验值 3/10 | 再学4次就进化了！」
- 「🔥 连续学习3天 | 还差4天解锁新成就」
