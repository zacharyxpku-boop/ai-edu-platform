## 核心竞争壁垒分析（5类）

| 壁垒类型 | 描述 | 复制难度 |
|----------|------|----------|
| **人机混合** | 人的信任层+AI的效率层 | 高 |
| **数据飞轮** | 持续适应创造切换成本 | 非常高 |
| **垂直专精** | 聚焦特定学科/场景 | 中 |
| **自有内容** | 独特高质量数据+内容库 | 高 |
| **可证结果** | 证明学习效果的数据 | 中高 |

## 原点智学的差异化定位

**市场空白：**
- 人工规划师收费3000-10万+但无AI增强
- AI工具便宜(299-1999)但缺乏人的信任和深度
- "AI增强的家庭教育教练"模式是未被占据的甜蜜点
- 家庭教育指导师市场无标准——AI标准化方法可差异化

**我们的独特定位：**
1. 不是硬件（学而思/科大讯飞），不需要买设备
2. 不是替代老师（松鼠AI），而是增强家长引导力
3. 不是只给答案（小猿搜题），而是教方法和思维
4. 不是学科课程（好多AI），而是"学习力+思维力+输出力"
5. 免费利他内容（方法库/基础知识/新闻）建立信任→付费深化
