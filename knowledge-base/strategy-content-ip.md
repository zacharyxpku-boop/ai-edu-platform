# 原点智父 — 内容IP全战略手册

> 版本：v1.0 | 2026年4月
> 定位：原点智学全域流量引擎 | 第一层产品（IP流量层）
> 目标：6个月内建立AI家庭教育领域第一IP，私域月增200+，支撑智元家长社群和智元成长课转化

## 一、IP人格定义

### 1.1 人设定位

**原点智父不是什么：**
- 不是培训机构的课程销售
- 不是居高临下的教育专家
- 不是靠焦虑收割的知识付费博主
- 不是只会喊口号的创业者

**原点智父是什么：**

> 一个北大+伦敦商学院毕业的父亲，在AI时代重新思考「孩子到底该怎么学」这件事。他不卖课，他做实验——用自己的孩子、用身边的家庭、用真实的数据，趟出一条路。然后把趟出来的东西分享给你。

一句话人设：**「你身边那个懂AI、懂教育、还真在自己家干的爸爸」**

### 1.2 人格特征矩阵

| 维度 | 原点智父 | 文韬对照 |
|------|---------|---------|
| 情感基调 | 温暖理性（先共情再给方案） | 激情鸡血（先恐吓再给出路） |
| 说话方式 | 像朋友聊天（「我家孩子上周干了件事」） | 像演讲（「各位家长，时代变了！」） |
| 专业度 | 用数据说话不用感觉（「我跟踪了30个家庭3个月」） | 用案例说话（「我学员游小鹏怎么怎么样」） |
| 教育立场 | 成绩和能力都要（四维一体） | 回避成绩只谈生产力 |
| 焦虑管理 | 承认焦虑但给解法（「你焦虑对了，但方向错了」） | 制造焦虑再解决（「AI智商超清北你还刷题？」） |
| 商业感 | 低，更像科研分享 | 高，明显的创业者叙事 |
| 神秘感 | 有，东方哲学+西方商学的混合视角 | 无，纯理性科技路线 |

### 1.3 话语风格规范

**必须：**
- 用「我」开头：「我昨天试了个方法」「我观察到一个现象」
- 用具体数字：「我跟踪了23个家庭，其中17个出现了同一个问题」
- 用孩子的真实反应：「他第一反应是翻白眼，然后第三天主动来问我」
- 用反常识开头：「你以为最重要的是教孩子用AI？不是」
- 适度引用东方智慧：「老祖宗讲格物致知，AI时代的格物就是——」

**禁止：**
- "赋能""一站式""高效学习方案""精准分析"
- "AI驱动的教育革命""智能洞察""Powered by AI"
- 任何看起来像ChatGPT写的排比句
- "各位家长""亲爱的爸爸妈妈们"这种培训话术
- 三段式结构（痛点+方案+行动号召）的套路文

**标题原则：**
- 15字以内
- 有悬念或具体场景
- 用"你"开头或用孩子视角
- 禁止问号开头（太像标题党）

### 1.4 与文韬的差异化战略

| 对比维度 | 文韬（智能少年） | 原点智父 |
|---------|----------------|---------|
| IP类型 | 激情派创业者布道 | 理性派父亲实验 |
| 内容核心 | 案例轰炸（学员成绩） | 方法还原（过程拆解） |
| 焦虑策略 | 制造恐惧→卖解药 | 承认焦虑→给地图 |
| 学术背景 | 清华五道口金融圈 | 北大经济+伦敦商学院+东方玄学 |
| 覆盖盲区 | 不碰成绩/不碰情感 | 四维一体（含成绩+亲子） |
| 渠道依赖 | 100%视频号 | 四平台矩阵 |
| 商业模式 | 低频高价训练营 | 高频日常陪伴（AI学伴+社群+课程） |
| 内容壁垒 | 依赖个人演讲力 | 案例数据库+方法论体系+工具产品 |

**核心打法：文韬教育了市场，原点智父收割需求。** 文韬让1000+家庭认识到"AI教育重要"，但他只有训练营没有日常产品。这些家长就是原点智学的精准客户。

### 1.5 Zack独特背景的内容化

**北大经济学院 → 数据思维人设**
- 内容角度：「我用经济学的方式算了一笔账——孩子每天多省40分钟，一年省出243小时，相当于多了一个暑假」
- 体现方式：每篇内容都有数据、都有对比、都有量化

**伦敦商学院 → 全球视野人设**
- 内容角度：「伦敦的学校已经在做这件事了，我去年回去看了三所」
- 体现方式：定期输出海外AI教育动态，但不仰视，用对比视角

**东方玄学 → 神秘感+哲学深度**
- 内容角度：「易经讲"蒙以养正"，启蒙的本质不是灌输，是养正。AI时代的养正是什么？」
- 体现方式：偶尔（每月1-2次）从东方哲学切入教育，形成独特辨识度
- 注意：不做成玄学号，只是增加「这个人有点不一样」的记忆点

## 二、四平台内容矩阵

### 2.1 小红书（主战场）

**战略定位：** 种草+获客，把「原点智父」这四个字种进妈妈脑子里

**内容类型配比：**
| 类型 | 占比 | 形式 | 目的 |
|------|------|------|------|
| 案例展示 | 40% | 图文/视频笔记（孩子作品+过程对比） | 制造「我也想要」|
| 方法论 | 30% | 图文教程（5步/3招/清单体） | 提供价值建信任 |
| 认知升级 | 20% | 短图文/视频（数据+观点） | 打标签「这人懂」|
| 争议话题 | 10% | 文字笔记（观点碰撞） | 破圈涨粉 |

**发布频率：** 每周5条（周一三五六日），每天晚8-10点发布

**最佳发布时间：** 20:00-21:30（妈妈群体手机高峰）

**KPI目标：**
| 指标 | 月度目标 | 说明 |
|------|---------|------|
| 收藏率 | >8% | 核心指标，代表内容有用 |
| 互动率 | >5% | 评论+收藏+点赞/曝光 |
| 涨粉 | 月增500+ | 前3个月目标 |
| 私信引流 | 月增80+ | 导入微信私域 |
| 爆款率 | 20%笔记>1万曝光 | 每月至少1条破万 |

**内容模板：**

**模板A：案例展示型（小红书爆款结构）**
```
标题：[孩子年龄]+[具体成果]（≤15字）
封面：左右对比图 / 作品截图+手写标注

正文结构：
第1行：钩子（制造好奇）
「我家10岁的儿子用豆包写了个商业计划书，他班主任以为是我帮写的。」

第2-3行：背景（建立共情）
「他数学一般，语文更差，每天放学就想打游戏。
三个月前我试了个方法——」

第4-8行：过程还原（核心价值）
「第一步：不是教他用AI，是教他提问
第二步：给他一个「10岁CEO挑战」
第三步：让豆包当他的员工，他当老板
具体怎么做↓↓↓
（附截图/流程图）」

第9-10行：结果+转折
「第11天他主动跟我说：爸，我发现豆包说的也不全对。
——这句话比考100分更让我高兴。」

最后1行：引导互动
「你家孩子用AI做过最让你惊讶的事是什么？评论区聊」

标签：#AI教育 #原点智父 #小学生AI #孩子自主学习
```

**模板B：方法论型**
```
标题：你家孩子用AI的方式，可能全错了
封面：清单体封面（大字+编号）

正文结构：
第1行：反常识钩子
「90%的家长让孩子用AI的第一件事是查资料。大错。」

第2行：为什么错
「直接查资料=培养依赖。正确的第一步是——」

第3-7行：方法（3-5步，每步配截图）
「✅ 第一步：先让孩子自己想3分钟
✅ 第二步：把他的想法说给AI听（不是问AI）
✅ 第三步：让AI挑毛病（不是给答案）
✅ 第四步：孩子修改后再问AI"还有什么问题"
✅ 第五步：最终版本孩子自己定」

第8行：数据佐证
「我在23个家庭测试过，用这个方法的孩子，4周后主动使用AI的频率提高了3倍，但每次使用时间反而缩短了40%。」

最后：引导保存
「方法简单但容易忘，先收藏⭐再试」
```

**模板C：争议话题型**
```
标题：我不让孩子用DeepSeek
封面：纯文字封面，大字标题

正文：
「不是DeepSeek不好，是太好了。

我儿子用了一个月DeepSeek，作文从班里中等变成了前五。
听起来很好对吧？

但我发现一个问题：他写作文的时间从40分钟变成了5分钟。
不是他变快了，是他直接让DeepSeek写，自己改两个字交上去。

这不叫学习，叫作弊。

所以我做了一件事——（具体方法详见评论区第一条）

你家孩子有没有类似情况？」
```

**互动策略：**
- 每条笔记发布后1小时内回复前10条评论
- 评论区第一条自己占楼，放方法细节或引导加微信
- 遇到质疑不删不怼，用数据回应
- 每周找3-5个同类型博主互动评论（不是互赞，是真评论）
- 私信话术：「你说的这个问题我之前写过一个详细的方法，加我微信发你，比评论区说得清楚」

### 2.2 抖音·视频号（破圈渠道）

**战略定位：** 短视频破圈，触达小红书覆盖不到的爸爸群体和三四线城市

**发布频率：** 每周3条（周二、周四、周六）

**最佳发布时间：**
- 抖音：12:00-13:30（午休）或 21:00-22:30（晚间）

**KPI目标：**
| 指标 | 月度目标 |
|------|---------|
| 完播率 | >40% |
| 点赞率 | >3% |
| 评论率 | >1% |
| 涨粉 | 月增300+ |
| 引流私域 | 月增50+ |

**视频脚本模板：**

**模板A：认知冲击型（60秒口播）**
```
【0-5秒·钩子】
「你孩子现在用的豆包，3年后会被淘汰。」
（画面：正对镜头，表情平静但认真）

【5-20秒·颠覆认知】
「不是豆包不好。而是AI工具一年换一代。
你教孩子用豆包，就像2010年教他用诺基亚。
学会打字不重要，学会写什么才重要。」

【20-45秒·核心观点】
「我研究了全球30所走在最前面的学校，
它们教的不是某个工具，是三个底层能力——
第一，提出好问题的能力
第二，判断AI说得对不对的能力
第三，把AI的输出变成自己作品的能力
这三样，不会因为工具换代而失效。」

【45-60秒·行动+导流】
「具体怎么练？我整理了一份清单，
想要的在评论区扣1，我私信发你。」
```

**模板B：案例快闪型（45秒）**
```
【0-3秒】
「12岁，语文从82分到96分，没报一个班。」
（画面：成绩单对比，真实手写分数）

【3-15秒】
「她妈妈只做了一件事——
每天让她花15分钟，用AI改自己的作文。
不是让AI写，是让AI当老师改。」

【15-35秒】
「具体方法：
打开豆包，输入这段话——
（屏幕录制，展示prompt）
"请你扮演一个语文老师，指出我这篇作文的3个具体问题，不要帮我改，告诉我问题在哪，让我自己改。"

然后孩子改完再发给AI——
"我改了，你再看看。"
三轮下来，作文质量肉眼可见提升。」

【35-45秒】
「这就是原点智父讲的——AI不是代笔，是陪练。
更多方法，关注我。」
```

**互动策略：**
- 评论区置顶：每条视频都设一个置顶评论引导私信
- 评论区扣1策略：让用户扣数字获取资料，增加互动数据
- 直播预告：每周一次在视频结尾预告周末直播

**KPI目标：**

**文章模板：**

**模板A：深度方法论**
```
标题：你家孩子的AI学习，正在经历三个致命阶段

导语（100字）：
上个月我跟踪了30个正在用AI学习的家庭。发现一个规律：
几乎所有孩子都会经历三个阶段——兴奋、依赖、厌倦。
如果在"依赖"阶段不做干预，第三阶段就是"AI用了等于没用"。
今天拆解这三个阶段，以及每个阶段你该做什么。

正文结构：
一、兴奋期（第1-2周）：症状+家长常见误判
二、依赖期（第3-6周）：数据+真实案例+干预方法
三、突破期（第7周+）：正确引导后的变化+量化数据
四、原点智父的建议：3条可执行的行动清单
五、附：一份家庭AI学习自检表（扫码领取完整版→引流）

文末：
「这篇文章来自"原点未来研究院"。
我们不贩卖焦虑，只做一件事——用数据和方法，帮你在AI时代把孩子教好。
觉得有用，点个在看，让更多家长看到。」
```

- 留言精选：挑选3-5条高质量留言置顶并回复

## 三、内容生产SOP

### 3.1 每周选题会（周一 9:00-10:00）

**参与人：** Zack + 内容运营（远程即可）

**流程：**

| 步骤 | 时间 | 动作 | 输出 |
|------|------|------|------|
| 1. 数据回顾 | 15分钟 | 看上周每条内容的数据（收藏/互动/引流） | 找出上周TOP3和BOTTOM3 |
| 2. 热点扫描 | 10分钟 | 刷小红书/抖音热搜、家长群聊天记录、竞品动态 | 2-3个可追热点 |
| 3. 痛点挖掘 | 10分钟 | 翻看用户私信/社群问题/1v1咨询记录 | 3-5个真实痛点 |
| 4. 选题确定 | 15分钟 | 从选题库中匹配+新增，确定本周5条小红书+3条视频+1篇公众号 | 本周选题表 |
| 5. 分工排期 | 10分钟 | 确定每条内容的负责人、截稿时间、发布时间 | 周排期表 |

**选题评估标准（5分制）：**
- 痛点匹配度（这个话题家长真的在意吗？）— 3分起步才做
- 差异化（文韬/其他号讲过吗？我们能讲出不一样的吗？）— 2分起步
- 可执行度（需要多少素材？能在2小时内完成吗？）— 3分起步
- 传播潜力（有争议性/有共鸣/有实用价值吗？）— 2分起步

### 3.4 去AI味检查清单

每条内容发布前，逐条检查：

- [ ] **没有排比句**：三个以上结构相同的句子必须打散
- [ ] **没有总分总**：开头不是"在当今时代"，结尾不是"总而言之"
- [ ] **有口语标记**：至少包含2个口语表达（"说实话""你懂的""讲真"）
- [ ] **有具体数字**：至少有1个不是整数的真实数据（"23个家庭""第11天"）
- [ ] **有个人经历**：至少有1句以"我"开头的真实经历
- [ ] **有情感波动**：不是平铺直叙，有转折/意外/幽默
- [ ] **标题≤15字**：超了就砍
- [ ] **没有禁词**：检查禁词列表（赋能/一站式/高效/精准/驱动/智能洞察）
- [ ] **读出来顺**：整条内容用嘴读一遍，读不顺的地方改
- [ ] **辨识度测试**：盖住作者名，能认出是原点智父写的吗？

## 六、内容→私域→转化漏斗

### 6.1 每篇内容的导流设计

**导流三件套（每条内容必备）：**

| 导流位置 | 设计 | 话术模板 |
|---------|------|---------|
| 评论区第一条 | 自己占楼 | 「想要[具体东西]的姐妹，评论区扣"要"，我私信你」 |
| 正文末尾 | 自然引导 | 「更详细的方法我整理了一份PDF，加我微信发你，不收费」 |
| 个人简介 | 固定引流 | 「北大+LBS爸爸的AI教育笔记 | 加V领《家庭AI学习指南》」 |

**不同平台导流设计：**

**小红书：**
- 正文里不放微信号（会被限流）
- 用「评论区扣关键词→私信→给微信号」的链路
- 私信话术：「你好，你要的[XX]整理好了，加我微信yuandianzhifu发你，笔记里不方便放」

**抖音：**
- 视频口播：「想要这份清单的，评论区扣1」
- 评论区→私信→引导关注公众号或加微信
- 直播间：「今晚直播间的观众，加我微信领独家版」

**公众号：**
- 文末放「扫码领完整版」二维码（企业微信活码）
- 菜单栏设置「免费领取」入口
- 阅读原文→落地页→留手机号/加微信

**视频号直播：**
- 直播间挂企业微信二维码
- 每15分钟口播一次：「刚进来的朋友，扫码加群，直播结束我把PPT发群里」

## 七、内容壁垒建设

### 7.1 原点少年案例库（最强内容资产）

**为什么案例库是壁垒：** 文韬有3-5个明星案例反复讲。原点智学要做到50个、100个、500个真实案例。数量足够大时，任何人都无法复制。

**案例收集SOP：**

| 步骤 | 动作 | 输出 |
|------|------|------|
| 1. 日常收集 | 社群内家长主动分享孩子作品→运营标记 | 原始素材库 |
| 2. 每月评选 | 月末从素材库选出5-10个优秀案例 | 月度精选清单 |
| 3. 深度采访 | 对精选案例进行15分钟家长+孩子访谈 | 采访录音+文字稿 |
| 4. 内容制作 | 将采访转化为小红书/抖音/公众号内容 | 多平台内容包 |
| 5. 案例归档 | 按年龄/场景/工具/能力维度打标签入库 | 结构化案例数据库 |
| 6. 权限管理 | 获取家长授权书（用于对外传播） | 授权档案 |

**案例分类标签：**
- 年龄段：6-8 / 9-11 / 12-14 / 15-16
- 场景：学科提分 / AI创作 / 自主学习 / 思维训练 / 兴趣探索
- 使用工具：豆包 / DeepSeek / 原点AI学伴 / 其他
- 效果维度：学得快 / 考得高 / 思维好 / 有产出

**案例数量目标：**
| 时间 | 累计案例数 | 来源 |
|------|-----------|------|
| 第1个月 | 5-10个 | 创始人自己家+朋友 |
| 第3个月 | 30个 | 社群早期用户 |
| 第6个月 | 80个 | 付费用户+社群活跃用户 |
| 第12个月 | 200个 | 全渠道用户 |

**案例激励机制：**
- 分享孩子作品到社群→孩子获得「原点少年积分」
- 被选为月度精选→免费延长1个月社群会员
- 接受采访并授权传播→¥200现金/等值课程抵扣
- 年度最佳原点少年（3名）→免费一学期课程

### 7.2 建立行业权威（原点未来研究院）

**定位：** 原点智学旗下的研究品牌，输出AI教育领域的专业认知，建立行业话语权。

**权威建设四步走：**

**第一步（1-3月）：定期输出研究内容**
- 每月1篇《AI教育月报》：汇总国内外AI教育动态
- 每季度1份《中国家庭AI教育调研报告》：自有数据+公开数据
- 格式：PDF白皮书，设计精美，免费下载（用于引流）

- 邀请3-5位教育/AI领域专家做社群分享
- 与高校教育学院合作研究（北大/清华/华东师大）

- 成为行业论坛常驻嘉宾

### 7.3 让内容越来越难复制

**短期壁垒（0-6月）：**
- **真实数据**：跟踪家庭数据越多，别人越难伪造
- **人设辨识度**：北大+伦敦商学院+东方玄学，这个组合独一无二
- **话语风格**：温暖理性的父亲视角，跟所有焦虑营销号区分

**中期壁垒（6-18月）：**
- **案例库规模**：100+真实案例，每个有采访、有数据、有后续跟踪
- **社群口碑**：用户自发推荐，口碑飞轮转起来后外人追不上
- **研究品牌**：原点未来研究院的行业地位

**长期壁垒（18月+）：**
- **品牌心智**：「AI家庭教育=原点智学」的认知占位
- **数据飞轮**：AI学伴积累的学习数据→更精准的推荐→更好的效果→更多案例→更强品牌

**内容护城河公式：**
```
护城河 = 真实案例数量 × 数据追踪深度 × 创始人IP独特性 × 社群情感温度
```
