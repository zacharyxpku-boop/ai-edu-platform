# 清北伴学 产品设计文档
> 版本: V1.0 | 日期: 2026-04-03 | 产品线: 现金流产品
> 利用丙方清北资源，与AI学伴打通的辅导产品

---

## 一、产品定义

### 1.1 基本信息

| 维度 | 说明 |
|------|------|
| 产品名称 | 清北伴学 |
| 副标题 | 清北学长带你学，AI学伴帮你练 |
| 产品形态 | 在线1v1/小班辅导 + AI学伴课后自动复习 |
| 定价 | 1v1：¥200-300/小时，小班（3-5人）：¥80-120/小时/人 |
| 授课方式 | 腾讯会议/Zoom 在线直播，支持屏幕共享+白板 |
| 课程时长 | 每节60分钟（含5分钟课前对接+50分钟授课+5分钟课后总结） |
| 目标用户 | 9-16岁学生，以数学/英语/物理为核心科目 |

### 1.2 战略角色

```
原点智学产品矩阵中的位置：

速成班 ← 体验导流         ¥98-298
成长课 ← 核心收入+能力      ¥2980
清北伴学 ← 现金流+提分       ¥200-300/h    ← 你在这里
AI学伴 ← 粘性工具           ¥38/月
社群  ← 信任+转化            ¥199/季
```

**清北伴学的三重价值**：
1. **现金流** — 高客单价、高复购率，稳定收入来源
2. **提分验证** — 积累"成绩提升"的真实案例，反哺成长课/速成班的招生
3. **AI学伴冷启动** — 每次辅导后AI学伴自动生成复习任务，推动工具使用

### 1.3 与智元成长课的区别定位

| 维度 | 清北伴学 | 智元成长课 |
|------|---------|-----------|
| 核心目标 | **提分** — 解决眼前的考试/作业问题 | **能力** — 建立AI辅助学习的长期能力 |
| 教学内容 | 学科知识点+考试技巧+错题攻克 | AI学习方法+批判性思维+研究产出 |
| 教学方式 | 清北学长1v1/小班讲题 | 苏格拉底-AI协作法系统课 |
| 时间维度 | 按次/按包，灵活约课 | 8周+4周固定周期 |
| 师资 | 清北在校生/毕业生 | 专业教师+AI助教 |
| 家长心智 | "找清北学霸给孩子补课" | "让孩子掌握AI时代的学习方法" |
| 适合人群 | 有明确提分需求的学生 | 想系统培养AI素养的学生 |
| 竞品对标 | 家教/补习班/猿辅导 | 文韬/Alpha School |

**关键原则**：清北伴学是"术"（提分工具），成长课是"道"（能力体系）。两者互补，不冲突。

## 二、学科优先级

### 2.1 优先顺序：数学 → 英语 → 物理

| 排序 | 学科 | 理由 |
|------|------|------|
| **第1** | **数学** | ① 家长付费意愿最高（"数学是分水岭"）<br>② 提分效果最直观、最快（2-3个月可见变化）<br>③ AI辅助数学学习已被Khanmigo验证有效（0.23SD提升）<br>④ 清北理科生最多，师资最充足<br>⑤ 标准化程度高，教学质量可控 |
| **第2** | **英语** | ① 市场需求稳定，家长长期投入<br>② AI口语陪练是天然优势（与AI学伴联动强）<br>③ 英语辅导可做高频（每周2-3次），客单价高<br>④ 清北英语水平普遍较高 |
| **第3** | **物理** | ① 初二/初三开始学物理，很多学生卡在物理上<br>② 物理思维训练和数学互补<br>③ 高中物理是很多学生的"命门"<br>④ 但师资相对窄（需理科背景），排在第三 |

### 2.2 暂不开设的学科

| 学科 | 不开的原因 | 未来可能性 |
|------|-----------|-----------|
| 语文 | 提分周期长，标准化困难，AI辅助效果不显著 | 作文专项可考虑 |
| 化学 | 师资窄，需求量不如数学英语 | 高中阶段可考虑 |
| 生物 | 同化学 | 高中选课阶段 |
| 政史地 | 非核心提分科目 | 暂不考虑 |

## 三、师资团队组建

### 3.1 丙方清北同学招募标准

#### 硬性条件

| 条件 | 要求 |
|------|------|
| 学校 | 北京大学/清华大学 在校生（本科/硕士/博士）或毕业3年内 |
| 成绩 | 高考对应学科≥140/150（数学）或英语≥140/150，或竞赛省级奖项 |
| 教学经验 | 有≥50小时家教/辅导经验（优先），或通过培训考核 |
| 时间 | 每周可稳定排课≥4小时 |
| 设备 | 稳定网络+电脑+麦克风+手写板（数学需要） |

#### 软性条件

| 条件 | 评估方式 |
|------|---------|
| 表达能力 | 试讲10分钟，用学生听得懂的语言讲一个知识点 |
| 耐心 | 模拟场景：学生连续3次说"不懂"，观察反应 |
| 亲和力 | 面试中的自然互动 |
| 价值观 | 认同"引导思考，不给答案"的教学理念 |

### 3.2 招募渠道

| 渠道 | 方式 | 预期效果 |
|------|------|---------|
| 丙方个人人脉 | 丙方直接推荐清北同学（核心渠道） | 首批5-10人 |
| 北大清华BBS/论坛 | 发布兼职招募贴 | 补充5-10人 |

### 3.3 培训流程（3天线上）

| 天数 | 内容 | 时长 | 考核 |
|------|------|------|------|
| Day 1 | **教学理念** — 原点智学教育理念+苏格拉底引导法+AI学伴联动机制+清北伴学的定位（提分工具不是能力课） | 2小时 | 理念问答（口头） |

## 四、与AI学伴联动设计

### 4.1 联动机制

```
辅导前（课前）
├── AI学伴自动推送"课前预习任务"（基于上节课的薄弱点）
├── 学生在AI学伴中完成预习（10分钟）
└── 预习数据同步给辅导老师（了解学生当前水平）

辅导中（课中）
├── 老师在白板/屏幕上讲解
├── 老师标记本节重点知识点和薄弱点
└── 课后信息自动同步到AI学伴

辅导后（课后）
├── AI学伴自动生成"课后复习任务"
│   ├── 本节知识点的巩固题（3-5道）
│   ├── 薄弱点的专项训练（3-5道）
│   └── 变式题（举一反三，2-3道）
├── 学生在AI学伴中完成复习（15-20分钟）
├── AI学伴的苏格拉底对话帮助理解
├── 复习数据自动同步给老师和家长
└── 下次辅导前老师查看复习数据，调整教学
```

### 4.2 数据打通

| 数据流向 | 内容 | 用途 |
|---------|------|------|
| 老师→AI学伴 | 本节知识点+薄弱点+推荐练习方向 | AI自动生成复习任务 |
| AI学伴→老师 | 学生复习完成率+正确率+对话记录 | 老师调整下节教学 |
| AI学伴→家长 | 辅导+复习的完整学习报告 | 家长了解进展 |
| 全链路→系统 | 学生能力变化数据 | 效果追踪+案例积累 |

### 4.3 家长端可见性

每次辅导后家长收到的报告：

```
【清北伴学 · 辅导报告】

📌 本次辅导
- 科目：数学 | 老师：小张（北大数学系大三）
- 内容：一元二次方程求解
- 表现：掌握了公式法，因式分解法还需加强

📌 AI学伴复习任务（已自动布置）
- 巩固题：5道（预计15分钟）
- 薄弱专项：3道因式分解（预计10分钟）
- 状态：⏳ 待完成

📌 老师建议
- 回家后用AI学伴复习因式分解，重点是配方法
- 建议下次辅导继续一元二次方程应用题
```

## 六、质量保证

### 6.1 试听机制

| 项目 | 标准 |
|------|------|
| 首课试听 | 新学生首节课为试听课，不满意全额退款 |
| 试听后决策期 | 试听后3天内决定是否购买课程包 |
| 试听课标准 | 老师按正常课程上，不做特殊表演。结束后和家长沟通10分钟 |
| 试听课定价 | 单独购买¥300，但购买课程包可抵扣 |

### 6.2 满意度追踪

| 追踪维度 | 方式 | 频次 |
|---------|------|------|
| 课后即时反馈 | 每节课后推送5星评价（1-5星+文字选填） | 每节 |
| 月度满意度 | 月度电话/微信沟通（班主任执行） | 每月 |
| 阶段效果评估 | 对比报名前后成绩变化 | 每学期 |

### 6.3 不满意处理机制

```
家长反馈不满意
    ↓
第1次：班主任24小时内沟通，了解具体原因
    ├── 老师教学问题 → 与老师沟通改进，下节课观察
    ├── 师生不匹配 → 立即更换老师（免费试听新老师1节）
    ├── 课程内容问题 → 调整教学计划
    └── 其他原因 → 一事一议
    ↓
第2次：同一原因再次不满意
    ├── 老师教学问题 → 强制换老师
    ├── 对产品整体不满 → 退剩余课时费用（已上课时不退）
    └── 超出服务范围 → 坦诚沟通，引导至其他产品
    ↓
退款处理：剩余课时×单价，5个工作日内退款
```

### 6.4 教学质量抽查

| 方式 | 频次 | 执行 |
|------|------|------|
| 课堂录像抽查 | 每月每位老师抽查1节 | 丙方+Zack |
| 家长回访电话 | 每月随机5位家长 | 班主任 |
| 课后总结审阅 | 每周抽查30%的课后总结 | 丙方 |
| 学生成绩追踪 | 每次考试后收集成绩 | 班主任 |

## 八、运营流程

### 8.1 学员全生命周期

```
咨询阶段
├── 家长咨询 → 了解孩子情况（年级/科目/成绩/目标）
├── 匹配老师 → 根据科目/年级/时间匹配2-3位老师供选择
└── 安排试听 → 24小时内安排试听课

试听阶段
├── 试听课 → 老师按正常标准上课
├── 课后沟通 → 老师反馈+班主任和家长沟通
└── 决策 → 家长3天内决定是否报名

正式上课
├── 购买课程包 → 确定排课时间
├── 每周上课 → 按固定时间上课
├── 课后复习 → AI学伴自动生成任务
├── 月度沟通 → 班主任和家长月度沟通
└── 效果追踪 → 考试成绩对比

续费/升级
├── 课时用完前2周 → 提醒续费
├── 满意度高 → 推荐升级更大的包
├── 有能力需求 → 推荐成长课（提分+能力双线）
└── 推荐其他家长 → 裂变
```

### 8.2 排课管理

| 项目 | 标准 |
|------|------|
| 约课方式 | 班主任每周日前确认下周课表 |
| 调课规则 | 提前24小时调课免费，24小时内调课扣1次课时 |
| 缺课规则 | 老师缺课免费补课+道歉，学生缺课提前24小时通知可改期 |
| 排课频率 | 建议每周2-3次（提分效果最佳），最少每周1次 |

## 十一、扩展可能

### 11.1 短期扩展（6-12个月内）

| 方向 | 说明 | 启动条件 |
|------|------|---------|
| **AI竞赛培训** | 信息学奥赛/数学竞赛/物理竞赛的AI辅助训练 | 有竞赛经验的清北老师≥3人 |
| **作文专项** | AI辅助写作训练（语文/英语作文提分） | 完成数学英语的验证 |
| **小升初/中考冲刺班** | 针对升学节点的密集训练 | 积累足够的成绩提升案例 |

### 11.2 中期扩展（12-24个月）

| 方向 | 说明 | 启动条件 |
|------|------|---------|
| **实习项目** | 利用清北人脉对接企业实习（高中生） | VIP学员≥50人 |
| **背景提升** | 科研课题/论文指导/学术竞赛 | 有研究生导师资源 |
| **留学辅导** | 清北学长做留学文书/面试辅导 | 有留学经验的老师≥5人 |

### 11.3 长期扩展（24个月+）

| 方向 | 说明 |
|------|------|
| **AI证书培训** | 与机构合作推出AI素养认证（可加分/加学分） |
| **校企合作** | 进入学校做AI辅助教学的B端服务 |
| **师资平台化** | 从自营师资扩展为平台模式（更多高校+更多学科） |

### 11.4 扩展优先级评估框架

```
评估维度（每项1-5分）：
1. 市场需求（家长付费意愿）
2. 师资可行性（能否快速组建团队）
3. 与现有产品协同度（是否增强AI学伴/成长课）
4. 盈利空间（毛利率≥40%）
5. 品牌一致性（是否符合原点智学定位）

总分≥20分 → 启动筹备
总分15-19分 → 观察等待
总分<15分 → 暂时搁置
```

## 十二、风险与预案

| 风险 | 概率 | 影响 | 预案 |
|------|------|------|------|
| 清北老师排课不稳定（期末/考试期） | 高 | 学员体验下降 | 每个老师配1个备选老师，提前2周确认期末安排 |
| 家长对"大学生家教"信任度不够 | 中 | 试听转化低 | 强调"清北+AI学伴联动"差异化，展示成绩提升案例 |
| 老师教学质量参差不齐 | 中 | 满意度下降 | 严格培训+月度评分+淘汰机制 |
| 被认为是"传统家教换个皮" | 中 | 品牌损害 | 持续强调AI学伴联动是核心差异：不是找人讲题，是讲题+AI练题的闭环 |
| 政策风险（双减延伸到线上1v1） | 低 | 产品被迫调整 | 定位为"AI素养+学科融合"而非纯学科辅导，保持合规弹性 |
| 老师被家长直接挖走（绕过平台） | 中 | 收入流失 | 协议约束+AI学伴联动价值（绕过平台就没有AI复习任务），让平台本身有不可替代性 |
