## 成长课学员入学流程

### 报名确认（付款后2小时内）

**Step 1: 电话/语音确认**
- 主动打电话给家长（不是文字消息）
- 话术: "你好XX妈妈，我是Zack。恭喜报名成长课！我想花3分钟了解一下孩子的情况，好让我们的老师提前准备。"
- 确认: 孩子年级+目前成绩水平+家长最关心的问题+孩子用AI的经验

**Step 2: 发送入学礼包消息**
```
【智元成长课·入学确认】

欢迎 [孩子名字] 加入探索轨第X期！🎉

📅 开课日期: X月X日(周X) 20:00-21:00
📅 课程周期: 8周正课 + 4周项目期
👨‍🏫 班主任: [名字] (微信: XXXXX)
👥 班级: [X]人小班

【入学准备（开课前完成）】
1. 完成AI学习力测评（链接附后），建立能力基线
2. 下载原点AI学伴小程序，注册账号
3. 准备近1个月的错题照片（10道以上）
4. 加班主任微信，进入班级群

【退款保障】
前4节课（1个月）不满意全额退款，零附加条件。
我们对课程质量有信心，你只需要给我们一个证明的机会。

有任何问题随时找我或班主任！
```

**Step 3: 班主任对接**
- 班主任24小时内主动联系家长
- 了解孩子情况（学科强弱、性格特点、学习习惯）
- 建立班级群

### 开课前3天
- 班主任在班级群发: 开课倒计时+同学自我介绍
- 引导每个孩子在群里说: "我叫XX，X年级，我希望用AI学会XX"

### 开课前1天
```
【明天就开课了！】

🎯 第1课主题: AI学习入门 — Prompt公式+第一次对话体验
⏰ 时间: 明天(周X) 20:00-21:00
📍 腾讯会议链接: [链接]

📋 准备：
✅ AI学伴小程序已注册
✅ 豆包App已下载
✅ 错题照片已准备好

[孩子名字]，元元已经在等你了！明天见！
```

### 第1节课后（24小时内）班主任必做
1. 私信家长:
```
XX妈妈，第1节课结束了。
[孩子名字]今天表现不错，[具体1个亮点]。
课后作业已发在群里，建议今晚或明天完成。
有任何问题随时找我！
```

2. 群里发作业提醒
3. 前3个交作业的孩子点名表扬

### 关键节点触达

| 时间点 | 动作 | 负责人 | 话术要点 |
|--------|------|--------|---------|
| 第1课后24h | 私信确认首课感受 | 班主任 | 肯定孩子+确认作业 |
| 第4课后 | 中期成长报告 | 班主任 | 4维度变化数据+续课预热 |

| Demo Day后 | 效果报告+续课推荐 | Zack | 完整效果数据+下期信息 |

## 所有入学流程的共同原则

1. **速度第一** — 付款后30分钟内必须有人联系
2. **真人感** — 不要群发模板消息，至少改1个个性化细节
3. **降低焦虑** — 第一条消息就说清楚退款政策
4. **制造期待** — 提前发有价值的资料，让家长觉得"还没上课就值了"
5. **班主任是关键** — 家长续费70%取决于"对这个人的信任"
