## 一、平台选择

### 视频号优先（短期）
- 微信生态内，与私域无缝打通
- 家长用户在微信里，不需要跳平台

### 抖音同步（中期）
- 流量池更大，破圈能力更强
- 但跳转到微信有阻力（需要"评论区扣1"引导私信）
- 建议视频号稳定后再开抖音

## 三、内容策略

### 核心定位
> 不做日更博主，做"每一条都值得看完"的精品号

### 发布频率
- 视频号：每周2条（周二+周五）
- 抖音：同步发（或延迟1-2天发）
- 不追求数量，1条爆款 > 10条普通

### 4种视频类型

| 类型 | 占比 | 目的 | 时长 | 代表选题 |
|------|------|------|------|---------|
| 知识干货 | 40% | 涨粉+收藏 | 60-90秒 | "1个AI公式让孩子作文提升一档" |
| 反常识/争议 | 25% | 播放量+破圈 | 20-30秒 | "AI考试成绩已超清华，你还在让孩子刷题？" |
| 案例故事 | 25% | 信任+转化 | 45-60秒 | "数学70→85，只做了一件事" |
| 招生/产品 | 10% | 直接转化 | 30-45秒 | "速成班还剩X个名额" |

### 视频制作标准

**开头3秒 — 决定生死**
```
有效钩子：
✓ 数据冲击："99.7%的学生在用AI，但90%的家长不知道"
✓ 反常识："教育部刚官宣——AI成为第四通识"
✓ 共情提问："每天催孩子写作业催到崩溃的家长请举手"
✓ 悬念："我让10岁孩子用AI做了一件事，结果让我惊了"

无效开头：
✗ "大家好，我是XXX"（没人关心你是谁）
✗ "今天给大家分享一个方法"（太平淡）
✗ 长logo动画（直接划走）
```

**中段 — 核心内容**
- 每15秒一个信息点（注意力窗口就15秒）
- 用数据/案例说话，不空讲理论
- 口播节奏：快→慢→快（不要匀速说话）

**结尾 — 行动号召**
```
✓ "评论区扣1，我把模板发给你"
✓ "关注我，每周教你一个AI学习技巧"
✓ "主页有详细内容"
✓ "想了解更多？私信我"

✗ 不要说"微信搜XXX"（抖音会限流）
✗ 不要放二维码（直接被删）
```

### 字幕要求
- 必须有字幕（很多人静音刷）
- 字体大（24pt+）、颜色对比强（白字黑边）
- 关键词用不同颜色标注
- 工具：剪映自动字幕+手动校对

## 四、拍摄/剪辑SOP

### 设备（极简方案）
- 手机：竖版拍摄（9:16）
- 支架：手机三脚架（¥50搞定）
- 灯光：窗户自然光（面对窗户拍） 或 ¥100环形灯
- 背景：干净书架/白墙（不要太杂乱）
- 收音：手机自带 或 ¥50领夹麦

### 拍摄流程（30分钟出一条）
```
1. 写脚本（10分钟）— 参考content-scripts.md
2. 对着镜头读2遍（5分钟）— 不用背，说到大概就行
3. 正式录（5分钟）— 一条过，不追求完美
4. 剪辑（10分钟）— 剪映：掐头去尾+加字幕+加BGM
```

### 剪辑标准
- 总时长：30-90秒（超过90秒完播率断崖下跌）
- 掐掉所有"嗯""啊""那个"
- BGM音量比人声低50%
- 开头不要空白/黑屏（第1帧就要有内容）

## 六、爆款公式（从文韬学到的）

文韬在视频号的爆款有一个共同结构：

```
开头(3秒): 反常识数据 → "你知道吗？AI已经比清华生考试考得好了"
问题(10秒): 共鸣 → "但99%的家长还在让孩子用20年前的方法学习"
转折(5秒): 希望 → "但也有孩子——10岁用AI做出了XX"
方法(20秒): 干货 → 具体怎么做（1-2-3步）
案例(15秒): 证明 → 真实案例+真实数据
收尾(5秒): 行动 → "评论区扣1/关注我"
```

**原点智学的调整：**
- 文韬的风格偏激情/鸡血 → 原点偏温暖/理性
- 文韬靠"恐惧+希望"双驱动 → 原点靠"方法+案例"驱动
- 文韬不碰提分 → 原点正面说"考得高也重要"
- 差异化：爸爸视角+北大背景+东方美学调性
