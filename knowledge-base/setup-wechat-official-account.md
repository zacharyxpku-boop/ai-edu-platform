## 三、公众号内容规划

### 发布频率
- 订阅号：每周四晚8点，1篇深度文章
- 不追求数量，追求质量（每篇>2000字，有干货有案例）

### 内容分类标签
```
#AI学习方法    — 实操类（Prompt/工具/工作流）
#原点研究院    — 深度类（行业趋势/政策解读）
#原点少年      — 案例类（学员故事/作品展示）
#家长课堂      — 认知类（AI教育理念/亲子指导）
```

### 首月4篇文章选题
| 周 | 选题 | 类型 | 字数 |
|---|------|------|------|
| W1 | 2026了，你的孩子还在"野生"用AI吗？ | 认知 | 2500 |
| W2 | 从70分到85分：一个初中生用AI分析错题的真实故事 | 案例 | 2000 |
| W3 | 别再给孩子报编程班了——AI时代需要的不是编程，是思维 | 观点 | 2500 |
| W4 | 家长AI素养自测：你的"引导力"够吗？ | 互动 | 2000 |

### 文章排版规范
- 标题：≤22字（公众号标题限制）
- 摘要：≤50字，有悬念
- 正文字号：16px
- 行间距：1.75倍
- 字间距：0.5px
- 配色：正文黑色 + 重点橙色(#E94D35) + 引用灰色
- 配图：每500字至少1张图（可用AI生成/Unsplash免费图）
- 排版工具：秀米/135编辑器（免费版够用）

### 每篇文章必须有的元素
1. **开头钩子**（前3行决定读不读完）
2. **数据支撑**（至少1个数据点）
3. **真实案例**（至少1个具体故事）
4. **可操作建议**（读完能做什么）
5. **结尾CTA**（测评/速成班/社群，选1个）
