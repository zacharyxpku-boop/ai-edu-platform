> 2026年4月 · 阁主审核通过

## 零、评估方法论

本评估基于四个维度交叉验证：

| 数据源 | 样本 | 核心发现 |
|--------|------|---------|
| 50+家长真实反馈 | 文韬直播课报名数据 | P0=提效自学，豆包90%，9-14岁70% |
| 竞品文韬/智能少年 | 3年1000+家庭 | 线下营强但无日常产品，不碰提分 |
| Alpha School | $1B投入22校区 | 2小时模型+争议（WIRED调查） |
| 可汗Khanmigo | 70万+学生 | 苏格拉底验证有效，3周衰减是硬伤 |

**约束条件：**
- 团队3人（Zack做产品/技术，乙方做增长，丙方做交付）
- 资金=0（资金池制，赚钱才分钱）
- 中国市场（双减+AI素养强制+国产模型）
- 时间窗口：2025-2026是品牌心智抢占期

## 一、家长真实需求 vs 现有产品设计的GAP分析

### 家长说的话 → 他们真正想要的 → 我们该做什么

| 家长原话 | 翻译成真实需求 | 现有产品设计是否覆盖 | GAP |
|----------|-------------|-------------------|-----|
| "用AI提升学习效率" | 孩子做作业更快、成绩看得见提升 | ✓ AI学伴(苏格拉底对话+错题分析) | **缺：接入中国课标题库+成绩追踪仪表盘** |
| "如何写指令/Prompt" | 我不会用AI，给我模板我抄 | ✓ prompts.html有模板 | **缺：场景化Prompt包(按学科/年级/场景)** |
| "防GEO投毒" | AI会不会教坏孩子 | ✗ 无任何信息可信度标注 | **必须加：来源标注+批判性思维训练** |
| "孩子没专注力/不想学" | 方法再好孩子不用=白搭 | ✗ 无游戏化/激励系统 | **致命缺口：无激励系统=产品无法留存** |
| "找到兴趣方向" | 成绩之外的出路 | △ 六大挑战任务(但太浅) | **需深化：兴趣探索→产出→作品集** |
| "会不会让孩子依赖AI" | 安全感 | ✓ 设计原则"AI不给答案" | 需要在产品/营销中反复强化这一点 |

### 关键洞察：现有产品设计全案(V1)的3个致命盲区

1. **没有解决"孩子不想用"的问题** — 所有设计假设孩子有学习意愿，但50+家长数据显示"专注力/自驱力缺失"是第4大痛点。没有游戏化=Khanmigo式的3周衰减必然重演。

2. **没有"拿来就用"的轻量入口** — 产品漏斗从"社群¥199/季"起步，但家长真正想要的是"今天就能用、免费、3分钟见效"的东西。缺一个0成本的"Aha moment"产品。

3. **课程产品太重、太慢** — 智元成长课¥3980/学期+12周，但家长的耐心窗口是2周。文韬用5-7天训练营解决体验问题，Alpha用2小时学习解决效率叙事。原点需要一个更轻更快的体验产品。

### 产品线1：原点AI学伴（日常陪伴工具）— P0 最高优先级

**为什么这个排第一：**
- 文韬最大弱点 = 无日常产品。这是我们的精准切入点
- Khanmigo验证了苏格拉底模式有效（0.23SD提升）
- 家长P0需求 = 提效自学，这就是工具该做的事
- 工具有数据飞轮 → 用得越多越精准 → 留存越高 → 竞争壁垒越深

**产品定义：**

| 维度 | 设计 |
|------|------|
| 形态 | 微信小程序(MVP) → 独立App(正式版) |
| 核心能力 | 苏格拉底对话(不给答案，引导思考) |
| 技术 | DeepSeek-chat / Qwen作为基座(国内可用+数学更准) |
| 防沉迷 | 每日45分钟提醒 / 22:00-7:00屏蔽 |
| 防依赖 | AI永远不直接给答案，必须孩子先思考 |

**功能分层（Freemium）：**

| 功能 | 免费版 | 成长版¥38/月 | 家庭版¥68/月 |
|------|--------|------------|------------|
| 苏格拉底对话 | 5次/天 | 无限 | 无限×2孩子 |
| 学科覆盖 | 数学+语文 | 全科 | 全科 |
| Prompt模板库 | 基础20个 | 全部100+ | 全部+自定义 |
| 每周成长报告 | 月报 | 周报 | 周报+家长看板 |
| 作品存储 | 5个 | 无限 | 无限+家庭相册 |
| 错题分析 | ✗ | ✓ | ✓ |
| AI辩论伙伴 | ✗ | ✓ | ✓ |
| 学习规划 | ✗ | ✗ | ✓ |

**游戏化设计（解决3周衰减）：**
- 原点能量值：每次深度思考(对话≥3轮)+10，完成作品+50
- 成就勋章：提问家/探索者/创造者/批判者 四条线
- AI学伴宠物：随使用成长，不用就饿（轻度FOMO，不惩罚）
- 周挑战：每周一个趣味AI任务，完成解锁新宠物装扮
- 排行榜：只展示"本周进步最大"而非绝对分数，鼓励增量

**中国课标适配：**
- 对接人教版/北师大版知识点体系
- 按年级+学期+单元组织Prompt模板
- 错题分析基于中国考试题型(选择/填空/解答)

**关键指标：**
- 免费→付费转化率 > 15%
- 月留存率 > 40%（超过Khanmigo的3周衰减线）
- 日均使用时长 > 15分钟

### 产品线2：AI学习方法速成班（轻体验课）— P0 最高优先级

**为什么这个排第一（并列）：**
- 家长P1需求 = "Prompt怎么写""拿来就用"
- ¥3980的课太重，需要一个轻量体验产品验证付费意愿
- 文韬用"两天一夜家庭营"做体验层，我们需要线上版
- 这是智元成长课的导流产品，不是独立产品

**产品定义：**

| 维度 | 设计 |
|------|------|
| 形态 | 线上直播课（3节×60分钟） |
| 定价 | ¥298（体验价¥198） |
| 班型 | 20-30人直播，可回看 |
| 交付周期 | 1周（周一/周三/周五） |
| 讲师 | Zack亲讲首期 |

**课程大纲：**

| 节次 | 主题 | 家长/孩子获得 |
|------|------|-------------|
| 第1节 | **AI不是搜答案，是问好问题** | Prompt万能公式+5个拿来就用的学科模板。课后作业：用AI分析一道错题 |
| 第2节 | **识破AI的谎话：防投毒实操** | 3步验证法(交叉验证+追问来源+反向测试)。课后作业：让AI犯错并抓住它 |
| 第3节 | **2小时搞定作业，剩下时间做项目** | 完整的AI辅助学习工作流：诊断→计划→执行→复盘。课后作业：用AI做一份研究小报告 |

**为什么这3节就够：**
- 第1节回应P1痛点(Prompt)
- 第2节回应P1痛点(防投毒)
- 第3节回应P0痛点(提效)+植入Alpha School叙事(2小时)
- 每节课后作业 = 强制使用AI学伴 = 工具冷启动

**转化路径：**
速成班¥298 → 深度体验AI学伴 → 报名智元成长课¥3980

### 产品线3：智元成长课（核心收入产品）— P1

**调整建议（对比原设计V1）：**

| 维度 | 原设计V1 | 优化后 | 原因 |
|------|----------|--------|------|
| 首发年龄 | 探索轨(9-11岁) | **不变** — 9-11岁是最大客群 | 数据验证：家长反馈35%集中在此年龄段 |
| 课时 | 12周×60分钟 | **8周×60分钟 + 4周项目期** | 12周太长，家长耐心窗口2-4周，前8周密集教学+后4周做作品 |
| 班型 | 8-12人 | **不变** | 小班是核心差异化，Khanmigo无法做到 |
| 定价 | ¥3980 | **¥2980(早鸟¥2480)** | 对标文韬训练营价位，降低首批决策门槛 |
| 教学法 | 苏格拉底 | **不变** — 全球验证最有效 | Khanmigo+Alpha都在用Bloom理论 |
| 核心产出 | 研究报告 | **不变 + 强化可见性** | 但增加：产出过程AI学伴记录 → 自动生成成长档案 |
| 退款 | 前2课时 | **前4课时(1个月)不满意全额退** | 文韬没有退款承诺，这是我们的信任差异化 |

**新增设计：**
- **家长旁听席**：每节课最后5分钟开放家长旁听（解决家长"不知道学了啥"焦虑）
- **月度Demo Day**：每月最后一节课是小型展示，家长观看孩子作品（裂变触发点）
- **班级排行：只排进步值**，不排绝对成绩（避免焦虑，鼓励增长）

### 产品线5：清北伴学（提分产品）— P2

**为什么保留这条线：**
- 家长P0需求 = 提分，这是底线
- 丙方有清北背景，天然背书
- 短期变现快（1v1辅导客单价高）
- 但：这不是原点智学的品牌核心，是务实的现金流产品

**产品定义：**

| 维度 | 设计 |
|------|------|
| 形态 | 1v1在线辅导 / 3-5人小班 |
| 学科 | 数学/英语/物理（高需求学科优先） |
| 定价 | 1v1: ¥200-300/小时 / 小班: ¥80-120/小时 |
| 师资 | 丙方清北同学团队 |
| 差异化 | 每次辅导后AI学伴生成复习任务（打通工具） |
