## 核心定位（30秒版）

> 原点智学是一个AI素养教育服务提供商。
> 我们帮学校解决一个问题：2025年9月起AI素养成为必修，但老师不知道怎么教。
> 我们提供：现成的课程包+教师培训+AI学习工具。
> 学校不需要额外开发，直接用。

## 学校合作的3个卖点

### 1. 政策刚需
> 2025年9月起，AI素养教育列入中小学必修课，每年≥8小时。
> 教育部文件已下发，学校必须执行，但大多数学校没有现成的课程和师资。
> 原点智学提供即用型解决方案。

### 2. 家长认可
> 我们已服务XXX个家庭（首期开始后更新真实数字）
> 家长NPS评分>70（有数据后更新）
> 学校引入原点课程 = 给家长交代"我们在做AI教育"

### 3. 零风险试点
> 可以从一个班级/一次活动开始试
> 效果好再扩大
> 不满意不续约

## 跟学校决策者聊天的话术

### 开场（找到痛点）
```
"X校长，请教一个问题：
今年9月AI素养课就要开了，你们学校准备得怎么样了？
老师们有没有现成的教案和工具？"
```

### 引入（给方案）
```
"我们原点智学专门做这件事。
简单说就是：我们出课程包+培训老师+提供AI工具，
学校不用自己开发，直接用。

已经有X所学校在合作了（或：我们正在找第一批试点学校）。"
```

### 打消顾虑
```
"可以先做一次试点——比如一个班的课后服务，或者一场AI创作日活动。
效果好再扩大，完全没有风险。"
```

### 关键：找对决策人
- **课后服务负责人** — 管课后服务安排，最容易切入
- **信息技术老师** — AI素养课的执行者，最需要你的课件
- **教务主任** — 管课程安排，有决策权
- **校长** — 终极决策者，但一般不直接接触供应商

**策略：从信息技术老师或课后服务负责人切入 → 用他们做内部推荐 → 触达教务主任/校长**

## 丙方（清北背景）的学校拓展优势

丙方清北背景是打开学校大门的最强名片：
- "清华/北大在读生来给学校做AI教育" → 学校有面子
- 校友网络可以直接介绍到校长/教务主任
- 先做一次免费分享（"清华学长教AI"），建立信任后再谈合作

**丙方的KPI：每月对接≥2所学校的初步沟通**
