## SLIDE 4 · 孩子用AI的3种典型模式（5:00-8:00）
**标题**: 你家孩子属于哪一种？
**三列**:
- 🔴 **搜答案型**: 遇到不会的题直接问AI，抄完交差。结果=越来越不动脑
- 🟡 **让AI写型**: 作文/报告让AI写完自己改几个字。结果=写作能力退化

**口播**:

## SLIDE 6 · Prompt万能公式（9:00-15:00）⭐核心
**标题**: 4个要素，往里填就行
**公式大字**:

```
身份 + 任务 + 要求 + 例子
```

**逐一讲解**:

| 要素 | 说明 | 作用 |
|------|------|------|
| 身份 | 告诉AI它是谁 | 决定输出质量的第一要素 |
| 任务 | 你要它做什么 | 明确方向 |
| 要求 | 限制条件和格式 | 控制输出精度 |
| 例子 | 给它一个参考 | 让输出风格一致 |

**口播**:
> 「记住：身份是最关键的。同一道题，你让AI扮演"百度知道"和"有10年经验的数学老师"，答案质量天壤之别。」

## SLIDE 7 · 现场演示：普通问法 vs 公式问法（15:00-20:00）
**左右对比**:

**普通问法**:
> 「帮我讲讲分数加法」
> AI输出：一堆教科书文字，孩子看不懂

**公式问法**:
> 「你是一位擅长用生活例子讲课的数学老师（身份），
> 请用切披萨的场景解释1/2+1/3怎么算（任务），
> 用10岁孩子能听懂的语言，不超过200字（要求），
> 像这样开头：小明和妹妹在分一个大披萨…（例子）」

**现场打开豆包，实时演示两种问法的区别（屏幕共享）**

**口播**:
> 「看到区别了吗？同一个AI，问法不同，答案完全不同。这就是为什么有的家长说'AI没用'——不是AI没用，是问法不对。」

## SLIDE 9-13 · 5个学科模板（25:00-40:00）⭐核心

### SLIDE 9 · 模板1：数学错题分析师
```
你是学习教练，请分析这道错题的原因。
要求：
- 不要给正确答案
- 只告诉我错在哪一步
- 用"你觉得这一步的逻辑是什么"来引导我
```
**演示**: 现场拍一道错题发给AI，展示效果

### SLIDE 10 · 模板2：语文作文教练
```
你是语文特级教师，请评价这篇作文。
要求：
- 先说3个优点，再说3个改进建议
- 不要直接帮改写
- 改进建议要给具体例子
```
**演示**: 用一篇真实学生作文演示

### SLIDE 11 · 模板3：英语口语陪练
```
你是美国高中英语老师，现在陪我练口语。
要求：
- 用简单英语对话
- 我说错了先表扬我说得好的部分，再温柔纠正
- 每次只纠正1个错误，不要一次说太多
```

### SLIDE 12 · 模板4：知识解释器
```
你是科学博物馆的讲解员，请解释[概念]。
要求：
- 用8岁孩子能理解的语言
- 举一个身边的例子
- 不超过150字
```

### SLIDE 13 · 模板5：思维拓展器
```
你是批判性思维教练。
围绕"[话题]"提出5个不同角度的问题。
要求：
- 问题要让人"咦，我没想过这个"
- 每个问题附一句为什么要从这个角度想
```

**每个模板讲3分钟（30秒讲场景+1分钟演示+1.5分钟Q&A）**
