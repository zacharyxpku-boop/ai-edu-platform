# 原点智学 · 危机预案
> 希望永远用不到，但必须提前准备

---

## 一、可能的危机场景

### 高概率（必须提前准备）

**C1: 家长不满意要退款+发负面评价**
- 触发：课程效果不达预期/孩子不喜欢/家长期望过高
- 预案：
  1. 24小时内私信联系，不在群里/公开场合讨论
  2. 先听完家长说完，不辩解
  3. 按退款政策执行（该退就退，不拖）
  4. 退款后追加一次关怀："虽然没能帮到您，但如果以后有需要随时找我"
  5. 如果家长在小红书发负面帖 → 在评论区礼貌回应（不删帖不攻击）
  - 话术：「感谢你的反馈，我们确实还有很多需要改进的地方。这个问题我记下了，会在下期课程中优化。如果你愿意的话，欢迎私信我聊聊具体情况。」

**C2: AI学伴给出错误答案**
- 触发：数学算错/事实编造/不恰当内容
- 预案：
  1. 向反馈的家长道歉+感谢发现问题
  2. 记录具体错误case → 加入prompt优化
  3. 在群里/朋友圈主动说："我们的AI有时候也会犯错，所以我们才教孩子验证。发现AI错误的孩子反而最厉害"
  4. 把"发现AI错误"变成一种荣誉 → "火眼金睛"徽章

**C3: 讲师教学质量差**
- 触发：讲师敷衍/不按苏格拉底法教/直接给答案
- 预案：
  1. 收到家长投诉后24小时内回听课程录像
  2. 确认问题后与讲师私聊（不在群里通报）
  3. 给家长：安排补课/换讲师/退差价
  4. 连续2次投诉 → 暂停讲师排课+辅导培训

### 中概率

**C4: 被指控"贩卖焦虑"**
- 触发：内容被误读为"不学AI就完了"
- 预案：
  1. 审查所有公开内容，删除任何可能被解读为焦虑营销的表述
  2. 发一篇正面声明："我们的立场是提供方法而非制造恐慌"
  3. 增加"不贩卖焦虑"的明确承诺在品牌介绍中

**C5: 竞品攻击/抄袭**
- 触发：文韬等竞品点名批评/抄袭内容
- 预案：
  1. 不回应攻击，不打口水仗
  2. 如果被抄袭 → 截图存证 + 继续快速迭代（让他们追不上）
  3. 专注做好产品，用户口碑是最好的回应

### 低概率但严重

**C6: 监管政策变化（双减扩大到AI教育）**
- 预案：
  1. 确保所有内容定位为"AI素养教育"而非"学科辅导"
  2. 不使用"提分""补习"等敏感词
  3. 课程名称和介绍中强调"思维培养""能力提升"

**C7: 学生数据泄露**
- 预案：
  1. 最小化数据收集（不收集身份证/住址等敏感信息）
  2. 所有数据存储在境内服务器（Supabase中国区）
  3. 一旦发现泄露 → 24小时内通知所有受影响用户
  4. 个保法合规检查每季度做一次

## 二、危机应对原则（刻进DNA）

1. **速度** — 24小时内必须有第一次回应
2. **真诚** — 不推诿不甩锅，有错就认
3. **私密** — 在私聊解决，不在公开场合争论
4. **过度补偿** — 退款要爽快，赔偿要超预期
5. **变坏事为好事** — 每次危机都是改进的机会，公开说"我们因为这件事做了什么改进"
