# 原点智学 · 课程体系V3 · 终稿
> 基于20条观点+25条方法+21条案例+13条金句重构
> 每节课有明确的"不会→会→做出来"的变化弧线
> 通俗到8岁能听懂，深入到教育专家挑不出毛病

---

## 课程哲学（一句话）

> **用AI学会任何东西，用AI做出你自己的东西。**

不是"学AI"，是"用AI学+用AI做"。

这12个字是原点智学版本的核心叙事，对标文韬的"以自学为基础，以生产为导向"但更直白、更面向家长和孩子。

### S1：你一直在错误地用AI（60min）

**变化弧线：** "AI就是搜答案的" → "原来AI可以当私教"

| 时间 | 做什么 | 用了什么素材 |
|------|--------|------------|
| 0-3 | **开场炸弹** | [Q7]席酉民："80%大学毕业生专业能力不如AI" + [D20]"全球84%人没用过AI，你今天来了就已经领先" |
| 3-8 | **你家孩子怎么用AI的？** | 三种模式PK：🔴搜答案(抄)→🟡让AI写(替)→🟢问AI问题(学)。"红色和黄色占了90%。不是孩子的错——没人教。" |
| 8-12 | **一个公式改变一切** | 身份+任务+要求+例子。类比："像给外卖备注——你写'随便'和你写'少辣多葱不要香菜加个蛋'，出来的东西完全不同" |
| 12-18 | **现场PK** | 同一道题，两种问法，屏幕共享豆包现场打。[D6]张亚勤："问得越深，AI回答越深入" |
| 18-22 | **你也来试** | 全场打开手机，改写"帮我讲光合作用"→聊天区发→挑3个演示 |
| 22-35 | **5个模板直接拿走** | 数学错题教练/语文作文教练/英语口语陪练/知识解释器/思维拓展器——每个完整Prompt+现场演示 |
| 35-40 | **核心秘密** | [Q5]李开复："会提问才是真能力" → "永远让AI不给答案而是问你问题。AI给答案=枪手。AI问问题=教练。" [M4]安德森的三指令："教我/测试我/反驳我" |
| 40-48 | **全场实操** | 每人用模板分析一道错题 → 看效果 → "刚才这3分钟比刷10道题有用" |
| 48-52 | 作业 | 回去分析3道错题，截图发群 |

## Phase 1：用AI学会任何东西（W1-W3）

> 核心方法：超级学霸4步法 [M1] + 费曼输出 [M3] + 效率对比测试 [M10]
