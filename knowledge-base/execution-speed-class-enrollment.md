# 速成班14天招生执行手册
> 从0到30个付费学员的逐日操作

---

## 目标
- 14天内招满30人
- 首期体验价¥98（后续¥298）
- 零广告预算，全靠内容+私域

---

## Day 1-3：内容蓄水（不卖课）

### Day 1
| 时间 | 动作 | 话术/内容 |
|------|------|---------|
| 上午 | 小红书发帖#1：测评引流 | "测了一下儿子的AI学习力，第三项让我坐不住了" |
| 下午 | 建微信免费群 | 群名"智元家长·AI学习交流"，发群规+欢迎语 |
| 晚上 | 朋友圈第1条 | "今天看了一个数据：99.7%的学生已经在用AI了。但系统性接受AI教育的不到15%。你家孩子是哪种？" |
| 全天 | 私聊邀请20人入群 | 从通讯录选目标家长，逐一私聊邀请 |

### Day 2
| 时间 | 动作 |
|------|------|
| 上午 | 回复小红书所有评论，私信每个互动用户 |
| 下午 | 群里发第一条干货（Prompt公式简短版） |
| 晚上 | 朋友圈第2条："教了孩子一个AI公式，他说比老师讲得还清楚" |

### Day 3
| 时间 | 动作 |
|------|------|
| 上午 | 小红书发帖#2：Prompt干货帖 |
| 下午 | 群里发AI工具推荐（豆包+DeepSeek介绍） |
| 晚上 | 朋友圈第3条："有家长问我让孩子用AI会不会越来越懒。看怎么用。" |

**Day 1-3 KPI：** 群内≥30人 / 小红书2篇 / 朋友圈3条

## 如果Day 13还没招满30人

| 报名人数 | 应对策略 |
|---------|---------|
| 25-29人 | 正常开课，缺口用老带新补（"推荐1人双方减50"） |
| 20-24人 | 正常开课，同时把名额降到25继续招 |
| 15-19人 | 正常开课，加一条朋友圈"因为名额有限特别珍贵，报名的都是真正重视AI教育的家长" |
| <15人 | 延期1周，加大内容输出，不降价 |

**核心原则：宁可少招也不降价。98已经是体验价，再降就失去价值感。**
