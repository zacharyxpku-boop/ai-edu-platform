## 一、产品定义

### 1.1 三层社群体系

| 层级 | 名称 | 价格 | 人数上限 | 平台 | 战略角色 |
|------|------|------|---------|------|---------|
| 第1层 | 智元家长·开放群 | **免费** | 500人/群 | 微信群 | 流量池+认知教育+筛选付费用户 |
| 第2层 | 智元家长·成长群 | **¥199/季** | 100人/群 | 微信群+知识星球 | 深度内容+信任建立+课程转化阵地 |
| 第3层 | 智元家长·VIP群 | **¥999/年** | 30人/群 | 微信群+专属服务号 | 高净值家长+深度服务+口碑核心 |

### 1.2 各层核心差异

| 维度 | 免费群 | 付费群¥199/季 | VIP群¥999/年 |
|------|--------|-------------|-------------|
| 内容 | 每周1篇精选文章+碎片化讨论 | 五大固定栏目+系统化内容 | 全部内容+专属深度内容 |
| 互动 | 群内自由讨论 | 有组织的话题讨论+答疑 | 1v1答疑+定制化建议 |
| 工具 | 无 | AI学伴7天体验码/月 | AI学伴全年免费 |
| 课程优惠 | 无 | 速成班减¥50/成长课减¥200 | 速成班免费/成长课减¥500 |
| 线下 | 无 | 线下工作坊优先报名 | 线下活动免费参加 |
| Zack接触 | 无 | 群内偶尔回复 | 每月1次线上茶话会 |

### 1.3 定价逻辑

- **¥199/季** = ¥2.2/天 = "一杯奶茶钱换一周的AI教育认知升级"
- **¥999/年** = ¥2.7/天 = "全年深度陪伴+所有优惠算下来约等于免费"
- 季付降低决策门槛，年付锁定长期用户
- VIP年费回本测算：成长课减¥500 + AI学伴¥288免费 + 速成班¥298免费 = ¥1,086价值 > ¥999

## 二、免费群运营方案

### 2.1 定位

免费群是**漏斗最宽的入口**，目标是让尽可能多的家长感受到"原点智学是靠谱的、有干货的"，从而筛选出愿意付费的家长。

### 2.2 每周内容规划

| 日期 | 内容类型 | 具体内容 | 发布时间 |
|------|---------|---------|---------|
| 周一 | 认知升级 | 1篇AI教育趋势/数据解读文章（800-1200字） | 8:00 |
| 周三 | 实用方法 | 1个"拿来就用"的AI学习技巧（图文/短视频） | 12:00 |
| 周五 | 话题讨论 | 抛出一个争议话题，引导家长讨论（如"你让孩子用AI写作业吗？"） | 20:00 |
| 周日 | 案例分享 | 1个孩子用AI学习的真实案例（如果没有则用模拟案例，标注为示范） | 10:00 |

### 2.3 活跃策略

| 策略 | 具体做法 | 目标 |
|------|---------|------|
| 入群仪式 | 新成员发自我介绍（孩子年龄+城市+最想解决的问题），管理员24小时内回复欢迎+推荐1篇相关内容 | 降低潜水率 |
| 话题引爆 | 每周五晚8点的话题讨论，前3个发言的家长获得"思考者"标签 | 制造参与惯性 |
| UGC激励 | 家长主动分享孩子AI学习经历，管理员精选+整理成案例发公众号（署名+感谢） | 鼓励产出 |
| 快闪福利 | 每月1次不定期"福利快闪"：免费AI工具评测报告/Prompt模板包/限时课程优惠 | 培养关注习惯 |
| 淘汰机制 | 连续30天无任何互动（含点赞/回复）→ 私聊确认是否继续 → 无回复移出 | 保持群质量 |

### 2.4 导流付费群路径

```
免费群家长
    ↓ 每周看到付费群专属内容预告："本周付费群公开课主题是XX，精华摘要见下方"
    ↓ 看到付费群学员的专属案例/资源
    ↓ 每月1次"付费群开放日"（选1个栏目内容免费开放）
    ↓ 季度末限时优惠："本季度新入会减¥30，限20人"
    ↓
付费群（¥199/季）
```

**转化话术**：
> "免费群我们会持续分享内容。如果你想要更系统的AI教育认知升级——每周一节公开课+案例深度拆解+工具评测+专属答疑+课程优惠——可以加入成长群。¥199/季，不到一杯奶茶一天，随时退群全额退款。"

### 栏目4：周五答疑（周五 20:00-20:30）

#### 运营流程

```
周三-周四：群内征集问题（文字接龙或小程序投票）
    ↓
周五18:00：整理问题，分类（工具类/方法类/心理类/课程类），优先回答高票问题
    ↓
周五20:00-20:30：文字答疑（非直播，降低运营成本）
    ↓
流程：
- 20:00 公布本次回答的5-8个问题
- 20:00-20:25 逐个回答，每个问题200-400字
- 20:25-20:30 快速回答群内追问
    ↓
周五21:00：整理答疑精华，发知识星球存档
```

#### 答疑分类应对

| 问题类型 | 回答策略 | 示例 |
|---------|---------|------|
| 工具使用类 | 给步骤+截图，建议试试AI学伴的对应功能 | "DeepSeek和豆包哪个适合小学生？" |
| 学习方法类 | 给原则+具体操作建议，引用Bloom/苏格拉底理论 | "孩子抄AI答案怎么办？" |
| 心理焦虑类 | 先共情，再给框架，不给具体答案（转1v1） | "孩子完全不想学习怎么办？" |
| 课程咨询类 | 客观介绍，不硬推，给试听/体验机会 | "成长课适合我家孩子吗？" |

## 八、防死群策略

### 8.1 活跃度监控

| 指标 | 健康 | 预警 | 危险 |
|------|------|------|------|
| 7日活跃率 | >60% | 40-60% | <40% |
| 每日发言条数 | >20条 | 10-20条 | <10条 |
| 公开课参与率 | >50% | 30-50% | <30% |
| 新增成员/周 | >5人 | 2-5人 | <2人 |

### 8.2 应急方案

**预警级（活跃率40-60%）— 7天行动方案**

| 天数 | 行动 |
|------|------|
| Day 1 | 管理员在群内发起"争议话题"讨论（如"你觉得AI会取代老师吗？"） |
| Day 2 | 发放一个有价值的"限时资源"（如"10个学科Prompt模板包，今天领取"） |
| Day 3 | @3-5个活跃度高的家长，公开感谢+邀请分享经验 |
| Day 4 | 发布一个家长容易参与的活动（如"晒一下你家孩子最近用AI做的东西"） |
| Day 5 | 做一个快速调研：发投票"你最想在群里看到什么内容？" |
| Day 6 | 根据调研结果调整内容策略，在群内公布调整 |
| Day 7 | 评估效果，未回升则启动危险级方案 |

**危险级（活跃率<40%）— 14天深度干预**

| 行动 | 说明 |
|------|------|
| 内容升级 | 连续3天密集发布高价值内容（干货长文/独家数据/内部报告） |
| 大咖空降 | 邀请1位外部嘉宾做一次特别分享（教育专家/企业家/AI从业者） |
| 主题活动 | 启动"7天AI学习挑战赛"（每天打卡完成一个AI任务） |
| 1v1私聊 | 管理员私聊20%的沉默用户，了解不活跃原因 |
| 清理 | 移除30天零互动的用户（先私聊确认） |
| 补血 | 同步加大新成员引入力度 |

### 8.3 结构性防死策略

| 策略 | 说明 |
|------|------|
| 固定节奏 | 五大栏目按固定时间执行，形成家长的"期待惯性" |
| UGC驱动 | 让家长成为内容生产者（案例分享/经验交流），而不是只消费 |
| 积分体系 | 积分可兑换课程优惠/AI学伴使用时间，给参与加外部动机 |
| 小组制 | 100人以上分成小组（按孩子年龄），小组内更亲密 |
| 定期淘汰 | 每季度清理不活跃用户+引入新血液 |
