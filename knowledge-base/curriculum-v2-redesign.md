## 一、为什么V1不够

### V1课程的本质问题

V1教的是：**怎么用AI做作业更好**
- Prompt公式 → 问AI更好的问题
- 错题诊断 → 找薄弱点
- 学习规划 → 做攻坚计划
- 阅读理解 → 用AI深度读文章
- 作文提升 → AI当教练
- 信息验证 → 防投毒
- 研究方法 → 做调研
- 作品整合 → 写报告

**本质上这是一套"AI辅助学习方法课"——帮孩子考试考得更好。**

文韬教的是：**怎么用AI成为一个能创造价值的人**
- 生产者思维 → 从消费者变成创造者
- AI编程 → 用AI写代码做游戏/网站
- 3D打印 → 把想法变成实物产品
- 内容创作 → 拍视频号/写公众号
- 商业实战 → 定价/销售/赚到真钱
- 投资思维 → 理解金钱/资本的逻辑

**本质上这是一套"AI时代生存力课"——帮孩子在AI时代不被淘汰。**

### 原点智学该教什么

**两者都要，但有自己的独特整合方式。**

文韬的弱点：他回避成绩，只讲"生产者"。但中国家长的底线是成绩不能掉。
可汗的弱点：他只做学科学习，不做产出和创造。
Alpha的弱点：全日制学校，不可复制，且有伦理争议。

**原点智学的独特定位：**

> 用AI同时做到三件事——
> ① 学习更高效（成绩是底线）
> ② 思维更先进（批判/创造/生产者思维）
> ③ 作品真实可见（不只是分数，是做出来的东西）

这就是"四维一体"真正该有的含义：
- **学得快** = AI提效自学（对标Alpha 2小时学完）
- **考得高** = 成绩可验证提升（对标可汗0.23SD）
- **思维好** = 生产者思维+批判性思维（对标文韬三种思维）
- **有产出** = 用AI做出真实项目/产品（对标文韬STEM营）

## 四、成长课V2（12周 · 面向9-14岁 · ¥2,980）

**V2根本性变化：从"8周学习技巧+4周项目"变成"6周能力训练+6周实战项目"**

### V2课程结构

```
Phase 1: AI超级学霸（Week 1-3）
  → 解决成绩焦虑，让家长放心

Phase 2: AI时代思维（Week 4-6）
  → 打开视野，从学生变成思考者

Phase 3: AI项目实战（Week 7-12）
  → 从想法到产品，做出真实成果

Demo Day: 展示+路演（Week 12最后一天）
```

### 逐周设计

#### Phase 1: AI超级学霸（Week 1-3）· "先解决成绩问题"

**Week 1: AI自学入门——不是教你用AI，是教你用AI学任何东西**

| 核心内容 | 学生做什么 |
|---------|-----------|
| Prompt万能公式（复用速成班S1） | 写3个不同学科的Prompt |
| 苏格拉底式AI对话体验 | 第一次被AI追问"你觉得呢" |
| 超级学霸4步法介绍（整理→讲解→拓展→复述） | 理解4步法框架 |
| 跨学科思维启蒙："用AI从5个角度看《草船借箭》" | 尝试跨学科分析 |

**课后作业：** 用4步法自学一个新知识点（选你最弱的科目），记录过程

**Week 2: AI错题诊断——找到Bug然后消灭它**

| 核心内容 | 学生做什么 |
|---------|-----------|
| 错题分析Prompt（复用但更深入） | 分析20+道错题 |
| 能力雷达图 | 画出自己的5维雷达 |
| 2周攻坚计划制定 | 拿到个性化学习计划 |
| **新增：费曼输出法**——"你能给AI当老师讲一遍吗" | 录一段视频讲解一个知识点 |

**课后作业：** ①开始执行攻坚计划Day1 ②录一段2分钟视频讲你今天学的知识点

**Week 3: AI自学高手——用AI一天学完一周的内容**

| 核心内容 | 学生做什么 |
|---------|-----------|
| 超级学霸完整实操（一个完整学科章节） | 2小时内学完一个新章节 |
| AI自测：学完立刻做题验证 | 做AI出的测试题 |
| 效率对比：传统方法vs AI方法 | 记录时间和正确率对比 |
| **成绩验证：课前测vs课后测** | 看到自己的进步数据 |

**课后作业：** 用AI自学下一个你还没学到的章节，记录用了多少时间

**Phase 1结束时的成果：** 每个孩子有一份可量化的"学习效率提升数据"→这是给家长看的硬指标

---

#### Phase 2: AI时代思维（Week 4-6）· "打开一扇新的门"

**Week 4: 生产者思维——从消费者变成创造者**

| 核心内容 | 学生做什么 |
|---------|-----------|
| 消费者vs生产者（文韬核心理念，原点版本） | 算一算自己每天消费/生产的时间比 |
| AI让生产成本→零 | 看3个同龄人案例 |
| **你的第一个生产者身份：内容创作者** | 用AI写一篇300字的小红书帖文 |
| 三大杠杆入门：内容/智能/资本 | 理解"一份时间卖多次"的逻辑 |

**课后作业：** 用AI创作一段内容（文章/视频脚本/海报），发到群里

**Week 5: 批判性思维——AI说的话不能全信（你说的也不能）**

| 核心内容 | 学生做什么 |
|---------|-----------|
| 防投毒3招（复用但面向学生优化） | AI侦探游戏 |
| **新增：你自己的观点也要被质疑** | 写一个观点→让AI从反面驳你→你反驳AI |
| 辩论训练：AI当对手 | 5分钟AI辩论实战 |
| **批判性思维4步：定义→分类→比较→因果** | 用4步分析一个社会现象 |

**课后作业：** 选一个你坚信的观点，让AI说服你改变想法。你被说服了吗？为什么？

**Week 6: 解决真实问题——从"做作业"到"做项目"**

| 核心内容 | 学生做什么 |
|---------|-----------|
| 项目思维入门：发现问题→调研→设计方案→执行→展示 | 列出身边3个你想解决的问题 |
| 案例学习：同龄人做过哪些真实项目 | 分析3个案例的思路 |
| **选题确定：选你Phase 3要做的项目** | 确定自己的项目方向 |
| 项目类型介绍：研究报告/AI工具/创意产品/内容IP | 选一个你最想做的类型 |

**课后作业：** 完成项目选题表+初步调研

**Phase 2结束时的成果：** 每个孩子有一个确定的项目方向 + 初步的调研数据

---

#### Phase 3: AI项目实战（Week 7-12）· "做出来给人看"

**这6周是原点智学区别于所有竞品的核心价值。**

每个学生选择一个项目类型，在6周内从零做出一个真实成品：

| 项目类型 | 最终产出 | 适合谁 | 用到的AI |
|---------|---------|--------|---------|
| **A. 调研报告** | 2000字研究报告(如"我们小区的停车问题") | 喜欢分析的孩子 | AI搜索+数据分析+图表生成 |
| **B. AI工具/智能体** | 一个可运行的AI小工具(如"英语单词记忆助手") | 喜欢技术的孩子 | Coze/扣子空间搭建AI agent |
| **C. 创意产品** | 一个可展示的创意作品(如AI生成的绘本/动画/海报系列) | 喜欢创意的孩子 | AI绘图+设计+排版 |
| **D. 内容IP** | 一个有3-5篇内容的小红书/公众号(如"10岁教你学AI") | 喜欢表达的孩子 | AI写作+剪辑+排版 |

### Phase 3 逐周节奏

| 周 | 主题 | 交付物 | 教师做什么 |
|---|------|--------|-----------|
| W7 | 项目启动：需求调研+方案设计 | 项目计划书(1页) | 1v1 check-in审核方案 |
| W8 | 核心创作1：收集素材/搭建框架 | 第一版框架/原型 | 巡场指导+解决卡壳 |
| W9 | 核心创作2：完成初版 | 初版成品 | 1v1反馈+修改建议 |
| W10 | 迭代优化：根据反馈修改 | 第二版成品 | 组织peer review(同学互评) |
| W11 | 包装展示：写介绍+做展示PPT | 展示PPT+3分钟演讲稿 | 演讲训练 |
| W12 | **Demo Day：正式展示+评审+颁奖** | 最终作品+展示 | 主持+评委+颁奖 |

### Demo Day V2（不再是"虚构投资人评语"）

**评审维度（5项×20分=100分）：**

| 维度 | 评的是什么 | 20分标准 |
|------|-----------|---------|
| 问题意识 | 你发现了一个值得解决的问题吗 | 问题真实+有数据支撑 |
| AI运用 | 你怎么用AI帮你完成的 | AI是工具不是替代，说清AI做了什么你做了什么 |
| 完成度 | 作品完整吗 | 有完整的结构和成品 |
| 原创性 | 有你自己的思考吗 | 不只是AI生成的拼凑 |
| 表达力 | 你能清楚地讲给别人听吗 | 3分钟讲清楚+自信 |

**奖项（真实评选，不虚构）：**
- 最佳调研奖 / 最佳技术奖 / 最佳创意奖 / 最佳表达奖 / 最具影响力奖

## 六、原点智学 vs 文韬 的课程差异

| 维度 | 文韬 | 原点V2 | 我们的独特优势 |
|------|------|--------|-------------|
| 成绩 | 回避，只讲生产者 | Phase 1正面攻坚 | 家长底线焦虑直接解决 |
| 编程 | 重度(AI Coding全栈) | 轻度(Coze/扣子搭建AI agent) | 门槛更低，9岁能做 |
| 3D打印 | 核心差异化 | 不做(需要设备投入) | 不硬拼硬件 |
| 内容创作 | 视频号/公众号 | 小红书/公众号(更适合低龄) | 适配年龄 |
| 投资 | 股票/基金模拟 | 不在核心课程内(太超前) | 聚焦+不贪多 |
| 设备管控 | 3-strike制 | 防沉迷+家长报告 | 科技手段>人工管控 |
| 日常陪伴 | ❌ 无(营结束就没了) | ✅ AI学伴365天 | 核心壁垒 |
| 苏格拉底法 | 不系统 | 核心教学法 | 可汗验证有效 |
| 费曼输出 | 有(录视频) | 有(录视频+写文章) | 整合进课程 |
| 教学方式 | 线下集训6天 | 线上12周+线下营(可选) | 更灵活 |

**原点V2的真正独特之处：**
1. **同时解决成绩+思维+产出**（文韬只做后两个）
2. **有日常AI学伴陪伴**（文韬完全没有）
3. **线上12周系统课**（文韬只有6天线下集训）
4. **4种项目类型自选**（文韬项目相对固定）
5. **苏格拉底+费曼双教学法**（学术验证有效）
