### SLIDE 3 · 真实事件（2:00-5:00）
**标题**: 上周发生了一件事
**内容**:
- 我家孩子用AI做小报告
- 引用了一句"爱因斯坦说：想象力比知识更重要"
- 我去查了——这句话确实是爱因斯坦说的（✓）
- 但他还引用了另一句"牛顿说：站在巨人的肩膀上"的原话
- 实际上牛顿原话不是这样说的，AI编了一个更"好听"的版本

**口播**: 「AI的可怕之处不是它说谎，是它说谎的时候特别自信，你完全分不出来。」

### SLIDE 4 · 什么是AI幻觉（5:00-8:00）
**标题**: AI为什么会"一本正经地胡说八道"？
**要点**:
- AI不是在数据库里找答案，是在"预测下一个最合理的词"
- 它不知道真假，只知道"什么听起来像真的"
- 研究数据：大模型在某些领域幻觉率15-30%
- 越复杂的问题，越容易出错

**口播**: 「你问它1+1等于几，它永远不会错。你问它一个历史细节，它可能给你一个听起来很对但完全编的答案。」

### SLIDE 5 · 这有多危险（8:00-10:00）
**标题**: 孩子信了怎么办？
**三个后果**:
1. 交了错误的作业/报告 → 成绩受影响
2. 养成"不验证"的习惯 → 批判性思维退化
3. 考试中的"信息判断题"也做不好 → 因为从来不判断

### SLIDE 6-8 · 方法1：追问来源（10:00-18:00）

**SLIDE 6**: 标题 — 第1招：追问来源
**内容**:
- Prompt模板：「你说的这个数据/说法，出自哪份报告/哪本书？给我链接或完整出处」
- 3种结果判断：
  - 给出具体出处+可验证 = 可能靠谱 ✓
  - 给出出处但链接打不开 = 可疑 ⚠️
  - 说"根据多项研究"但给不出具体 = 很可能编的 ✗

**SLIDE 7**: 现场演示
- 问AI一个有争议的事实
- 追问来源
- 展示AI的回答（大概率给不出真实来源）

**SLIDE 8**: 互动
- 「现在你们也试试：问AI一个问题，然后追问来源。看它能不能说清楚出处。截图发群。」
- 3分钟等待+挑2个展示

### SLIDE 9-11 · 方法2：交叉验证（18:00-26:00）

**SLIDE 9**: 标题 — 第2招：交叉验证
**内容**:
- 用2个不同的AI问同一个问题
- 如果两个AI说法一致 = 可能靠谱
- 如果两个AI说法不同 = 需要自己再查
- 推荐组合：豆包+DeepSeek / 豆包+Kimi

**SLIDE 10**: 现场演示
- 分屏展示：同一个问题发给豆包和DeepSeek
- 比较两个回答的异同
- 分析：一致的部分可以信，不一致的要警惕

**SLIDE 11**: 互动
- 「你们也试试：同一个问题问两个AI。把两个回答都截图发群，看看差异有多大。」

### SLIDE 12-14 · 方法3：反向测试（26:00-34:00）

**SLIDE 12**: 标题 — 第3招：反向测试
**内容**:
- 把AI给你的答案反过来问它：
- 「有没有与你刚才说法相反的观点或研究？」
- 如果AI说"确实也有"= 说明原来的说法不是定论
- 如果AI说"没有"= 可能靠谱，但也要保持怀疑

**SLIDE 13**: 现场演示
- 先让AI给一个肯定的说法
- 然后问"有没有相反观点"
- 展示AI的"转弯"

**SLIDE 14**: 为什么这一招最厉害
- 因为你不只是在验证信息
- 你在训练孩子"多角度思考"的能力
- 这个能力比任何知识点都值钱

### SLIDE 15 · 3招总结（34:00-36:00）
**标题**: 3招联合使用 = AI信息三重保险
**内容**:
1. 追问来源 → 看它有没有依据
2. 交叉验证 → 看不同AI是否一致
3. 反向测试 → 看结论是否站得住

### SLIDE 5 · 完整工作流（11:00-13:00）
**标题**: AI高效学习4步法
**大字**: ① 诊断 → ② 计划 → ③ 执行 → ④ 复盘

### SLIDE 6-9 · Step 1 诊断（13:00-22:00）

**SLIDE 6**: 标题 — Step 1：用AI找到你的"学习Bug"
**内容**:
- 收集近3个月错题（10-20道）
- 发给AI，用这个Prompt：
```
你是学习诊断专家。请分析以下错题：
1. 找出错误集中的知识点（不超过3个）
2. 分析每个知识点的错误原因
3. 按严重程度排序
不要给我正确答案，只告诉我病根在哪。
```

**SLIDE 7**: 现场演示
- 用准备好的10道真实错题
- 发给AI → 展示分析结果
- 解读：「看，80%的错误集中在2个点上。这就是病根。」

**SLIDE 8**: 为什么传统方法找不到
- 刷100道题 → 80道已经会了 → 浪费80%时间
- AI分析 → 直接找到20%的病根 → 精准打击
- 效率差距：5倍以上

**SLIDE 9**: 互动
- 「你们之前做过作业的家长，现在把孩子的错题发给AI试试。看看AI找出来的'病根'跟你以为的一样吗？」

### SLIDE 10-11 · Step 2 计划（22:00-28:00）

**SLIDE 10**: 标题 — Step 2：让AI做一份精准攻坚计划
**Prompt模板**:
```
我的孩子X年级，数学薄弱点是[分数混合运算]和[方程移项]。
请制定一份2周攻坚计划：
- 每天不超过20分钟
- 从最基础的开始，逐步加难度
- 每3天安排一次自测
- 给出每天具体做什么（不是笼统的"练习"）
```

**SLIDE 11**: 演示AI给出的计划
- 展示一份2周逐日计划
- 强调：「每天20分钟，不是2小时。精准比猛攻有效100倍。」

### SLIDE 12-13 · Step 3 执行（28:00-34:00）

**SLIDE 12**: 标题 — Step 3：AI当你的私人教练
**内容**:
- 执行计划时遇到不会的 → 用苏格拉底式AI对话
- 不搜答案，让AI引导你想
- 用第1节课学的公式：身份+任务+要求+例子
- 每天20分钟，严格不超时（超时=低效的信号）

**SLIDE 13**: 演示一次AI引导式学习
- 模拟一个孩子在做分数题卡住
- AI不给答案，追问引导
- 孩子自己想通
- 「看，从头到尾AI没告诉他答案，但他自己做出来了。」

### SLIDE 14-15 · Step 4 复盘（34:00-38:00）

**SLIDE 14**: 标题 — Step 4：2周后验证效果
**内容**:
- 2周后再做一套同类型的题
- 对比正确率变化
- 如果提升 → 进入下一个薄弱点
- 如果没提升 → 调整计划（可能诊断不准，重新分析）

**SLIDE 15**: 真实案例
- 初一，数学70→85，2周，每天20分钟
- 关键：不是更努力，是找对了病根
