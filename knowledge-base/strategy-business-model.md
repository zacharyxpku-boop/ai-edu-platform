## 四、单位经济学（Unit Economics）

### 获客成本（CAC）

| 渠道 | CAC预估 | 占比 |
|------|---------|------|
| 小红书自然内容 | ¥0（时间成本） | 40% |
| 朋友圈口碑 | ¥0 | 25% |
| 速成班转化 | ¥298（速成班本身就是付费获客） | 20% |
| 老带新 | ¥300（双方各减¥150） | 15% |
| **加权平均CAC** | **¥90** | |

### 用户终身价值（LTV）

| 用户类型 | 年付费 | 留存年限 | LTV |
|----------|--------|---------|-----|
| 纯工具用户 | ¥288-498 | 2年 | ¥576-996 |
| 课程用户 | ¥2,980+¥288 | 2年 | ¥6,536 |
| 全栈用户(工具+课程+社群) | ¥2,980+¥498+¥999 | 3年 | ¥13,431 |

### LTV/CAC比率

| 场景 | LTV/CAC |
|------|---------|
| 最差（纯工具） | 576/90 = **6.4x** |
| 中等（课程用户） | 6,536/90 = **72x** |
| 最好（全栈用户） | 13,431/90 = **149x** |

**任何LTV/CAC > 3x的生意都值得做。原点最差情况也有6.4x。**

## 五、增长飞轮（三轮驱动）

### 飞轮1：内容→信任→转化

```
原点智父发内容
  → 家长关注/加私域
    → 参加免费公开课
      → 试用AI学伴(免费版)
        → 报名速成班(¥298)
          → 体验够好 → 报名成长课(¥2,980)
```

**关键指标：** 每月新增200私域 → 10%试用AI学伴 → 5%报速成班 → 30%转成长课

### 飞轮2：产出→分享→获客

```
孩子用AI做出作品
  → AI学伴自动生成分享卡片
    → 家长发朋友圈
      → 朋友圈好友看到 → 扫码试用AI学伴
        → 新用户进入飞轮1
```

**关键指标：** 每月产出100份作品 → 60%家长分享 → 每条触达200人 → 1%转化 = 120新用户

### 飞轮3：数据→精准→留存

```
用户使用AI学伴
  → 积累学习行为数据
    → AI推荐越来越精准
      → 用户学习效果提升
        → 续费率提升
          → LTV增长
            → 可以承受更高CAC → 投入更多获客
```

**关键指标：** 使用3个月后续费率 > 60%

## 六、定价心理学

### 价格锚定策略

| 接触顺序 | 产品 | 价格 | 心理效果 |
|---------|------|------|---------|
| 1 | AI学伴免费版 | ¥0 | "免费就这么好用？" |
| 2 | AI学伴成长版 | ¥38/月 | "每天1块钱，值" |
| 3 | 速成班 | ¥298 | "3节课298，每节不到100" |
| 4 | 智元成长课 | ¥2,980 | "8周课，每周不到400" |
| 5 | 清北伴学 | ¥250/h | "清北学长1对1，市面上至少400" |

**逐级升价，每级都有"比市面便宜"的感知：**
- AI学伴¥38/月 vs 讯飞学习机¥3,199-11,699买断
- 成长课¥2,980 vs 学而思线下班¥5,000-8,000
- 清北伴学¥250/h vs 市面清北辅导¥400-600/h

### 退款保障（信任杠杆）

| 产品 | 退款政策 | 竞品对比 |
|------|---------|---------|
| AI学伴 | 7天无理由退款 | 豆包免费无退 |
| 速成班 | 第1节课后不满意全退 | 文韬无退款 |
| 成长课 | 前4周(4节课)不满意全退 | 学而思线下班退款困难 |
| 清北伴学 | 首次试听免费 | 市面同行无 |

**退款是最便宜的信任建设工具。** 文韬没有退款承诺，这是原点的差异化武器。

## 七、成本控制（一人企业原则）

### 不花钱的事

| 项目 | 替代方案 | 节省 |
|------|---------|------|
| 办公室 | 无（远程协作） | ¥5,000/月 |
| 全职员工 | 三人分成制（赚钱才分） | ¥30,000/月 |
| 广告投放 | 内容获客（自然流量） | ¥10,000/月 |
| 课程平台 | 腾讯会议直播+小鹅通录播 | ¥3,000/月 |
| 设计师 | AI生成+Canva | ¥5,000/月 |
| 客服 | AI学伴内置FAQ+创始人亲回 | ¥3,000/月 |

**月固定成本 < ¥6,000（API+服务器）。** 这意味着月收入超过¥6,000就能活。

### 花钱的时机（什么时候开始投入）

| 月收入 | 动作 |
|--------|------|
| ¥0-10K | 纯内容获客，不花一分钱推广 |
| ¥10-30K | 开始投小红书薯条推广（¥1,000/月） |
| ¥30-60K | 考虑招1名兼职运营（¥3,000/月） |
| ¥60K+ | 开始投信息流广告（ROI>3x才投） |

## 八、风险模型

### 最差情况（Downside）

假设只有速成班和社群能跑通，AI学伴和成长课延迟：
- 速成班6期×25人×¥298 = ¥44,700
- 社群150人×¥199/季 = ¥119,400
- 清北伴学400h×¥250 = ¥100,000（毛利¥40,000）
- **最差年收入 ≈ ¥204,100，毛利 ≈ ¥200,000**
- 足够3人团队的基本生存

### 基准情况（Base Case）

上述财务模型：**年收入¥747K，毛利¥577K**

### 最好情况（Upside）

AI学伴病毒式传播（小程序裂变），用户量达到3,000：
- 工具订阅: 3,000×¥288 = ¥864,000
- 课程转化率更高: ¥400,000+
- **最好年收入 ≈ ¥1.5M+**
