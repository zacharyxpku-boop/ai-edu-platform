## 每周监控流程（30分钟·周五下午）

### Step 1: 刷竞品内容（15分钟）
```
打开以下页面：
1. 视频号搜索"文韬" → 看最新3条视频标题/主题
2. 小红书搜索"AI教育" → 看热门帖/新品牌
3. 豆包爱学App → 看有没有更新/新功能
4. App Store搜"AI学习" → 看排名变化
```

### Step 2: 记录发现（10分钟）
```
在群里发一条竞品周报：

【竞品周报 · X月X日】

文韬：[本周动态，没有就写"无动态"]
豆包：[本周动态]
学而思：[本周动态]
其他：[值得注意的新玩家/新趋势]

对我们的影响：[有/无，如果有说明什么]
我们该做什么：[具体动作或"继续按计划推进"]
```

### Step 3: 判断是否需要应对（5分钟）

| 情况 | 应对 |
|------|------|
| 竞品出了类似产品 | 不慌，加速自己的节奏 |
| 竞品降价了 | 不跟降，用品质差异化竞争 |
| 竞品出了我们没有的功能 | 评估是否值得加，不盲目跟风 |
| 竞品出了重大负面 | 关注但不攻击，做好自己 |
| 出现了新玩家 | 快速研究定位/差异，1页分析 |
