# 原点智学 · 学员案例收集与展示模板
> 案例是最强的招生武器
> 每个结课学员都要收集一份

---

## 一、案例收集流程

### 什么时候收集
- 速成班：第3节课后当天
- 成长课：Demo Day当天 + 结课后7天
- 清北伴学：每10次课后

### 怎么收集
1. 发问卷（5个问题，3分钟填完）
2. 选3-5个最好的案例做电话采访（10分钟）
3. 整理成标准化案例卡片

### 家长授权话术
```
XX妈妈，你家[孩子名字]这次表现特别好！
我们想把他/她的成长经历整理成一个案例，
帮助更多家庭了解这种学习方式。

内容会隐去真实姓名（用昵称），不暴露隐私。
你觉得可以吗？

如果可以的话，我想花10分钟跟你聊一下，
主要问3个问题：
1. 孩子学之前是什么状态
2. 学了之后最大的变化
3. 你会怎么跟朋友介绍
```

## 二、案例收集问卷（发给家长）

```
【原点智学·学员反馈】3分钟填写

1. 孩子年龄/年级：_________

2. 学之前最困扰你的问题是什么？（选1-2个）
   □ 学习效率低
   □ 不会用AI / 乱用AI
   □ 成绩提不上去
   □ 不爱学习 / 没动力
   □ 不会独立思考
   □ 其他：_________

3. 学完之后最大的变化是什么？（用你自己的话说）
   _____________________________________________

4. 如果用一句话告诉朋友这个课怎么样，你会说什么？
   _____________________________________________

5. 满意度打分（1-10）：___

6. 你愿意参与我们的案例采访吗？（10分钟电话）
   □ 愿意（我的方便时间：_____）
   □ 不方便
```

## 三、电话采访提纲（10分钟）

```
开场：
"XX妈妈你好！感谢你愿意花10分钟聊一下。
我主要想了解[孩子名字]的变化，帮助更多家庭。"

Q1: 当初为什么想让孩子学这个？（挖痛点）
   - 追问：具体是什么事让你觉得"不能再这样了"？

Q2: 学的过程中，有没有一个让你印象最深的瞬间？（挖故事）
   - 追问：孩子当时的表情/说的话？你的感受？

Q3: 现在跟学之前比，最明显的变化是什么？（挖效果）
   - 追问：有没有具体的例子？（成绩/习惯/态度）

Q4: 你觉得这种方式跟补习班有什么不同？（挖差异化）

Q5: 如果你的闺蜜问你"值不值"，你怎么说？（挖金句）

结束：
"非常感谢！我把内容整理好发给你确认，
没问题的话我们会用在招生材料里。
孩子的真名会换成昵称，完全保护隐私。"
```

## 四、案例卡片标准格式

### 小红书/朋友圈版（短）

```
【孩子昵称】XX岁 · [城市] · [学的什么产品]

学之前：[一句话痛点]
学之后：[一句话变化]

家长原话：
"[最打动人的那句真实评价]"

——————
[如果有成绩变化就写]
数学：70→85分（2周）
```

### 公众号/官网版（长，500字）

```
# [标题：孩子昵称的故事]

## 学之前
[2-3句描述孩子当时的状态和家长的焦虑]

## 转折点
[什么时候/为什么报名，最初的顾虑]

## 学习过程
[1-2个具体的学习瞬间，越具体越好]

## 变化
[可量化的变化：成绩/习惯/态度/作品]

## 家长说
"[原话引用，不修改]"

## 孩子说
"[如果有孩子的话也引用]"
```

## 五、案例积累目标

| 时间 | 目标案例数 | 来源 |
|------|----------|------|
| Phase 0 (M1-2) | 5个 | 速成班首期学员 |
| Phase 1 (M3-4) | 15个 | 速成班2-3期 + 社群 |
| Phase 2 (M5-8) | 50个 | 成长课首期 + 伴学 |
| M12 | 100个 | 全产品线 |

**案例数量是品牌信任的基石。100个真实案例 > 1亿广告费。**

---

## 六、案例使用规范

1. **真实优先** — 绝不编造、夸大、拼接案例
2. **隐私保护** — 用昵称，不暴露全名/学校/照片（除非家长明确同意）
3. **家长确认** — 整理好的案例必须发给家长确认后才能使用
4. **多场景复用** — 一个好案例在小红书/朋友圈/官网/群里分别发不同版本
5. **持续更新** — 每月至少新增3个案例，保持"活的"品牌感
