# 原点AI学伴 · 微信小程序审核准备清单
> 提交审核前必须全部通过，否则100%被拒

---

## 一、账号准备

- [ ] 微信公众平台注册小程序账号（主体：企业/个体工商户）
- [ ] 选择类目：**教育 → 在线教育**（需要提供教育相关资质）
- [ ] 如无资质，可选：**工具 → 效率工具**（风险：可能被要求补充教育资质）
- [ ] 完成微信认证（¥300/年）
- [ ] 配置服务器域名（request合法域名）
  - DeepSeek API域名：api.deepseek.com
  - Qwen API域名：dashscope.aliyuncs.com
  - Supabase域名：[你的项目].supabase.co
- [ ] 配置业务域名（web-view使用的域名）

## 二、功能合规

### 必须有
- [ ] 用户协议/服务条款（底部链接或弹窗）
- [ ] 隐私政策（底部链接或弹窗，首次使用必须同意）
- [ ] "关于我们"页面（公司/团队简介）
- [ ] 投诉/反馈入口

### 必须没有
- [ ] 不能有虚拟支付（iOS限制）— 如需付费走微信支付
- [ ] 不能有诱导分享（"分享到群解锁"这类）
- [ ] 不能有诱导关注公众号（不能强制关注才能用）
- [ ] 不能有竞品品牌名（不要在文案里写"豆包""学而思"）
- [ ] 不能有绝对化用语（"最好""第一""保证提分"）

### AI相关
- [ ] AI生成内容标注（"由AI辅助生成"字样）
- [ ] AI对话不涉及政治敏感/违法内容
- [ ] 内容安全接口对接（微信 msgSecCheck API）
- [ ] 图片安全检测（如有图片上传功能）

## 三、类目资质

### 教育→在线教育 需要的材料
| 材料 | 说明 |
|------|------|
| ICP备案截图 | 域名已备案 |
| 营业执照 | 经营范围含教育/咨询/培训 |
| 在线教育许可证 | 部分地区要求（可先用工具类目上线） |

### 退而求其次：工具→效率工具
- 只需要营业执照
- 但功能描述不能包含"课程""教学"等教育关键词
- 建议：先用工具类目上线MVP，后续补充教育资质再切换

## 四、审核易踩的坑

| 坑 | 怎么避 |
|---|--------|
| "小程序功能不完整" | MVP也要有完整闭环：注册→使用→反馈，不能有"敬请期待"的空页面 |
| "收集用户信息未说明用途" | 每个信息收集点旁边标注"用于XX" |
| "存在虚拟支付" | iOS端不能有任何充值/购买按钮，付费用安卓端或引导到公众号 |
| "页面加载空白" | 加骨架屏/loading动画，不能白屏超过3秒 |
| "存在第三方跳转" | 不能跳转到外部网页（除非配置了业务域名） |
| "涉及用户生成内容" | 如果用户能发布内容，需要内容审核机制 |

## 五、提审前自检流程

```
Step 1: 功能自测
  [ ] 所有页面能正常打开，无白屏
  [ ] 注册→使用→退出全流程走通
  [ ] AI对话能正常收发
  [ ] 支付流程正常（安卓端）
  [ ] 分享功能正常

Step 2: 合规自测
  [ ] 隐私政策弹窗正常
  [ ] 用户协议可查看
  [ ] 无竞品品牌名
  [ ] 无绝对化用语
  [ ] AI标注到位

Step 3: 体验自测
  [ ] 首屏加载<3秒
  [ ] 无明显卡顿
  [ ] 各机型适配正常（iPhone/Android各测1台）

Step 4: 提交审核
  [ ] 填写版本说明（描述本次更新内容）
  [ ] 上传截图（5张核心页面截图）
  [ ] 选择审核加急（如需要）
  [ ] 预计审核时间：1-7个工作日
```

## 六、被拒后怎么办

1. 看清拒绝原因（审核结果页会说明）
2. 针对性修改（不要改其他东西，只改被拒的点）
3. 重新提审时在版本说明里写明"已修改XX问题"
4. 通常二审会快一些（1-3个工作日）
5. 如果连续被拒3次 → 联系微信开放平台客服沟通
