Lobster AI Teacher

配置到家长已经在用的设备和工作群里

龙虾不是孤立网页。当前优先跑通官网配置、飞书机器人、钉钉机器人三个闭环；微信只走后续官方适配，不做个人号外挂。

1. 官网配置

家长填写孩子年级、学科、成绩、错题和今晚真实卡点。

2. 群内对话

飞书/钉钉机器人接收材料，转给龙虾生成回复。

3. 主动跟进

系统生成今晚、明天、周末的回访计划和家长报告。

配置一个 AI 教师

官网 / Web

已可用

最适合第一个家庭闭环。家长打开网页配置，孩子在家长设备上共屏使用。

飞书机器人

优先打通

适合老师、机构、运营群。家长或老师发成绩和观察，机器人返回报告和今晚动作。

钉钉机器人

优先打通

适合学校、班级和机构。通过官方应用机器人接收消息和推送跟进。

微信

后续官方适配

只走公众号、小程序客服、订阅消息或企业微信，不做个人微信外挂机器人。

飞书/钉钉怎么接

Webhook 收消息

平台事件进入 /api/lobster-message?mode=channel&channel=feishu 或 channel=dingtalk。

Send API 发计划

/api/lobster-message?mode=channel&action=send_plan 生成官方发送请求。缺 token 时只返回配置提示，不假装发送。

安全边界

  • 孩子不需要独立账号，优先在家长设备上共屏使用。
  • 不存平台用户 ID 原文。
  • 不保存孩子原始对话。
  • 孩子模式不直接给最终答案。
  • 微信、QQ、小天才只做官方适配。
