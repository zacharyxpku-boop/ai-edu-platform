场景一 · 错题分析

孩子做错题了，怎么让AI帮忙分析？

关键：不要让AI直接给答案，要让AI分析错因并引导孩子自己想出来。

我的孩子读[年级]，这道[科目]题做错了： [把题目粘贴在这里] 孩子的错误答案是：[填写] 请你： 1. 分析他可能是哪个知识点没理解透 2. 不要直接给正确答案 3. 用追问的方式引导他自己想出来 4. 最后出2道类似的练习题让他巩固
适用年龄：6-16岁 · 关键词：「不要直接给答案」「追问引导」

场景二 · 学习计划

怎么让AI帮孩子做一个靠谱的学习计划？

关键：给够具体信息，AI才能给出个性化方案。

我的孩子读[年级]，[科目]成绩在班级大概[排名/水平]。 主要薄弱点是：[具体描述，比如"分数运算容易出错""阅读理解总是抓不住重点"] 请帮我制定一个为期4周的提升计划： - 每天学习时间不超过30分钟 - 重点攻克上面说的薄弱点 - 每周有一个小测试检验效果 - 用大白话写，孩子能看懂
适用年龄：8-16岁 · 关键词：「每天不超过30分钟」让计划可执行

场景三 · 作文辅导

孩子写了作文，怎么让AI辅导而不是代写？

关键：明确告诉AI「不要重写」，只给修改建议。

我的孩子读[年级]，写了一篇[题材]作文，题目是"[题目]"。 以下是孩子写的原文： [把作文粘贴在这里] 请你： 1. 不要帮他重写，保留他的原始表达 2. 指出3个最值得改进的地方 3. 每个地方给一个具体的修改建议（告诉他怎么改，但不要直接改） 4. 最后用一句话肯定他写得好的地方
适用年龄：8-16岁 · 关键词：「不要重写」「保留原始表达」防止AI代写
豆包DeepSeekKimi
场景四 · 英语口语

怎么让AI当孩子的英语对话伙伴？

关键：设定难度等级，让AI自动调整用词。

请用简单的英语和我的孩子练习口语对话。 孩子的情况：读[年级]，英语水平[初级/中级/较好] 今天的话题：[比如：去超市买东西 / 介绍自己的家人 / 最喜欢的动物] 规则： 1. 你先开始对话，每次说1-2句就好 2. 用孩子能理解的简单词汇 3. 如果孩子说错了，温和地纠正并给出正确说法 4. 每3轮对话后，总结一下孩子学到的新表达 5. 全程鼓励为主
适用年龄：6-16岁 · 提示：可以让孩子用语音输入（豆包支持语音对话）
豆包（推荐，支持语音）KimiChatGPT
场景五 · 兴趣探索

孩子对某个东西感兴趣，怎么用AI深入探索？

关键：把兴趣变成一个小项目，让孩子边玩边学。

我的孩子[年龄]岁，对[兴趣方向]很感兴趣。 请设计3个用AI辅助的小项目，要求： 1. 每个项目1-2小时能完成 2. 有明确的产出（比如一份报告、一幅画、一个小故事） 3. 过程中孩子是主导者，AI是助手 4. 难度适合[年龄]岁孩子 5. 用到的AI工具最好是免费的 每个项目请列出：名称、需要的工具、具体步骤、预期产出。
适用年龄：6-16岁 · 产出示例：恐龙研究小报告、城市观察手记、AI插画绘本

3个提高AI回答质量的小技巧

1. 给够背景信息

"我孩子初二，数学一般，分数运算总出错"比"帮我辅导数学"好10倍。AI了解得越多，回答越精准。

2. 明确说"不要做什么"

"不要直接给答案""不要帮他重写"——这些「禁令」比「请引导他思考」更有效。AI默认会给完整答案，你要主动拦住它。

3. 让AI交叉验证自己

如果不确定AI说的对不对，试试问它："你确定吗？请再检查一遍，特别是[你怀疑的部分]。"AI会自我纠正很多错误。
