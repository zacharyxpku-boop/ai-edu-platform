## 二、8 项合规风险点 · 当前状态 · 修补

### 风险 1 · 未成年人个人信息收集无监护人同意 · **P0**

**风险描述：** PIPL 第 31 条 + 未成年人网络保护条例第 31 条：处理 14 周岁以下未成年人个人信息**必须**取得其监护人同意。

**当前状态：** `welcome.html` 直接收集姓名、年级，无任何同意条款，无监护人同意流程。30 秒注册流走完直接进对话。

**修补动作：**
1. `welcome.html` 提交前强制勾选两项 checkbox：
   - "我已阅读并同意《服务协议》和《隐私政策》"（必勾）
   - "我已获得家长 / 监护人同意"（< 14 岁必勾，PoC 期一律强制）
2. 新增 `/terms` `/privacy` 占位页（指向 docs/TERMS-OF-SERVICE.md / PRIVACY-POLICY.md）
3. 后端 `/api/student-init` 收 `consent_v1` 字段，写入 students 表元数据

**工作量：** 2 小时（前端 1h + 文档 1h）

---

### 风险 2 · AI 生成内容未标识 · **P0**

**风险描述：** 《生成式 AI 服务管理暂行办法》第 12 条：服务提供者应当对图片、视频等生成内容进行标识。文本类目前监管口径偏宽，但《深度合成规定》第 16-17 条要求"显著标识"。教育场景 + 未成年人，监管会从严解释。

**当前状态：** `tutor.html` 蓝色"原"头像气泡是 AI 输出，但没有任何"AI 生成"标识。学生可能误以为是真人。

**修补动作：**
1. tutor 气泡（AI 输出）右下角加"AI 生成"灰色 ≤8px 字
2. v3 prompt 元规则段加 AI 边界明示话术（学生问"你是真人吗"必须答"我是 AI"）
3. 首次访问 onboarding 已有"我是原小点 AI 学习管家"，保留并加粗

**工作量：** 1 小时

---

### 风险 3 · 心理热线话术无免责声明 · **P0**

**风险描述：** AI 不是持证心理咨询师。T6 危机分支直接给热线电话，但若学生认为"AI 帮我处理了"而未拨打专业热线导致严重后果，平台承担相当法律责任。

**当前状态：** `api/escalate.js` T6 分支返回话术："先停。你说的这件事比作业重要太多。我让平台老师 5 分钟内联系你和爸妈，同时给你这个能立刻打的电话：北京心理援助热线 010-82951332。" 没有声明"我是 AI 不是专业咨询师"。

**修补动作：** 改写 `kindMessage.crisis` 加入：
> "我是 AI 不是专业心理咨询师。这个电话是公益资源，他们能帮你。同时我会让平台的真人老师立刻联系你和你爸妈。"

**工作量：** 5 分钟

---

### 风险 4 · 用户数据导出权未实现 · **P0**

**风险描述：** PIPL 第 45 条：个人有权查阅、复制其个人信息；处理者应当及时提供。无导出端点 = 直接违反。

**当前状态：** 无 `/api/student-data-export` 端点。学生 / 家长无法导出自己的数据。

**修补动作：** 新建 `api/student-data-export.js`：
- GET `?student_id=<uuid>&token=<auth_token>`
- 返回 JSON 包：students / dialogues / attempts / escalations / student_states / parent_pushes / moderation_logs（敏感字段脱敏）
- 速率限制：单 student_id 每 24h 5 次
- 写审计日志

**工作量：** 3 小时

---

### 风险 5 · 数据保留期限未设定 · **P0**

**风险描述：** PIPL 第 19 条：个人信息保存期限应当为实现处理目的所必要的最短时间；法律法规另有规定除外。

**当前状态：** students 表无 `expires_at` 字段，无自动清理机制。学生注册后数据永久保留 = 不合规。

**修补动作：** `db/migrations/0011_data_retention.sql`：
- 加 `students.expires_at` 字段（默认 created_at + 3 年）
- 加 `cleanup_expired_data()` 函数：到期把姓名 hash 化（不真删，保学习轨迹聚合统计）
- pg_cron 或外部 cron 每周触发一次

**工作量：** 2 小时

---

### 风险 6 · 数据跨境传输未告知 · **P0**

**风险描述：** PIPL 第 38-40 条：境外接收方处理个人信息，需要单独同意 + 标准合同 / 安全评估 / 认证。Supabase 服务器在境外（AWS us-west-2 / Singapore）。

**当前状态：** 学生数据存 Supabase（境外）。隐私政策无说明，无单独同意，无标准合同。

**修补动作：**
1. 隐私政策明示"数据存储于境外（Supabase / AWS）"
2. 隐私政策给本地化路线图："2026 Q3 完成境内化迁移"
3. PoC 期通过单独同意 + 最小化收集（不收手机、邮箱、住址、生日）走豁免路径
4. 长期解决：迁移至腾讯云 / 阿里云国内 region 的 Postgres + Storage

**工作量：** 1 小时（文档）+ 长期 1 个月（迁移）

---

### 风险 7 · 防沉迷机制缺失 · **P1**

**风险描述：** 未成年人网络保护条例第 41-43 条：网络服务提供者应建立健全防沉迷制度。算法推荐管理规定第 8 条：未成年人模式。

**当前状态：** prompt 里有"20-30 分钟节奏控制""疲态信号识别"软约束，但无硬性时长限制、无未成年人模式开关、无家长可见的使用时长报告。

**修补动作（v2 阶段，本 batch 不修）：**
- 单日累计 60 分钟 → 弹窗提示
- 单日累计 90 分钟 → 强制中断 30 分钟
- 22:00 后弹窗"今天到这"
- 家长面板加"本周使用时长"模块

**工作量：** 1 周（v2 阶段）

---

### 风险 8 · 广告法 + 双减红线 · **P1**

**风险描述：** 广告法第 24 条：教育、培训广告不得对效果作明示或暗示保证；双减政策严禁面向 K9 学科类广告。

**当前状态：** 落地页文案需逐句过审。"AI 私教""提分""4 周提升 0.5 SD"等措辞踩双减红线风险。

**修补动作（运营层面）：**
- 落地页禁用："提分""保过""1 对 1 名师""AI 智能"模糊话术
- 改用："学习管家""陪伴诊断""家长简报"
- "Khanmigo 0.23 SD 一倍"这类对内 OKR 不上落地页
- B 端 / 营销素材单独过法务审核

**工作量：** 持续运营管控

## 三、学生数据流地图

```
┌─────────────┐
│   学生端    │ welcome.html 输入: name, grade
│  浏览器     │ ⚠️ PII: name 是个人信息
└──────┬──────┘
       │ HTTPS
       ▼
┌─────────────────────────────────────────────┐
│  Vercel Edge Function (中国境外)             │
│  /api/student-init  → 生成 student_id (uuid)  │
│  /api/tutor-chat    → 拉 dossier + 调 LLM    │
│  /api/escalate      → T1-T7 分诊            │
└──────┬─────────────────┬────────────────────┘
       │                 │
       │ ⚠️ 跨境点 1     │ ⚠️ 跨境点 2
       ▼                 ▼
┌─────────────┐   ┌──────────────┐
│  DeepSeek   │   │  Supabase    │
│  (国内 API) │   │  (境外存储)  │
│  推理无落库 │   │  全部学生数据│
└─────────────┘   └──────┬───────┘
                         │
                ┌────────┼────────┐
                ▼        ▼        ▼
            students  dialogues  attempts
            (PII)    (对话原文) (作答记录)
            ⚠️ 30 天 ⚠️ 加密?  ⚠️ 含错题
                         │
                         ▼
                  ┌──────────────┐
                  │ 学长 / 家长面板 │
                  │ 结构化档案     │
                  │ 不见原文       │
                  └──────────────┘

PII 字段清单：
  students.name                      （直接标识）
  students.grade                     （准标识）
  dialogues.user_message             （对话原文，可能含家庭信息）
  dialogues.tutor_message            （AI 回复）
  attempts.answer_text               （学生作答）
  escalations.student_message        （求助原文）
  moderation_logs.content_excerpt    （审核片段）
```

**跨境点风险：**
- 跨境点 1（Vercel）：Edge Function 在境外，但仅为路由，无落库，**风险低**
- 跨境点 2（Supabase）：所有 PII 存境外 Postgres，**风险高 → 必须明示 + 单独同意 + 长期境内化**

## 五、5.4 demo 不能演示的 3 件

1. **不演示数据导出 API 调用**（PoC 期数据样本少，调出来反而暴露 PII；让评委信，不让评委看原始数据）
2. **不演示 T6 危机话术**（孩子在场情况下演示自伤场景不合适；录视频代替）
3. **不出现"提分"、"保过"、"1 对 1 名师"字样**（双减红线，万一现场被拍下来传到监管渠道直接吃罚单）

**可演示的安全样本：**
- 学生 onboarding（含同意条款）
- 普通讲题对话
- 学长转交（T1 概念档）
- 家长简报生成
- AI 边界自陈（学生问"你是真人吗"，AI 回答"我是 AI 原小点"）
