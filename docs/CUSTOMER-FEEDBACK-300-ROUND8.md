# 300 用户截图反馈第八轮

## 结论

本轮真实查看移动端 PNG 后，用户批评成立：上一版页面像同一个深绿模板换文案，不像 Gizmo、Khanmigo、StudyX 这类头部产品各自有清楚的交互形态。

## 300 个学生/家长会怎么说

1. 学生愿意点“开始”，但不愿意先理解一个复杂系统。
2. 学习包最有吸引力，但必须像 StudyX 一样一眼看到“粘贴就生成”。
3. 复习页只有做成卡片闯关，才会接近 Gizmo 的打开动机。
4. 原小点需要像 Khanmigo 一样保护思考，而不是像普通聊天机器人。
5. 家长页不能把雷达图当主角，主角应该是今晚先做什么和验收什么。

## 本轮修正

1. 截图审计工具改为 7 个页面 7 种结构，不再共用深绿 hero。
2. Home 改成浅色任务卡和玩具感今日任务。
3. Tools 改成输入工厂视觉，强化粘贴材料生成学习包。
4. Review 改成深蓝紫 quiz/flashcard 闯关感。
5. Tutor 改成聊天气泡和第一步追问感。
6. Radar/Profile 保留成人信任感，但减少“后台驾驶舱”气质。
