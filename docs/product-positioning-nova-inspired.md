# 原点老师团产品包装说明

## 一句话定位

学校给全班同一份任务，原点老师团给每个孩子一条自己的晚间学习路线；孩子今天选择谁，谁就陪他把这条路线走完。

## 我们参考的不是功能形态

Nova 给我们的启发不是“做几个功能老师”，而是角色化、陪伴感、系统感和长期记忆感。

原点智学的形态不是：

- 作业点拨 = 小原
- 错题闭环 = 问问
- 知识游乐场 = 阿衡
- 我的 = 团团

原点智学的形态是：

孩子今天选择谁，谁就陪孩子走完整 Tonight Route。

## Tonight Route

共同路线：

排顺序 -> 说第一步 -> 修卡点 -> 轻回访 -> 整理给家长看

每位老师都能完成：

- 帮孩子排今晚路线。
- 引导孩子说第一步。
- 修一个关键卡点。
- 生成回访卡。
- 做轻量回访。
- 把今天学了什么整理给家长看。

## 六位老师的陪伴方式

- 小原：帮孩子理顺，把乱糟糟的作业排成一条能走下去的路线。
- 问问：陪孩子多想一步，不急着讲结果，先问第一步。
- 安安：让孩子别慌，把任务变小一点，先稳住。
- 阿衡：记得孩子以前卡在哪，让下一次路线更懂他。
- 团团：帮孩子把学习过程讲给家长听，不是告状。
- 跃跃：把回访变成一小关，不刷题，不冲榜。

老师之间不是功能分工，也不是学科分工，而是人设、语气、陪伴方式、情绪质感不同。

## 成长记忆

成长记忆不是阿衡专属功能。所有老师都能使用成长记忆，只是表达方式不同。

产品只记录学习闭环需要的信息：今晚路线、卡点、回访卡和学习小结。它的作用不是做复杂报告，而是让孩子和家长感受到：

这一次卡在哪里，下一次路线会更懂我。

## 家长版说明

这不是拍题搜答案工具，也不是补课课表。它帮孩子把今晚学校任务排顺序；孩子卡住时，老师先让孩子说第一步；修过的卡点会变成轻回访；最后整理成家长 5 秒能看懂的小结。

家长看到的不是一份压缩报告，而是三件事：

- 今晚先帮什么。
- 孩子卡在哪里。
- 家长只问哪一句。

## 孩子版说明

今天可以选一个老师陪你。不会也可以先说一句，不用一次做完所有题。

你可以选：

- 温和一点。
- 多问一步。
- 慢一点。
- 记得你以前的卡点。
- 帮你讲给家长听。
- 陪你闯一小关。

老师会陪你排顺序、说第一步、修一个卡点、轻轻回访，再把今天学了什么整理给家长。

## 包装禁区

不要使用：

- AI 解题老师
- 秒解
- 拍照出答案
- 学科名师
- 清北老师
- 状元老师
- 完全自由定制角色
- 游戏陪聊

也不要把老师写成数学老师、英语老师、语文老师或科学老师。学科能力在后台，前台是陪伴方式。

## 已知限制

- 不支持拍照识别。
- 不支持 OCR。
- 不支持 PDF / PPT / Anki / Quizlet 导入。
- 不直接给答案。
- 不替孩子写作业。
- 不替代学校和老师。
- 老师团不是完全自由角色扮演。
- 当前仍需真实 AppID 和人工真机验收。
