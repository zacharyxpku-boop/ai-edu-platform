# 应试 AI 私教 · 90 天作战图 v1

> 出品：万象阁阁主｜决策人：Zack｜锁定时间：2026-04-25｜适用周期：W1（5/5 起算）—— W12（7/27）

---

## 0. 战略锚点

- **产品定位（一句话）**：一个能把高考真题讲到学生听懂为止的 AI 私教，针对 9-12 年级，单点突破数学。
- **差异化（一句话）**：别人卖 AI 陪聊，我们卖「替代讲题人」——基于 GAOKAO-Bench 真题底库 + Qwen3-Math/Confucius3-Math 双 math 模型路由 + ProcessBench 思维链审错，每一步推导都对得起家长的钱。
- **北极星指标**：**单知识点掌握度提升幅度（前测→后测，n≥30 学员，4 周窗口）**。一切功能、内容、营销围绕这一个数推进，掉了就停下。
- **不做什么（同等重要）**：不做陪聊，不做兴趣启蒙，不做艺术/英语口语，不自研模型，不做线下营（那是五一营的事），不做家长自学 Prompt 课。

> 校准：此前在 parent_feedback_v2 看到「Prompt 模板/防投毒/专注力」是 P1 痛点。这些是**老用户加购**的钩子，不是 90 天 PoC 的目标。90 天只解决「替代讲题人」一件事。

## 1. 三阶段路线图

### W1-W4 · PoC 阶段：单知识点闭环 + 5 学员内测

目标：把「学生拍一道题 → AI 出讲解 → 学生复述 → AI 判定掌握 → 推下一题」的回路打通，仅覆盖一个知识点（**高一函数·二次函数最值**），跑通即可。

| 周 | 关键交付 | 谁 | 验收 |
|---|---|---|---|
| W1 | 题库切片：从 GAOKAO-Bench 抽 2010-2024 二次函数题 200 道 + ChinaTextbook 人教 A 版必修一第三章原文切章节 | Zac | JSON 格式落库，每题带知识点 tag + 难度 + 标准答案 |
| W1 | 模型路由 v0：DeepSeek-Chat（讲解）+ Qwen3-Math（解题验算）+ Confucius3-Math（K12 语境）三档，前端走后端 `/api/tutor` | Zac | 单题响应 P95 ≤ 8s，三模型自动 fallback |
| W2 | OATutor 的 hint 系统迁移 + EduChat 的对话框架剥壳 | Zac | 至少能给 3 级 hint：方向 → 步骤 → 答案 |
| W2 | SocraTeach 的费曼追问模板汉化 | Wzq | 5 套模板：定义复述 / 步骤复述 / 反例追问 / 变式追问 / 错题归因 |
| W3 | EduCDM 学生建模 v0：用 IRT-2PL 对 5 学员做能力点估值 | Zac | 每题作答后能力值更新 |
| W3 | ProcessBench 错步检测接入：学生写过程被判错时定位到哪一步错 | Zac | 在 50 道历史错题上人工抽检，错步定位准确率 ≥ 70% |
| W4 | 闭环 5 学员 · 4 天每天 1h · 前测/后测同卷 | Wzq + Zack | 5/5 完成 + 至少 3 人后测分高于前测 ≥ 20% |

**W4 决策点**：5 人样本里掌握度提升中位数 ≥ 20% → 进 W5；< 10% → 砍模型路由重做，或干脆只用 DeepSeek 单跑别折腾。

### W5-W8 · 内测阶段：30 个原点营老学员 4 周留存测试

目标：从五一营第二期（5/2-5/4）30 名学员里捞 20-30 个进内测，验证「单点闭环」能否扩到「整章 → 整学期」。

| 周 | 关键交付 | 谁 | 验收 |
|---|---|---|---|
| W5 | 五一营结营当天 · 现场扫码进内测群 · 给 30 天免费体验权 | Wzq | 报名转化率 ≥ 70%（30 人里 21+） |
| W5 | 知识点扩展到「函数 + 三角 + 数列」三章 60 个细粒度知识点 | Zac | 题库扩到 1500 题 |
| W6 | 家长周报模板（gamification-engine 抽出来用） · 每周二自动推送 | Wzq | 包含：本周做题数 / 掌握知识点数 / 薄弱点 / 下周建议 |
| W6 | 错题本 + FSRS 间隔复习 · ts-fsrs 直接接 | Zac | 复习触达率 ≥ 60% |
| W7 | E-EVAL 自动评测：每周跑 200 道随机题对比 baseline | Zac | 解题正确率 ≥ Qwen-Plus 单模 + 5pp |
| W7 | Eedi 误概念库接入：错题归因到 100+ 标准误概念 tag | Zac | 错题归因可读性家长打分 ≥ 4/5 |
| W8 | 4 周留存数据出炉 · 决定是否进商用 | Zack | DAU/WAU ≥ 0.5 + 主动续费意愿 ≥ 50% |

**W8 决策点**：留存 < 30% 或续费意愿 < 30% → 转「五一营增值附赠」定位（不单卖），90 天目标降级；留存 ≥ 50% → 全力进 W9 商用。

### W9-W12 · 商用准备：定价 + 家长端 + 招商话术 + V1 上线

| 周 | 关键交付 | 谁 | 验收 |
|---|---|---|---|
| W9 | 定价方案出版：单点试用 7 天 ¥0 → 单科月卡 ¥299 → 三科年卡 ¥1999 | Zack + Wzq | 灰度 30 人调研，付费意愿 ≥ 30% |
| W9 | 家长端 v1：家长扫码看孩子周报 + 一对一答疑入口（人接） | Zac | 30 户家长，7 日打开率 ≥ 60% |
| W10 | 招商话术（线下）：北大中关 / 海淀文化馆做 2 场公开课，主打「替代 1v1 讲题人」 | Wzq | 现场到访 ≥ 40 户 |
| W10 | 公众号「原点 AI 学堂」连发 3 篇深度 case：学员真实提分故事 | Wzq + Zack | 单篇阅读 ≥ 3000 |
| W11 | 视频号 SOP D 卡片速览 8 条 + 家长访谈 4 条 | Wzq | 完播率 ≥ 30%（按 platform_psych 铁律） |
| W11 | 合规自查：未成年信息收集 / 个保法 / 广告法 | Zack | 调用 `legal-advisor` skill 出 checklist |
| W12 | V1 公开上线 + 首批付费 ≥ 30 单 | 全员 | 营收 ≥ ¥30k，付费转化率 ≥ 20% |

**W12 决策点**：付费 < 10 单 → 回炉做 ToB 学校采买切入；付费 ≥ 30 单 → 进下一个 90 天「数理化全科扩张」。
