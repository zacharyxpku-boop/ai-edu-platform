# Khanmigo 差距分析 v1 · 14 维对比 + 追/不追决议

承认差距：当前 tutor 跟 Khanmigo 比，**视觉接近但产品形态浅一层**。本文逐维拆解，每一项标"追/不追"+ 成本 + ROI 优先级。

> 不是抄。Khanmigo 服务美国 K12 探索式学习，我们服务中国高考体系——有些差距是对的（不该追），有些是真短板（必须追）。

## 必追清单（按 P 排）

### P0 · 5.4 Demo 前 / 内测前必有

#### A. Exercise → Tutor 流程闭环（差距 #4）
当前：mastery-loop 做错题 → 完成态 4 按钮里有「问老师」 → 跳 tutor 带 topic_code（已 ship）
真实差距：**做题中**做错某题时不能直接召唤 AI；只能做完一关再回看。Khanmigo 是答错的瞬间弹 hint。

修复方案：mastery-loop 每题答错后弹 mini-tutor 浮窗（不离开当前页），用户问完一句继续做下一题。

工作量：tutor.html 抽出 `<TutorPanel>` 组件（HTML iframe 或纯 JS），mastery-loop 嵌入，3-4h。

#### B. 家长 view 对话历史（差距 #6）
当前：parent-radar 只显示雷达分数。
真实差距：中国家长比美国家长**更关心过程**——「孩子今天问了什么、AI 怎么答的、孩子卡了多久」。

修复方案：parent-radar 加 tab「最近对话」，列出最近 3 天 dialogues + signals 抽取。每条对话可展开看完整。

工作量：新加 1 tab + 调 student-memory API filter by date_range，2-3h。

#### C. Curriculum 扩到初一全册（差距 #2）
当前：左栏锁着的章节点不动。
真实差距：5.4 demo 演示完一元一次方程后家长问「整式呢？几何呢？」我们答「内测后开」——气势就泄了。

修复方案：knowledge_points 表灌完初一数学全 16 章 KPs（数据来自 ChinaTextbook 仓库已抽取的 raw 数据）；左栏点开锁章节虽然没题但能问 AI。

工作量：seed SQL 写 ~120 条 KP，2h；左栏锁解除 + 点击切 KP，0.5h。

### P1 · 内测期 5.5-6.1 必有

#### D. AI 4 模式入口（差距 #5）
现在所有进 tutor 都是「问数学」单一定位。改成顶部 4 chip 切换：
- **讲题**（默认，已有）
- **错题归因**（让孩子贴错题 → AI 走 64 类 misconception 流程）
- **考前突击**（输入考试时间 → AI 排 5-7 天复习计划，按 BKT mastery 倒排）
- **作文批改**（仅初中以上，跟数学没关，但每个孩子都需要）

工作量：tutor.html 加 chip + tutor-chat.js 接 `mode` 参数路由 4 段 system prompt，半天。

#### E. Lesson video（差距 #3）
当前：左栏 KP 点开只有对话，没视频。
修复方案：每个 KP 挂 1 个 3-8 min 教材讲解（用 Remotion 出，已有 SOP）。

工作量：每 KP 2-3h × 50 KP = 100-150h（不可能 5.4 前完成）。
**降级方案**：先挂 5-10 个最高频 KP 的视频，其他显示「视频赶制中」。

### P2 · 内测后 6.1+

#### F. 安全护栏（差距 #12）
家长账号 + 开关（年龄限制 / 不当词拦截 / 每日时长上限）。

#### G. 高考阅卷规则训练（差距 #11）
prompt 加「答题规范」段：步骤分要点、结论框出、关键词必出。

### P3 · 6.1 后

#### H. 定价 + 免费试用（差距 #13）
Stripe / 微信支付，14 天免费 trial 后 ¥39/月（参考 Khanmigo $4 + 中国 ARPU 调整）。

## 实事求是的总结

**当前距离 Khanmigo 真实差距**：约 50-60%（产品形态层面）。
- 视觉/技术骨架：基本到位
- 内容深度（curriculum + video + exercise 闭环）：差距最大
- 中国独有强项（错题归因 / 课标对齐 / 跨会话记忆）：已经超过

**5.4 demo 前能补上**：A+B+C+D 4 项 = 把差距压到 30-35%
**内测期 5.5-6.1 能补上**：E+G 2 项 = 压到 20%
**6.1 后追**：F+H = 压到 15%

15% 是合理稳态——剩下的差距是「美国课外探索 vs 中国高考」的根本定位差异，不该消除。
