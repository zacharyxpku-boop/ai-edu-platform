# RC4 User Journey Map

Date: 2026-05-13

## 1. One-Sentence Experience

孩子选一位老师，发作业或说卡点；老师陪他先排今晚第一步，只修一个真实卡点，用小黑板看清第一步；孩子说出自己的第一步后，系统生成明天回访卡，家长只看一句话。

## 2. Child

### Current Situation

- 作业多，不知道今晚先做什么。
- 卡住了，但说不清自己到底卡在哪里。
- 怕家长一上来就批评“你怎么又不会”。
- 不想听长篇讲解，也不想被直接塞答案。

### What The Child Needs

- 先知道下一步做什么。
- 被温和地接住，不被直接批评。
- 能用一句话说出“我卡在哪里”。
- 感觉今天选的老师真的在陪自己走完整晚间路线，而不是换了个工具皮肤。

### Desired Path

1. 打开首页，看到“今晚作业先从哪一步开始？”。
2. 选择今天想被怎么陪。
3. 发作业清单，或者说一句“我写到第二步就乱了”。
4. 系统把今晚路线排出来。
5. 进入错题闭环，只修一个卡点。
6. 小黑板不讲答案，只提示先看哪里。
7. 孩子用一句话说出自己的第一步。
8. 修完后知道明天会回来轻轻回访。

## 3. Parent

### Current Situation

- 想帮孩子，但不一定会讲题。
- 晚上时间有限，不能陪很久。
- 担心 AI 直接给答案，让孩子依赖。
- 需要知道今晚有没有真正学到一点东西。

### What The Parent Needs

- 5 秒知道孩子卡在哪。
- 知道今晚只问哪一句。
- 知道系统没有直接给答案。
- 明天还能回访，不是一晚结束就忘了。

### Desired Path

1. 孩子修完一个卡点。
2. 家长打开“我的”。
3. 看到“今晚家长只问这一句”。
4. 看到孩子说出的第一步。
5. 看到老师提示先看哪里。
6. 用一句不压迫的问题回访孩子。
7. 明天用 2 分钟再看同一张回访卡。

## 4. Product Role

原点私教不是答案机器。

它不直接生成完整答案，不做拍照搜题，不做秒解，也不替代学校老师讲完整题。

原点私教不是补课老师。

它不把老师写成数学老师、英语老师、语文老师或科学老师，也不把六位老师拆成作业规划、错题、复习、家长复盘等功能分工。

原点私教不是游戏。

它可以轻一点、有陪伴感、有小挑战感，但不做排行榜、PK、冲榜或报告墙。

原点私教是晚间学习路线私教。

它做的事是：

1. 帮孩子先排今晚作业。
2. 把“我不会”变成一个真实卡点。
3. 用小黑板提示第一步该看哪里。
4. 让孩子说出自己的第一步。
5. 生成明天回访卡。
6. 给家长一句能问、不会变成讲答案的问题。

## 5. Page-Level User Questions

Home:

- 今晚作业先从哪一步开始？

Review:

- 今晚只修哪一个真实卡点？

Tools:

- 今天回访哪一小步？

Profile:

- 今晚家长只问哪一句？

## 6. Language Boundary

User-facing language should prefer:

- 今晚路线
- 卡住的一步
- 孩子说出的第一步
- 明天回访卡
- 家长只问一句
- 小黑板提示

User-facing language should avoid:

- todayFocus
- reviewCard
- issueType
- growth memory
- companionPreference
- blackboardHint
- miniActionText
- evidence flow
- dashboard
- system diagnosis
