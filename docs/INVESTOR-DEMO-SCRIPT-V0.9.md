# 原点智学投资人 5 分钟 Demo 话术 v0.9

目标：不要把产品讲成“又一个 AI tutor”。要讲成中国家庭作业场景里的学习决策系统，叠加 Gizmo 式内容引擎、Anki 式长期记忆、Khanmigo 式思考守门和家长侧数据飞轮。

## 0:00-0:40 痛点

```text
中国家庭晚上的学习问题，不只是孩子不会题，而是家长不知道今晚到底该把时间花在哪里。

大多数家庭现在是平均用力：每项作业都做、每道错题都骂、每个薄弱点都想补。结果是孩子累，家长焦虑，真正关键的错因却没有沉淀。
```

一句话：

```text
原点智学解决的是“家庭学习任务决策”问题，不是做一个泛聊天 AI 私教。
```

## 0:40-1:40 产品闭环

演示路径：

```text
首页 -> 录入今晚作业 -> 雷达弱点 -> 作业三分类 -> 必须做进入原小点 -> 生成复习卡 -> 家长周报
```

讲法：

```text
家长手动录入测评、错题或今晚作业。系统会先形成弱点雷达，再把作业分成三类：必须做、可以跳过、灵活选择。

孩子不是所有题都问 AI，而是只把必须做和关键错因交给原小点。原小点不直接给答案，而是要求孩子说条件、第一步和错因。最后，系统把这次学习沉淀成复习卡和家长周报。
```

核心差异：

```text
我们不是让孩子多学一点，而是让家庭少浪费一点。
```

## 1:40-2:30 对标竞品

```text
Gizmo 强在把资料变成卡片和测验，Anki 强在长期记忆调度，Khanmigo 强在不直接给答案的苏格拉底式引导。

原点智学会吸收这些能力，但落点不同：我们把它们放进中国家庭作业决策场景里。资料、错题、作业和家长反馈都会进入同一个闭环。
```

对标表述：

- Gizmo-like：粘贴学习材料后生成知识卡、测验、复习计划和家长摘要。
- Anki-like：复习卡进入长期调度，避免错因隔天消失。
- Khanmigo-like：tutor 先要思考证据，拒绝代写式答案。
- China family wedge：雷达弱点和作业三分类直接服务晚间家庭决策。

## 2:30-3:30 技术和数据壁垒

```text
长期壁垒不在单个 prompt，而在五类资产持续叠加：

第一，弱点图谱：孩子到底卡在哪类能力。
第二，作业价值排序：哪些任务最值得做。
第三，错因资产：反复出现的错因如何被修复。
第四，记忆资产：哪些内容该什么时候回来复习。
第五，家长校准：系统判断准不准，由真实家庭持续反馈。
```

数据飞轮：

```text
每一次作业录入、每一次必须做选择、每一次 tutor 守门、每一次复习反馈、每一次家长准不准判断，都会改善下一次推荐。
```

投资人该记住的一句话：

```text
原点智学不是题库公司，而是家庭学习决策数据公司。
```

## 3:30-4:20 商业化

首版不急着做复杂支付，先验证付费意愿：

- 免费体验：一次作业三分类 + 基础雷达 + 一个必须做引导。
- 家长报告：19-39 元/次，用于低门槛验证。
- 月度学习包：99-199 元/月，包含每周学习包、复习卡、家长周报。
- 深度诊断：299 元以上，半人工辅助建立第一版学习画像。
- 机构/老师版：后续做班级雷达、批量学习包和家长导出。

讲法：

```text
家庭愿意付费的不是“AI聊天”，而是更少无效作业、更清楚的弱点、更可见的进步证据。
```

## 4:20-5:00 当前状态和风险

当前状态：

- 小程序主链路已经成型。
- 内容工厂、复习调度、游戏化、家长周报、内测证据记录都有 v0.9 形态。
- 已准备上架 runbook、审核口径和 10 家庭内测 SOP。

真实风险：

- AppID、API key、云同步生产环境仍需要配置。
- 真正的提分证据必须来自真实家庭长期内测。
- Gizmo/Anki 级别的长期参数优化需要真实使用数据。
- 首版必须控制范围，不能同时做 OCR、支付、社交和全学科扩张。

收束句：

```text
我们现在不需要证明自己是最强 AI tutor。我们要先证明一件更有商业价值的事：在真实中国家庭里，原点智学能让晚上的学习决策更准、更省力、更可持续。
```

## Demo 备用问答

问：你们和通用大模型有什么区别？

答：

```text
通用大模型回答问题，原点智学组织家庭学习闭环。我们的核心是弱点、作业、错因、复习和家长反馈的结构化资产。
```

问：会不会变成作业代写？

答：

```text
不会。原小点默认要求孩子先说条件、第一步和错因，直接要答案会被守门。产品定位是思路引导和复习沉淀，不是代写。
```

问：怎么证明能提分？

答：

```text
首阶段不做保证提分承诺。我们先验证更前置的指标：每晚节省时间、家长判断信心、必须做完成率、复习回访率和错因复现下降。成绩变化需要更长周期跟踪。
```

问：壁垒在哪里？

答：

```text
壁垒来自真实家庭学习数据闭环：弱点图谱、作业价值排序、错因 taxonomy、记忆调度记录和家长校准反馈。越多家庭使用，推荐越贴近真实晚间场景。
```
