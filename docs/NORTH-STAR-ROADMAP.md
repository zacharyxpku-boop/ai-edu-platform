# 原点智学北极星路线图

## 最终目标

原点智学最终不是一个通用 AI 私教，也不是题库工具，而是面向中国家庭的学习决策系统：

```text
让家长每天知道哪些学习任务最值得做，让孩子只在关键弱点上用力，并把每一次作业、错题和反馈沉淀成个人学习策略。
```

北极星结果：

```text
孩子少做低价值任务，关键错因被持续消除，家长能看见每周进步证据。
```

## 产品终局形态

### 1. 家长决策端

家长每天只需要做三件事：

1. 录入作业、错题或测评结果
2. 查看弱点雷达和作业三分类
3. 标记判断是否准确，并查看周复盘

家长端的价值不是“看数据”，而是减少错误决策：

- 不再平均用力
- 不再用低价值作业挤占精力
- 不再只靠情绪催促
- 不再看不懂孩子到底卡在哪里

### 2. 孩子执行端

原小点只处理两类任务：

- 必须做
- 关键错因

固定掌握循环：

```text
读题 -> 找条件 -> 写第一步 -> 说错因 -> 复盘
```

原小点不替写答案，不做泛聊天，不承诺固定结果。

### 3. 学科题型策略库

长期壁垒来自结构化策略库，而不是散乱提示词：

```text
年级 -> 学科 -> 题型 -> 常见错因 -> AI 引导方法 -> 掌握证据 -> 家长复盘话术
```

首批只做：

- 数学计算题
- 数学应用题
- 数学错题复盘
- 英语单词记忆
- 英语日常对话
- 英语简单写作

等真实家庭数据出现后，再扩展语文、物理、化学和更多题型。

### 4. 家庭反馈校准引擎

系统必须持续记录：

- 哪些任务被判为必须做
- 家长认为准不准
- 孩子是否进入原小点执行
- 是否完成复盘
- 哪些错因反复出现

这些数据用于从规则排序升级到个体化排序。

## 阶段路线

### Phase 0：上架

目标：低成本通过审核，让审核员和首批家长 30 秒跑通。

完成标准：

- 真实 AppID 已替换
- request 合法域名配置为 `https://yuandianzhixue.com`
- 微信开发者工具可上传体验版
- 审核说明明确：不支付、不课程售卖、不 OCR、不代写
- 30 秒体验样例可从首页跑通

### Phase 1：20 个家庭内测

目标：验证“家庭学习决策系统”是否有真实需求。

关键指标：

- 20 个家庭连续使用 7-14 天
- 至少 100 条作业/错题输入
- 至少 50 条准/不准反馈
- 至少 30 次原小点必须做任务执行
- 至少 5 个家庭表达付费意愿

这阶段不追求增长，只追求真实使用证据。

### Phase 2：付费验证

目标：验证家长是否愿意为减负、决策和周复盘付费。

建议包装：

- 免费体验：每日 1 次三分类 + 基础雷达 + 第一项必须做引导
- 家庭版：29-49 元/月，更多分类次数、周复盘、错因趋势、完整原小点循环
- 深度陪跑版：199-399 元/月，半人工复盘、个性化策略、家长答疑

首版不急着在小程序内接支付，可以先用内测服务收款验证。

### Phase 3：题型策略库

触发条件：

- 真实作业输入足够多
- 能看出高频题型
- 家长反馈能反向校准系统

这时开始做数学和英语高频策略库，把提示词内容产品化。

### Phase 4：数据壁垒

目标：从规则系统变成家庭学习策略引擎。

核心资产：

- 错因 taxonomy
- 题型 taxonomy
- 作业价值排序向量
- 家庭校准反馈
- 学生掌握证据
- 周复盘历史

## 不能做的事

上架前和内测前禁止：

- 全学科铺开
- 做 OCR 作为主卖点
- 做复杂会员系统
- 承诺提分
- 讲成 AI 私教
- 追求大而全网站叙事
- 没有反馈数据就大规模写策略库

## 当前最重要的下一步

```text
拿 AppID -> 配合法域名 -> 上传体验版 -> 提审 -> 拉 20 个家庭内测
```

代码不是当前最大瓶颈。真实家庭反馈才是。
## 2026-05-03 闭环升级：家庭校准画像

本轮把学习模块库从“可点开的 AI 学习方法”推进到“可校准的家庭学习决策系统”。

新增闭环：

```text
测评/作业录入 -> 雷达弱点 -> 作业三分类 -> 学习模块推荐 -> 原小点执行 -> 掌握/卡点信号 -> 家庭校准画像
```

已落地信号：

- 作业判断反馈：准 / 不准
- 模块适配反馈：适合现在练 / 暂时不适合 / 原因
- 模块行为：浏览 / 开始 / 完成
- 原小点执行：掌握证据 / 拒答拦截 / 模块执行次数

产品意义：

- 不承诺“保证提分”，而是提高家庭学习任务决策质量。
- 不做散乱 prompt 集，而是把 AI 自学方法产品化为可执行模块。
- 不急着做 OCR 和重后台，先沉淀错因、作业价值、模块适配和家庭反馈。
- 上架成本保持低，真实 AppID 与微信域名配置完成后，再逐步同步匿名事件到服务端。

## 2026-05-03 闭环升级：原点复习引擎 v0

参考 Gizmo 的低阻力内容引擎和 Anki/FSRS 的间隔重复思想，但原点不做通用闪卡工具。原点复习的定位是：

```text
把孩子真实作业、错因、雷达弱点和原小点执行信号，自动转成每天 5 分钟的复习任务。
```

v0 已定义为四类卡：

- 弱点卡：今天先检查哪个能力缺口
- 第一步卡：这类任务开始时先做什么
- 错因卡：上次为什么错
- 执行卡：原小点里是否形成掌握证据

调度先采用低成本间隔策略：

```text
忘了 -> 1 天后
吃力 -> 2 天后
会了 -> 4 天后
很稳 -> 7 天后
```

后续可替换为 FSRS，不改变页面和数据入口。

护城河意义：

- Gizmo 强在把资料变成卡；原点要强在把“真实错因”变成卡。
- Anki 强在记忆调度；原点要把调度接回雷达、原小点和家长画像。
- 中国 K12 家长买单的是“少做无效作业 + 反复错因减少”，不是“卡片数量更多”。

新增闭环：

```text
雷达弱点 -> 必须做作业 -> 原小点执行 -> 原点复习卡 -> 掌握/遗忘反馈 -> 家庭校准画像
```
