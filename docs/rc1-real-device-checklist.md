# RC1 真机前检查清单

生成日期：2026-05-11

## 1. 导入路径

微信开发者工具导入路径：

```text
miniprogram/
```

当前 `miniprogram/project.config.json` 仍为：

```json
"appid": "touristappid"
```

`miniprogram/project.private.config.json` 当前没有覆盖真实 `appid`。因此当前无法上传真实体验版，必须先运行：

```powershell
npm.cmd run miniapp:appid -- wx你的真实AppID
```

不要编造 AppID；以微信公众平台后台实际 AppID 为准。

## 2. 合法域名

小程序侧实际请求入口：

- `miniprogram/app.js`: `apiBase: 'https://yuandianzhixue.com'`
- `miniprogram/utils/api.js`: `DEFAULT_BASE_URL = 'https://yuandianzhixue.com'`
- `miniprogram/utils/api.js`: 使用 `wx.request`

微信公众平台后台需要配置：

| 类型 | 域名 |
| --- | --- |
| request 合法域名 | `https://yuandianzhixue.com` |
| uploadFile 合法域名 | 首版不配置，当前未发现小程序侧 `wx.uploadFile` |
| downloadFile 合法域名 | 首版不配置，当前未发现小程序侧 `wx.downloadFile` |
| websocket 合法域名 | 首版不配置，当前未发现小程序侧 `wx.connectSocket` |

说明：

- 当前页面主流程大量依赖本地状态和本地 mock，可在本地预览中跑通主体验。
- 已接入的正式 API 请求会走 `https://yuandianzhixue.com/api/...`，真实体验版前必须在微信后台配置 request 合法域名。
- 后端服务内部可能再访问 Supabase、模型服务或微信接口；这些属于服务端到服务端请求，不是小程序后台的 request 合法域名配置项。

## 4. 老师选择机制截图要求

至少保存以下截图：

1. 作业点拨中“今天想让谁陪你？”轻入口。
2. 老师选择展开态。
3. 选择安安后的四个 Tab。

5. 选择跃跃后的知识游乐场和我的页。
