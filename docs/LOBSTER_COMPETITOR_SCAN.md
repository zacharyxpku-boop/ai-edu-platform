# Lobster Competitor Scan

Last checked: 2026-06-03

## What I Found

Searches for "勺子 CLAW" did not surface a clear education product with that exact name. The useful reference set is the broader Claw/OpenClaw-style personal agent category.

## Relevant References

### OpenClaw

Source: https://openclaw.ai/

OpenClaw positions itself as a personal AI assistant that runs on a user's machine, connects to chat apps, keeps memory, and uses skills/plugins to take real actions. The useful pattern for Lobster is not the meme theme. The useful pattern is:

- user reaches the assistant from familiar channels,
- the assistant has durable memory,
- skills make the assistant useful beyond chat,
- proactive reminders and daily briefings create habit,
- security boundaries matter because skills can touch real systems.

### CatClaw

Source: https://catclaw.app/

CatClaw emphasizes local AI agents and privacy. The useful pattern for Lobster is:

- private-by-default positioning,
- clear setup surface,
- open-source trust signal,
- local/control-first story for families that do not want uncontrolled child chat.

### OpenClaw FAQ / Docs Pattern

Source: https://docs.openclaw.ai/faq

The docs position OpenClaw as a local-first control plane with stateful sessions, memory, tools, and chat-app access. For Lobster, the equivalent education-specific control plane should be:

- family profile,
- learning evidence,
- child-safe tutoring boundary,
- parent report,
- scheduled follow-up,
- official channel adapters only.

## What Lobster Should Copy

1. **Channel-first onboarding**: users should not first see a technical console. They should see "open website, configure family, start teacher".
2. **Memory as product value**: keep structured facts, not raw dialogue. "It remembers how your child gets stuck" is stronger than "it can chat".
3. **Skills as capabilities**: child Socratic hint, parent report, evidence gap check, follow-up schedule, emotional support.
4. **Proactive presence**: reminders and inbox are central. A real teacher follows up; a chatbot waits.
5. **Trust boundary**: no unofficial WeChat/QQ bots, no raw child dialogue storage, no direct-answer tutoring mode by default.

## What Lobster Should Not Copy

1. Do not sell "agent can control everything". Parents need confidence, not a risky automation story.
2. Do not make installation technical. Family product setup must be less than three minutes.
3. Do not make a marketplace of arbitrary skills for children.
4. Do not depend on chat apps before the Web parent-device loop works.

## Product Implication

The homepage should introduce Lobster as part of the Yuandian learning system:

- Yuandian = evidence and learning loop.
- Lobster = AI teacher on the parent device.
- Child experience = co-view, first-step tutoring, no direct answer.
- Parent experience = upload evidence, receive report, see follow-up.

This is a stronger sales story than "a lobster chatbot".
