# 原点智学小程序最低成本上架战役室

目标不是“把网站搬进小程序”，而是用最小成本让微信审核能过、家长能用、后续可迭代。

## 最低成本路线

### 推荐路线：工具型 MVP 先上架

- 主定位：学习效率工具、作业取舍助手、错因复盘陪练。
- 首版不做：支付、课程售卖、自动图片识别、作业代写、公开社区、排行榜。
- 首版保留：测评录入、作业清单录入、雷达弱点、作业三分类、原小点思路陪练、咨询留资。
- 成本：微信小程序账号 + 已有 Vercel/域名 + 现有 DeepSeek/Supabase 环境。

这样做的原因：教育/在线教育类目可能牵涉资质、未成年人保护和学科培训审查；先按“工具闭环”证明用户价值，后续有资质再扩教育类目。

### 不推荐首版做的事

- 不开微信支付：iOS 虚拟支付、教育服务退款与资质都会增加审核复杂度。
- 不上自动图片识别：图片安全、OCR 准确率、用户隐私和成本都会增加。
- 不强调“私教/辅导/课程”：对审核和双减合规都更敏感。
- 不展示孩子完整对话给家长：先给弱点类型、进展和作业建议，降低隐私风险。

## 账号与后台配置

1. 注册微信小程序账号。
2. 有企业/个体工商户主体时优先用主体账号；没有资质时先用能提交的工具类路径验证 MVP。
3. 修改 `miniprogram/project.config.json`：
   - `appid`: 换成真实小程序 AppID。
4. 微信后台配置服务器域名：
   - request 合法域名：`https://yuandianzhixue.com`
   - uploadFile 合法域名：首版不配，避免上传承诺。
   - downloadFile 合法域名：首版不配。
5. Vercel 环境变量：
   - `WECHAT_APP_ID`
   - `WECHAT_APP_SECRET`
   - `MINI_SESSION_SECRET`
   - `DEEPSEEK_KEY`
6. 小程序隐私保护指引：
   - 需要声明获取：网络请求、相册/摄像头（仅照片留档）、用户主动填写的手机号或联系方式。
   - 用途写：生成学习建议、保存本地记录、内测回访。

## 提审版本说明

建议直接复制：

> 本版本为学习效率工具 MVP。用户可手动录入测评成绩、错题描述和作业清单，系统生成能力雷达与作业优先级分类，并提供 AI 辅助的思路引导。首版不含支付、不含课程售卖、不含自动图片识别、不提供作业代写服务。

建议直接复制：

## 被拒快速应对

### 被拒：类目不符

回复：

> 已将产品定位调整为学习效率工具，首版不提供课程售卖、学科培训、老师授课或支付服务。核心功能为用户主动输入学习任务后的优先级整理和思路引导。

必要修改：

- 前台去掉“私教、辅导、课程、教学”等高敏词。
- 保留“学习效率、作业取舍、思路陪练、错因复盘”。

### 被拒：隐私政策不完整

回复：

> 已补充隐私保护指引，说明相册/摄像头仅用于照片留档，手机号仅用于用户主动提交后的内测回访，AI 内容用于生成学习建议。

必要修改：

- 微信后台隐私保护指引补齐对应权限。
- 小程序“我的”页保留隐私政策入口。

### 被拒：AI 生成内容未标识

回复：

> 已在首页和相关结果页标注“AI 辅助生成建议”，并说明不替代老师或家长判断。

必要修改：

- 每个结果页保留 AI 标识。

### 被拒：涉及代写作业

回复：

> 已明确产品不提供代写，AI 只做思路引导和最小提示；当用户要求直接答案或代写时，系统会拒绝。

必要修改：

- 保留 `api/mini/tutor-message` 的作业边界拒绝逻辑。
- 前台输入框避免“答案生成器”类表达。

## 真正的剩余阻碍

| 阻碍 | 最低成本处理 |
| --- | --- |
| 没有教育资质 | 首版走学习效率工具叙事，不卖课不支付 |
| 没有算法备案 | 首版先灰度/体验；正式扩大前准备算法备案材料 |
| 内容安全 | 已加本地预检，正式版接微信 `msgSecCheck` |
| 图片安全 | 首版照片只本地留档，不上传，不识别 |
| 支付复杂 | 首版只留资，后续线下/企微成交 |
| 隐私审核 | 已加隐私授权适配和协议入口 |
