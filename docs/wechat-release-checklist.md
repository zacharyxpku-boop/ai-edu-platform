# WeChat Release Checklist

本清单用于 Pilot Release Candidate 0 进入 5-10 个家庭封闭试用前的微信侧准备。不要把本清单当成已经完成真机验收的证明。

## 一、配置

- [ ] 从微信公众平台复制真实小程序 AppID。
- [ ] 运行：

```powershell
npm.cmd run miniapp:appid -- wx你的AppID
```

- [ ] 确认 `miniprogram/project.config.json` 或本机 private config 不再是 `touristappid`。
- [ ] 微信后台 request 合法域名配置：`https://yuandianzhixue.com`。
- [ ] 确认首版不启用 OCR / PDF / 拍照识别相关能力。

## 二、微信开发者工具

- [ ] 用微信开发者工具导入 `miniprogram/`。
- [ ] 使用真实 AppID 编译。
- [ ] 打开真机预览。
- [ ] 上传体验版。
- [ ] 生成体验二维码。
- [ ] 分发给 5-10 个家庭前，先让内部 1 台 iPhone + 1 台安卓机跑通主路径。

## 三、四个 Tab 截图检查

- [ ] 作业点拨：主 CTA 是“帮我安排今晚学习”。
- [ ] 作业点拨：`我来说第一步` 是次级入口。
- [ ] 错题闭环：主 CTA 是“开始 5 分钟修复”。
- [ ] 知识游乐场：主 CTA 是“开始试玩”。
- [ ] 我的：主 CTA 是“完成今日回访”。
- [ ] 四个 Tab 都能看见 Tonight Route 轻提示。
- [ ] 路线 pill 不挤爆、不遮挡标题。
- [ ] 底部 Tab 不遮挡主 CTA。
- [ ] 顶部标题不撞微信胶囊区。

## 四、设备覆盖

- [ ] iPhone SE 或同等小屏。
- [ ] 小屏安卓。
- [ ] 常规 iPhone。
- [ ] 微信开发者工具模拟器只作为补充，不等于真机验收。

## 五、试用前文案边界

- [ ] 不出现“秒解”。
- [ ] 不出现“拍照出答案”。
- [ ] 不出现“答案已生成”。
- [ ] 不暗示“学校作业不用做”。
- [ ] 已知限制写清楚：不支持拍照识别、不支持 PDF / PPT / Anki / Quizlet 导入、不直接给答案。
- [ ] 明确“不替代学校和老师”。

## 六、数据和隐私

- [ ] 提审前不要预置真实孩子数据。
- [ ] 试用家庭编号匿名化。
- [ ] 不在群里收集孩子完整姓名和敏感成绩截图。
- [ ] 隐私和未成年人使用提示准备好。

## 七、当前状态说明

截至本清单生成时，本地代码验证可以通过；真实体验版仍需配置 AppID，并通过微信开发者工具进行人工真机验收。
