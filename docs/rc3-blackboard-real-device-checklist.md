# RC3.1 Blackboard Real Device Checklist

## 1. 首页六位老师真机验收

目标：老师团显性化，但不抢“帮我安排今晚学习”。

- Home 默认态第一眼仍看到“今晚从哪一步开始？”和主 CTA“帮我安排今晚学习”。
- 六位老师选择区位于输入卡或主 CTA 下方。
- 老师区标题为“今天想让谁陪你？”。
- 老师区说明为“老师都会陪你走完整路线，只是陪法不同。”。
- 六张小卡为 2x3 轻量布局。
- 每张小卡只显示老师名和一句陪伴方式：
  - 小原：帮我理顺一点
  - 问问：多问我一步
  - 安安：慢一点陪我
  - 阿衡：记得我以前的卡点
  - 团团：帮我讲给家长听
  - 跃跃：陪我闯一小关
- 选中态只用轻描边或小勾，不做大角色卡。
- 不出现长人设。
- 不出现老师功能分工。
- 不出现学科老师。
- 小屏下不撑爆首屏，主 CTA 不被底部 Tab 遮挡。
- 选择安安后，Home / Review / Tools / Profile 四个 Tab 都保持安安语气。
- 选择问问后，四个 Tab 都保持问问语气。
- 选择跃跃后，Tools / Profile 有轻挑战感，但没有排行榜、PK 或冲榜。

允许真机前 P0 小修：
- 压缩老师卡 padding。
- 缩小字号。
- 减少副文案长度。
- 调整选中态。

不允许：
- 隐藏六位老师。
- 改成大角色卡。
- 写“老师分工”或学科老师。

## 2. 小黑板四类模板验收

小黑板只在 Review 错题闭环中出现，作为“第一步该看哪里”的提示层。

### 列式关系

- 标题：关系小黑板
- 结构：整体 → 部分 → 关系
- 内容提醒：先找题目问谁、谁是整体、谁和谁在比较。

### 读题审题

- 标题：审题小黑板
- 结构：问题 → 条件 → 第一步
- 内容提醒：先圈问题，再找相关条件，暂时放下无关信息。

### 步骤断点

- 标题：步骤小黑板
- 结构：第一步 → 下一步 → 检查
- 内容提醒：先说第一步，再决定下一步，不要一下子想完整题。

### 概念公式

- 标题：概念小黑板
- 结构：概念 → 条件 → 公式
- 内容提醒：先说这个概念在问什么，再想用哪个公式。

## 3. 小黑板状态流验收路径

路径：单位1 → 关系小黑板 → 回访卡 → 家长复盘。

1. 清空本地学习状态。
2. 打开 Home。
3. 输入：“我不确定单位1是谁。”
4. 确认生成 todayFocus：
   - issueType = 列式关系；
   - title 包含“单位1”；
   - sourceText 保存原话。
5. 进入 Review。
6. 点击“开始 5 分钟修复”。
7. 确认出现“关系小黑板”。
8. 确认结构为“整体 → 部分 → 关系”。
9. 输入 miniActionText：“我先找谁是整体。”
10. 点击保存第一步。
11. 完成修复。
12. 在 Storage 面板确认：
   - todayFocus.miniActionText = 我先找谁是整体；
   - todayFocus.blackboardHint 存在；
   - todayFocus.blackboardHint.structure = 整体 → 部分 → 关系；
   - todayFocus.blackboardUsedAt 存在；
   - todayFocus.repairStatus = completed。
13. 进入 Tools。
14. 确认 reviewCard.front 引用具体卡点或 miniActionText。
15. 确认 reviewCard.front 包含“小黑板提醒你先看：整体 → 部分 → 关系”。
16. 进入 Profile。
17. 确认主卡包含：
   - 孩子说出的第一步；
   - 老师提示你先看；
   - 家长只问一句。

## 4. 不变成答案工具的检查项

- 小黑板不在 Home 默认态出现。
- 无 todayFocus 时 Review 不出现小黑板。
- 有 todayFocus 但未开始修复时，小黑板不抢主任务。
- 小黑板不展示最终答案。
- 小黑板不代写完整过程。
- 小黑板不出现“答案已生成”。
- 小黑板不出现“秒解”。
- 小黑板不出现“拍照出答案”。
- 小黑板只提示第一步该看哪里。
- 完成修复仍必须有 miniActionText。
- 轻回访仍必须通过 reviewCard。

## 5. 当前不接 Qwen API

RC3.1 仍然是本地模板型小黑板，不接 Qwen API，不接 Qwen-VL，不做拍题搜题。

当前目标是让真机可观察到：
- 老师团显性化；
- 修卡点时出现第一步提示结构；
- 小黑板使用证据能进入 reviewCard 和 Profile。

## 6. 未来接 Qwen API 的边界

如果未来接 Qwen API，只能作为“原点小黑板能力层”：

- 只能生成第一步提示。
- 不能生成完整答案。
- 不能代写完整解题过程。
- 不能跳过 miniActionText。
- 不能跳过 reviewCard。
- 不能改变 companionPreference。
- 不能把产品变成千问套壳。
