# Release Candidate Readiness Report

生成日期：2026-05-11

## 当前产品叙事

学校给全班同一份任务，原点老师团给每个孩子一条自己的晚间学习路线；孩子今天选择谁，谁就陪他把这条路线走完。

核心路线：

排顺序 -> 说第一步 -> 修卡点 -> 轻回访 -> 整理给家长看

当前 RC 叙事已从“功能集合”收敛为三层：

- Tonight Route：每晚先把学校任务排成一条能走下去的路线。
- 全局今日陪伴老师：孩子选择今天想被怎么陪，选中的老师贯穿四个 Tab。
- 成长记忆：今晚路线、卡点、回访卡和学习小结会沉淀成下一次更懂孩子的线索。

## 老师团定位

原点老师团不是学科老师集合，也不是页面固定角色。每位老师都是全能 AI 陪学老师，都能陪孩子完成完整 Tonight Route。

区别只在陪伴方式：

- 小原帮孩子理顺。
- 问问陪孩子多想一步。
- 安安让孩子别慌。
- 阿衡记得孩子以前卡在哪。
- 团团帮孩子把学习过程讲给家长听。
- 跃跃把回访变成一小关。

正确理解：孩子今天选择谁，谁就陪完整路线。  
错误理解：作业点拨固定小原、错题闭环固定问问、知识游乐场固定阿衡、我的页固定团团。

## 家长可理解边界

家长版说明应始终强调：

- 不是拍题搜答案。
- 不直接给答案。
- 不替孩子写作业。
- 帮孩子排今晚顺序。
- 卡住时先说第一步。
- 修过的卡点会回访。
- 孩子可以选择今日陪伴老师。
- 老师只是陪伴方式不同，不会改变教学规则。
- 家长看到的是孩子和老师一起整理出来的小结。
- 老师团不是学科补课入口，不是娱乐角色扮演。

## 已知限制

- 不支持拍照识别。
- 不支持 OCR。
- 不支持 PDF / PPT / Anki / Quizlet 导入。
- 不直接给答案。
- 不替孩子写作业。
- 不替代学校和老师。
- 老师团不是完全自由角色扮演。
- 当前仍需真实 AppID 和人工真机验收。

## 包装禁区

不要在对外材料、试用说明或家长沟通中使用以下包装：

- AI 解题老师
- 秒解
- 拍照出答案
- 学科名师
- 清北老师
- 状元老师
- 完全自由定制角色
- 游戏陪聊

## 是否影响核心闭环

本轮文档更新不改 UI、不改后端 API、不新增 Tab、不改变数据结构。

核心能力仍保持：

- `tonightPlan`
- `todayFocus`
- `issueType`
- `reviewCard`
- `companionPreference`
- `tutor ladder`

## 进入封闭试用的判断

可以进入封闭试用准备阶段，但不能声称体验版已可分发。当前仍需：

1. 配置真实 AppID。
2. 微信后台配置合法域名。
3. 微信开发者工具导入 `miniprogram/`。
4. 完成真机预览和截图验收。
5. 上传体验版并生成体验二维码。

代码和本地验证已准备好，但真实体验版仍需配置 AppID 并人工真机验收。

## 第一批家庭建议

建议 5-10 户：

- 小学高年级 3-5 户，尤其是应用题第一步卡住明显的家庭。
- 初一/初二 2-3 户，验证作业多时的路线安排。
- 1-2 户亲子陪学冲突明显的家庭。
- 暂不选择主要诉求是拍照找答案的家庭。
- 暂不选择强依赖 OCR / PDF 导入的家庭。
