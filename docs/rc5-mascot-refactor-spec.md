# RC5 Mascot Refactor Spec

## 1. Why six teachers should be removed

当前“六位老师 / 多老师陪伴”的系统已经完成过一轮从学科老师到陪伴风格的降噪，但它仍然会把产品带向几个不利方向。

第一，它天然让用户联想到“老师团队”和“分工矩阵”。即使前台不写学科分工，六个名字并列也会让家长以为这是多个专家角色，孩子也容易把选择理解成又一次被安排。

第二，它抢走了核心问题。产品真正要回答的是“今晚先从哪一步开始”，不是“今天选哪位老师”。当首屏出现 2x3 角色选择时，情绪上更热闹，但主线更分散。

第三，它增加了后续 UI 重建成本。六个角色需要头像、语气、状态、记忆、选中态、跨 Tab 一致性和测试断言，容易把设计资源消耗在角色矩阵，而不是晚间第一步路线。

第四，它容易滑回重辅导感。中国家庭对“老师”这个词有期待，也有压力；孩子会默认老师要讲、要问、要评判。当前产品需要的是低压力陪伴，不是更完整的人类老师替身。

第五，它削弱品牌记忆点。六个轻角色各有一点好处，但没有一个能成为产品脸。一个统一的、有怪异记忆点的品牌 mascot 更适合小程序首屏、分享图、真机截图、后续视觉资产与社交传播。

结论：六老师系统应从用户可见产品叙事中移除。后续工程实施可以暂时保留 `companionPreference` 等内部兼容字段，但前台不再呈现“选老师 / 多老师 / 老师陪你”。

## 2. New mascot positioning

新角色是原点私教唯一的品牌 mascot：一只降落到地球的小外星生物。

它来到地球后，看见很多孩子晚上写作业时很紧张、很烦、很想逃，也看见家长想帮但常常越帮越急。它不太懂人类为什么要把学习弄得这么痛苦，但它决定先留下来，坐在孩子旁边，把卡住的那一下变小一点。

一句话定位：

**我懂你卡住了，我陪你先迈出第一步。**

它不是：

- 人类老师。
- 学科专家。
- 答案机器。
- 严格监督者。
- 家长的审判工具。
- 商业课程吉祥物。
- 通用 AI 聊天助手。

它是：

- 晚间作业现场的低压力陪伴者。
- 孩子卡住时的情绪缓冲垫。
- 第一小步的提醒者。
- 家长 5 秒复盘的安静翻译官。
- 原点品牌的统一脸。

产品主线保持不变：

1. 今晚先做什么。
2. 卡在哪。
3. 先看哪里。
4. 第一步怎么说。
5. 明天轻轻回访。
6. 家长 5 秒看懂。

## 3. Mascot personality

物种方向：外星小生物。它可以借用水豚、海獭、软团子、小水母、慢吞吞网络动物等高亲和特征，但不能像真实宠物，也不能像幼儿动画角色。

气质关键词：

- 呆萌，但不幼稚。
- 温暖，但不煽情。
- 稍微笨一点，但不是低智。
- 平静，甚至有一点冷幽默。
- 反应慢半拍，但总能接住孩子的情绪。
- 不讲大道理，不摆老师架子。
- 能成为表情包，而不是精致 IP 展示品。

推荐人格原型：

它像一个刚学会地球作业规则的小外星观察员。看到孩子抓头发，它会认真地点头，说“嗯，这个卡住，地球小孩常见。”然后把问题缩到第一小步。

可用语气：

- “先别急，我也刚看懂一半。我们先看第一眼。”
- “这题现在像一团线。先拽最短那根。”
- “你不是整题不会，你是入口被挡住了。”
- “先说一句就行，不用表演很会。”
- “我在。我们只动一小步。”

不可用语气：

- “老师来教你。”
- “你必须掌握。”
- “答错说明基础薄弱。”
- “马上给你完整解析。”
- “完成挑战即可通关。”
- “购买服务解锁更多辅导。”

命名建议：本规格暂不强行定名。后续可围绕“原点”“小原点”“点点”“落落”“墩墩”“咕点”等方向做独立命名测试。命名必须短、好叫、不像课程品牌、不像幼儿园角色。

## 4. Mascot role in product

Mascot 在产品里承担四个角色。

情绪承接者：先承认孩子卡住和烦躁是正常的，不立刻讲方法。它的第一句话应降低压力，而不是进入讲解。

路线收束者：帮助孩子从一堆作业、一个模糊卡点，收束到今晚第一步。它不扩展任务，只缩小入口。

小黑板引导者：只提示“先看哪里”，不讲完整题，不替孩子生成答案。它像拿着手电照第一块地面，不像站上讲台。

家长翻译者：把孩子今晚的真实推进整理成一句话，让家长知道该问什么，而不是看复杂分析。

核心边界：

- Mascot 可以安慰，但不做心理诊断。
- Mascot 可以提示观察方向，但不生成完整答案。
- Mascot 可以记得卡点，但不贴长期标签。
- Mascot 可以给家长一句话，但不做评判报告。
- Mascot 可以有趣，但不把学习变成刺激机制。

## 5. Screen-by-screen mascot behavior

Home：Mascot 是入口处的陪伴脸。它应该出现在首屏，表达“今晚先别把所有作业都摊开，我们先找第一步”。原有老师选择区应移除；如果需要保留风格控制，也应弱化成 mascot 的轻语气状态，例如“慢慢来 / 先理顺 / 只看第一眼”，但 RC5 UI 重建优先不做选择，直接统一 mascot。

Upload：Mascot 是接住卡点的人。它提示孩子可以发作业、也可以直接说卡在哪。文案必须避免像拍照搜题，重点是“让我看看你卡住的地方”，不是“上传后出结果”。

Diagnosis：Mascot 是三问引导者。它用短问题把孩子从“我不会”带到“我先看哪里”。它可以显得有点笨拙，例如“我先问三个地球小问题”，但不能滑向测评或审讯。

Review：Mascot 是第一步陪跑者。它帮助孩子确认“卡在哪、先看哪里、第一步怎么说”。完成态应强调孩子说出了自己的第一步，而不是 mascot 讲完了题。

Tools：Mascot 是明天轻回访的提醒者。它像从昨天的小纸条里探头：“昨天那一步还顺吗？”不能像玩法集合，也不能像每日任务中心。

Profile：Mascot 是家长 5 秒复盘翻译官。它用平静、短句告诉家长：孩子今天卡在哪里，是否说出第一步，家长只问哪一句。它不做数据墙，也不替孩子打标签。

Radar / Tutor / Arcade / Module 等深层页面：若后续 UI 仍保留这些页面，它们必须服从 mascot 主线。页面视觉不能像功能矩阵，不能像游戏区，不能像专家系统。Mascot 的存在应把页面重新拉回“今晚第一步路线”。

## 6. Copywriting principles

总原则：先接住情绪，再缩小动作，最后让孩子自己说。

推荐句式：

- “我懂你卡住了。”
- “先别整题想，我们只看第一眼。”
- “你现在不用会全部，只要说出第一步。”
- “这不是答案页，是先找入口。”
- “我陪你把这一小步拎出来。”
- “明天我们轻轻回来看一下。”
- “家长今晚只问这一句。”

Mascot 口癖方向：

- 少量呆萌观察：“地球作业有时候确实绕。”
- 少量冷幽默：“这题先别打架，我们先找门。”
- 少量陪伴确认：“我在，先动一小步。”
- 少量孩子视角：“不用装会，先说卡在哪。”

禁止方向：

- 老师权威感：“我来教你”“听老师讲”。
- 答案承诺：“马上出答案”“完整解析已生成”。
- 评判诊断：“你基础差”“你薄弱点是”。
- 游戏刺激：“过关”“冲榜”“奖励升级”。
- 商业暗示：“开通”“套餐”“服务权益”。
- 内部系统感：“stage”“source”“enum”“panel”。

从六老师迁移到 mascot 的文案替换方向：

| 旧方向 | 新方向 |
| --- | --- |
| 今天想被怎么陪？ | 今天卡住了吗？我陪你先动一小步。 |
| 老师都会陪你走完今晚路线 | 我不讲完整答案，只陪你找到第一步。 |
| 小原 / 问问 / 安安 / 阿衡 / 团团 / 跃跃 | 统一 mascot 名称或“原点小伙伴”临时占位。 |
| 理顺一点 / 多问一步 / 慢一点 / 记得我 / 讲给家长 | 变成 mascot 在不同场景下的自然语气，不再作为可选角色。 |
| 老师提示你先看 | 小黑板先提示你看这里。 |
| 老师会帮你整理给家长看 | 我帮你整理成家长能看懂的一句话。 |

## 7. UI implications

首屏结构：Home 不再放 2x3 老师卡片。首屏应由 mascot 形象、今晚第一步问题、主 CTA、当前卡点状态构成。mascot 不抢 CTA，但要成为情绪锚点。

视觉资产：需要一个统一 mascot 基础形象，至少覆盖 idle、stuck、thinking、blackboard、revisit、parent recap 六种状态。状态变化服务流程，不服务角色收集。

交互控件：不要做“选老师”。若一定要保留个性化入口，应放在后续设置里，作为语气强度或陪伴节奏，不作为主线选择。

文案层级：每屏第一句由 mascot 说人话，第二层才是操作按钮。按钮保持明确动作，例如“说说卡在哪”“先看第一步”“生成明天回访卡”。

小黑板：可让 mascot 站在黑板旁或探头看黑板，但黑板内容必须是观察提示，不是题目讲解。

Profile：mascot 可以作为“翻译给家长”的小头像，但不能让页面变成 IP 周边或商业展示。

测试与实现提示：后续代码任务中，应新增 mascot copy 的测试保护，更新旧 companion/teacher 断言。内部字段可先兼容旧数据，但用户可见 copy 应集中收敛到 mascot 叙事。

## 8. Risks to avoid

风险一：把 mascot 做得太幼儿化。目标孩子包含小学高年级和初中，过度奶萌会让孩子觉得低龄。

风险二：把 mascot 做成 generic AI chatbot。它必须嵌在晚间作业路线里，而不是一个悬浮聊天气泡。

风险三：保留六老师影子。只要首页继续让用户选六个名字，产品心智就仍是多角色矩阵，不是统一品牌 mascot。

风险四：外星设定太重。故事是品牌底色，不应在 UI 里长篇解释。孩子只需要感到“它懂我卡住了”，不需要读宇宙观。

风险五：呆萌变成装傻。Mascot 可以慢半拍，但不能显得不可靠。家长必须相信它知道边界，孩子必须相信它能陪自己找到第一步。

风险六：安慰压过行动。它不是纯情绪陪伴产品，每次安慰后都要落到一个小动作。

风险七：IP 化抢产品价值。Mascot 是体验入口，不是周边主角。UI 重建不应变成角色展示页。

风险八：商业化污染信任。Mascot 不能在当前 RC5 承担售课、转化或套餐解释角色。

## 9. Final recommendation

建议正式冻结：原点私教从“六位老师陪伴路线”转为“一个外星 mascot 陪孩子先迈出第一步”。

推荐下一步分两阶段执行。

第一阶段，策略与设计冻结：确定 mascot 名称、基础形象、六个状态、核心口癖、禁用语气，并更新 Variant UI brief。此阶段不改学习流，不加功能。

第二阶段，前台叙事替换：移除 Home 的六角色选择 UI；把 Home / Upload / Diagnosis / Review / Tools / Profile 的用户可见“老师陪你”改为 mascot 叙事；保留必要内部兼容层，避免破坏 todayFocus、miniActionText、blackboardHint、reviewCard、growthMemory 等学习证据流。

最终判断：

**MASCOT_REFACTOR_READY_FOR_UI_REBUILD = YES**

条件是：UI 重建必须把 mascot 当作低压力陪伴者，而不是新一层功能包装；必须继续守住“不直接给答案、不做老师分工、不做商业课程入口”的产品边界。
