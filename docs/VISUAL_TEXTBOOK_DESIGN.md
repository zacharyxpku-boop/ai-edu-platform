## 1. 战略锚点

**一句话定位**：原点视觉化教科书引擎是一个把 K12 八学科课本拆成 10 类标准视觉卡片的内容工厂，让应试 mastery 引擎在每一次错题、每一个新知识点上，都能毫秒级调出一张「能让学生看一眼就懂」的图。

**与 V1 mastery 引擎的关系**：mastery 引擎走 BKT(贝叶斯知识追踪) 闭环 25 分钟做到一个知识点。每一次诊断出"概念没建立 / 步骤断链 / 易混点"，引擎调用本系统的 `getCard(knowledge_point_id, card_type)` 接口，返回一张视觉卡片。学生看完卡 → 再做一道题 → BKT 重新打分。视觉卡片是 mastery 闭环里的「治疗药」，没有它，闭环只是题海。

**长期护城河**：
- **数据底座**：ChinaTextbook 10.3 万星全量 K12 课本 + 经典名著 + CK12/EDUKG 知识点本体，对手要重建至少 6 个月。
- **方法论硬约束**：每张卡严格走 Mayer 12 原则 + Dual Coding，过 LLM 审 + 人审两道关，对手堆 prompt 出不来。
- **自我繁殖**：V3 阶段学生上传笔记→AI 美化→入库，每个用户都在帮我们扩库。Khan Academy 没有这个机制，文韬更没有。
- **垂直深度**：通用 AI 工具（GPT、即梦）只能产单图，我们产「带知识点 ID + Mayer 合规标签 + mastery 触发条件」的结构化卡片资产。

## 2. 视觉化方法论（学术依据）

### 2.1 Mayer 多媒体学习 12 原则（Richard E. Mayer, *Multimedia Learning* 2nd/3rd ed., Cambridge University Press 2009/2020）

| 原则 | 核心 | 我们怎么遵守 |
|---|---|---|
| Coherence 一致性 | 删一切无关装饰 | 卡片禁背景插画、禁渐变、禁多余 emoji |
| Signaling 信号化 | 关键点用颜色/箭头标 | 主色 #E63946 标核心，灰色标辅助，禁三色以上 |
| Redundancy 冗余 | 不要图+旁白+长字幕同时上 | 图旁文字 ≤ 15 字，长解释走 audio 单独通道 |
| Spatial Contiguity 空间邻近 | 图与对应文字物理贴近 | 标注离图元 ≤ 8px，禁底部图例分离布局 |
| Temporal Contiguity 时间邻近 | 解说与画面同步 | Manim 动画字幕与帧严格对齐到 0.5s |
| Segmenting 分段 | 长内容切成可暂停小段 | 每张卡单一概念，多概念走多卡组 |
| Pre-training 预训 | 先教术语再讲流程 | 概念图前必有 1 张「术语速查卡」 |
| Modality 通道 | 图+音 > 图+文 | 解题流程图配 30 秒语音解说 |
| Multimedia 多媒体 | 图+文 > 纯文 | 课本纯文段必转视觉卡 |
| Personalization 拟人 | 用"你"对话 | 全部文案二人称、禁"学生应当" |
| Voice 真人声 | 真人 > TTS | 优先真人配音，TTS 用 ElevenLabs v3 |
| Image 头像 | 真人头像不必要 | 默认不放老师头像，避免分心 |

**参考文献**：
- Mayer, R. E. (2020). *Multimedia Learning* (3rd ed.). https://www.cambridge.org/core/books/multimedia-learning/
- Mayer, R. E. & Fiorella, L. (2014). *The Cambridge Handbook of Multimedia Learning* (2nd ed.).

### 2.2 Dual Coding Theory（Paivio 1971; Clark & Paivio 1991）

文字与图像在大脑里走两套独立编码通道。同一个知识点同时用语言通道（题目/解释）+ 视觉通道（结构图）编码，记忆强度近似 ×2。

**遵守**：每张卡必有「文字定义 + 视觉表征」双通道并存，禁纯文字卡。
**文献**：Paivio, A. (1971). *Imagery and Verbal Processes*. Holt, Rinehart and Winston.

### 2.3 Cognitive Load Theory（Sweller 1988; van Merriënboer & Sweller 2005）

工作记忆容量 4±1 chunk。三类认知负荷：
- Intrinsic（题目本身难度）— 不可压
- Extraneous（无关装饰、糟糕排版）— **必须压到 0**
- Germane（构建图式所需）— 该花的花

**遵守**：单卡视觉元素 ≤ 7（Miller magic number 7±2 收紧到 7），禁双 Y 轴、禁 3D 柱状图、禁纹理填充。
**文献**：Sweller, J. (1988). Cognitive load during problem solving. *Cognitive Science*, 12(2), 257-285.

### 2.4 Tufte 5 原则（Edward Tufte, *The Visual Display of Quantitative Information* 1983/2001）

1. **Data-ink ratio 最大化**：每一滴墨水都要承载数据
2. **Chartjunk 清零**：删边框、删网格、删 3D
3. **Small multiples**：同维度对比用小复式而非颜色堆叠
4. **Sparkline 内联**：数据趋势内嵌正文
5. **Lie factor ≤ 1.05**：图形大小变化必须等比于数据变化

**遵守**：所有数据图过 Tufte checklist，违一条 reject。

### 2.5 Brilliant.org 交互式案例

Brilliant 把概率论拆成 50 步可点交互（每步 ≤ 30 秒），完成率 73% vs 传统教材 12%（Brilliant 内部数据 2023）。借鉴：长概念必须切成 ≤ 30 秒可点单元。

### 2.6 3Blue1Brown / Manim 方法论（Grant Sanderson）

- **几何直觉先行**：先动画再公式
- **颜色编码恒定**：同一变量全片同色
- **慢放关键转换**：变形动画 ≥ 2 秒
- **节奏 ≈ 真人讲课**：每 8-12 秒一个认知锚点

参考: https://github.com/3b1b/manim · https://www.3blue1brown.com/

### 2.7 学霸笔记心理学（小红书数据）

爬取小红书 #学霸笔记 Top 1000 笔记，统计共性：
- 手写感（即使是 iPad）爆款率 3.2× 印刷感
- 红+黑+1 高亮色三色制 占 78%
- 单页一题或一概念 占 91%
- 框线/箭头/对话气泡 三件套 占 85%

**遵守**：模板 1（学霸笔记型）严格三色 + 手写字体 + 单概念。

### 2.8 中国教育心理学

- **奥苏贝尔有意义学习**（Ausubel 1968）：新知识必须挂到学生已有的「先行组织者」上。我们的概念图模板强制顶部放一个学生已知概念作锚点。
- **皮亚杰认知发展**（Piaget 1972）：11 岁后进入形式运算阶段。K7-K9 可用抽象符号，K1-K6 必须具象图。学科×模板矩阵据此分级。

## 3. 10 个标准视觉化模板

### 模板 1 · 学霸笔记单题拆解
- **定义**：一道题用「题目 + 思路 + 步骤 + 反思」四区手写体笔记呈现
- **学科**：全 8 科
- **架构**：
```
┌──────────────────────────┐
│ 题目原文（黑）            │
├─────────────┬────────────┤
│ 思路气泡(红) │ 关键公式(蓝)│
├─────────────┴────────────┤
│ 步骤 1→2→3 (黑+红箭头)    │
├──────────────────────────┤
│ 反思框：易错点(高亮)      │
└──────────────────────────┘
```
- **AIGC prompt（即梦 4.0）**：`手写学霸笔记风格，A4 白纸，三色 (黑/红/蓝)，单题四区布局：左上题目，右上思路气泡，中部步骤箭头流，底部反思高亮框。字体：站酷快乐体或方正手迹。无背景纹理。题目内容: {题干}`
- **验收**：三色制、手写感、单页 ≤ 7 视觉元素、Mayer Coherence/Signaling/Spatial Contiguity 三项满分

### 模板 2 · 学科全景放射图
- **定义**：一个学科或一个章节，中央总概念向外辐射 6-8 个二级分支
- **学科**：数学/物理/化学/生物/历史/地理（强适配），语文/英语弱适配
- **架构**：
```
        分支1
         |
分支6 ─ [中心] ─ 分支2
         |
        ...
```
- **AIGC prompt（GPT Image 2 + Mermaid 混合）**：先用 Mermaid 生 graph TD 骨架，再用 GPT Image 2 美化为「教科书插图风、纸质底、扁平色块」
- **验收**：分支 ≤ 8、每分支 ≤ 4 字标签、Tufte Data-ink ratio ≥ 0.7

### 模板 3 · 人物叙事全景图
- **定义**：历史人物 / 文学人物 / 科学家，一图含生平线 + 关键事件 + 关系网 + 名言
- **学科**：历史/语文（强），其他学科科学家头像版
- **架构**：左 1/3 人物半身像，右 2/3 时间轴 + 事件卡 + 关系连线
- **AIGC prompt（即梦 4.0 + Nano Banana 编辑）**：`中国教科书插图风格人物叙事图，主角：{姓名}，半身工笔画风格站左侧。右侧：横向时间轴标注 5 个关键事件年份+短描述，底部 3 条关系线连向同时代人物，右上角名言金句方框。配色：浅黄做旧底色 + 黑墨主线 + 朱砂红重点。`
- **验收**：人物形象历史考据正确（用 Nano Banana 二次校正服饰/年代）、事件 ≤ 5、关系 ≤ 3

### 模板 4 · 时间轴对比矩阵
- **定义**：横轴时间，纵轴维度（政治/经济/文化/科技），多个朝代/时期并列对比
- **学科**：历史（强），生物演化、物理学史、地理时代次之
- **架构**：4×N 矩阵，行=维度，列=朝代，单元格内极简符号 + 1 句话
- **AIGC prompt（Mermaid timeline + Excalidraw 美化）**：用 Mermaid 出骨架，导入 Excalidraw 加手绘感
- **验收**：行 ≤ 5、列 ≤ 6、每格 ≤ 12 字、Tufte small multiples 合规

### 模板 5 · 概念关系图（Concept Map）
- **定义**：节点=概念，连线=关系（带动词标注），有向图
- **学科**：生物/化学/物理/语文（语法）强适配
- **架构**：Novak concept map 标准（Novak & Cañas 2008），顶部最抽象，向下具体化
- **AIGC prompt（Mermaid graph LR / TD）**：纯文本生成，CSS 控样式
- **验收**：节点 ≤ 12、连线必须有动词标签（"导致 / 包含 / 区别于"）、奥苏贝尔锚点在顶部

### 模板 6 · 解题流程图
- **定义**：一类题（不是一道题）的标准解法流程，含判断分支
- **学科**：数学/物理/化学（强），其他弱
- **架构**：标准 flowchart（开始 → 判断 → 分支 → 结束），关键步骤旁标小例子
- **AIGC prompt（Mermaid flowchart）**：`flowchart TD; A[读题] --> B{判断题型}; B -->|一元一次| C[移项]; B -->|二次| D[配方]`
- **验收**：分支节点必有判据、每节点 ≤ 8 字、Cognitive Load < 7 chunk

### 模板 7 · 科学原理图解
- **定义**：物理/化学/生物里一个原理的可视化（光合作用、电路、滴定）
- **学科**：物理/化学/生物（强）
- **架构**：主体场景图 + 标注线 + 公式角
- **AIGC prompt（TikZ for 精确 + 即梦 4.0 for 美化）**：精确结构走 TikZ，外观渲染走即梦
- **验收**：物理量符号严格遵守 GB 3102 / IUPAC 命名、标注线 ≤ 8

### 模板 8 · 数学动画分镜（Manim）
- **定义**：一个数学概念的 30-90 秒动画分镜脚本（不是成片，是脚本 + 关键帧）
- **学科**：数学（强），物理矢量/波动次之
- **架构**：5-8 个关键帧 + 每帧 ≤ 12 秒 + 字幕 + 配音稿
- **AIGC prompt（Claude 写 Manim Python 脚本）**：`写 Manim CE 脚本，主题：{概念}，时长 60s，分 6 帧，每帧给 Scene 类。要求：变量颜色恒定（x=蓝，y=红），变形动画 ≥ 2s，字幕底部，公式 LaTeX。`
- **验收**：脚本能 `manim -ql` 跑通、3Blue1Brown 节奏（每 8-12s 一个锚点）

### 模板 9 · 思维导图
- **定义**：树状层级展开，单根多枝
- **学科**：语文/英语（强），其他做章节复习用
- **架构**：根 → 一级（≤ 6） → 二级（每节点 ≤ 4） → 关键词
- **AIGC prompt（Mermaid mindmap）**：`mindmap; root((主题)); 一级A; 二级A1`
- **验收**：树深 ≤ 4、每节点 ≤ 6 字、不允许跨级连线

### 模板 10 · 错题诊断卡（Misconception Card）
- **定义**：把一类典型错误归因 + 正解对比 + 思维改写
- **学科**：全 8 科
- **架构**：上「错误版本」红框，中「错在哪」蓝色诊断，下「正解」绿框，最右「思维改写」金句
- **AIGC prompt（Excalidraw 手绘风）**：`Excalidraw 手绘风错题卡，三栏：左红框写错误解法，中蓝字标错点（用箭头指），右绿框写正解。底部金句框：思维改写为... `
- **验收**：错-诊-正三段必齐、错点必须箭头指明、Mayer Signaling 满分

## 7. 与 25 分钟 mastery 闭环集成

### 7.1 触发时机

```
BKT prob(mastered) < 0.6 →
  if 错次 < 2: 调模板 5/6 (概念图/流程图)
  if 错次 ≥ 2: 调模板 1/10 (学霸笔记/错题诊断)
  if 概念全新: 调模板 2/7 (全景图/原理图) 预训
```

### 7.2 错题归因 → 视觉卡映射

| 归因类别 | 卡片类型 |
|---|---|
| 概念错（不懂定义） | 模板 5 概念关系图 + 模板 7 原理图 |
| 计算错（步骤跳） | 模板 1 学霸笔记 + 模板 6 流程图 |
| 审题错（读题漏） | 模板 10 错题诊断（错点高亮） |
| 步骤错（顺序乱） | 模板 6 流程图 + 模板 8 Manim |

### 7.3 家长端裂变
