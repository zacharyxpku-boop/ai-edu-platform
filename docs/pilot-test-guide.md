# 原点智学封闭试用指南

## 产品一句话

学校给全班同一份任务，原点老师团给每个孩子一条自己的晚间学习路线；孩子今天选择谁，谁就陪他把这条路线走完。

## 本轮试用验证什么

本轮只验证一件事：孩子和家长是否能自然理解并走完这条路线：

排顺序 -> 说第一步 -> 修卡点 -> 轻回访 -> 整理给家长看

同时观察三层叙事是否清楚：

- Tonight Route：今晚先做什么、卡住后怎么走。
- 今日陪伴老师：孩子选择的是陪伴方式，不是功能入口。
- 成长记忆：每晚的路线、卡点和回访，会沉淀成下一次更懂孩子的线索。

## 家长版介绍

原点智学不是拍题搜答案，也不替孩子写作业。它先帮孩子把今晚学校任务排成一条能走下去的路线；卡住时，不直接给结果，而是让孩子先说出第一步。

孩子可以选择今天想让谁陪自己。原点老师团里的每位老师都能陪完整路线，只是陪伴方式不同：小原帮孩子理顺，问问陪孩子多想一步，安安让孩子别慌，阿衡记得孩子以前卡在哪，团团帮孩子把学习过程讲给家长听，跃跃把回访变成一小关。

老师的语气会变，但教学规则不变：不直接给答案，不替孩子完成作业，不把学校任务变成补课课表。家长最后看到的是孩子和老师一起整理出来的小结：今晚先修哪个卡点、孩子原话是什么、家长只需要问哪一句。

## 孩子版介绍

今天可以选一位老师陪你。不是选功能，也不是选学科老师，而是选今天想被怎么陪。

- 想先理顺一点，可以选小原。
- 想多想一步，可以选问问。
- 今天有点累，可以选安安。
- 想让老师记得你以前卡在哪里，可以选阿衡。
- 想把今天学了什么讲给家长听，可以选团团。
- 想轻轻闯一小关，可以选跃跃。

不会也可以先说一句，不用一次做完所有题。先排顺序，卡住时说第一步，只修一个最关键的卡点，修完后轻轻回访一下，最后把今天学了什么整理给家长。

## 试用前配置检查

当前仍需真实 AppID 和真机验收。拿到真实 AppID 后运行：

```powershell
npm.cmd run miniapp:appid -- wx你的AppID
```

然后在微信开发者工具导入 `miniprogram/`，进行真机预览和体验版上传。

## 真机检查清单

### 作业点拨

- 首屏是否仍然回答“今晚从哪一步开始”。
- 主 CTA 是否仍是“帮我安排今晚学习”。
- “今天想让谁陪你？”是否只是轻入口，没有抢输入框和主 CTA。
- 展开后是否像陪伴方式选择，而不是功能选择或角色游戏页。
- 首页是否没有老师六宫格、大角色卡或学科老师入口。

### 错题闭环

- 首屏是否只表达“今晚只修一个卡点”。
- 是否能看到低压力表达：不是整题不会，只是卡在某一步。
- 是否清楚展示对应修法：先说第一步，再做一道小变式。
- 主 CTA 是否仍是“开始 5 分钟修复”。
- 完成后是否引导去轻回访，而不是出现第二个任务中心。

### 知识游乐场

- 是否明确是“修过的卡点，轻轻回访一下”。
- 回访文案是否跟随当前陪伴老师，而不是固定阿衡或跃跃。
- “开始试玩”是否仍是唯一强主 CTA。
- “想练自己的内容？”是否下沉，不抢回访主线。

### 我的页

- 家长 5 秒内是否能记住：今晚先修哪个卡点，我该问哪一句。
- “家长只问一句”是否足够突出。
- “本周卡点记忆”是否是一张轻卡，而不是成长 dashboard。
- 老师建议、成长卡、分享入口是否继续下沉。
- 我的页是否跟随孩子选的今日陪伴老师，没有强制切回团团或阿衡。

## 一条完整试用路径

建议测试输入：

```text
今晚 45 分钟
数学应用题 3 道，明天必交
英语单词 10 分钟，明天听写
数学拓展题 2 道
我不知道应用题下一步怎么列式
```

预期路径：

1. 孩子在作业点拨里输入今晚任务或卡住点。
2. 孩子可以轻量选择“今天想让谁陪你”。
3. 系统生成今晚路线，并结合最近卡点说明为什么这样排。
4. 孩子说出第一步或卡住点，形成 `todayFocus`。
5. 错题闭环只修一个关键卡点。
6. 完成小动作后生成 `reviewCard`。
7. 知识游乐场做轻回访。
8. 我的页整理给家长看，并沉淀“本周卡点记忆”。

## 已知限制

- 不支持拍照识别。
- 不支持 OCR。
- 不支持 PDF / PPT / Anki / Quizlet 导入。
- 不直接给答案。
- 不替孩子写作业。
- 不替代学校和老师。
- 老师团不是完全自由角色扮演。
- 当前仍需真实 AppID 和人工真机验收。

## 包装禁区

封闭试用、家长说明和对外材料中，不要把产品写成：

- AI 解题老师
- 秒解
- 拍照出答案
- 学科名师
- 清北老师
- 状元老师
- 完全自由定制角色
- 游戏陪聊

正确说法是：原点老师团是陪孩子走完整晚间学习路线的 AI 陪学老师团，区别是陪伴方式，不是学科分工或功能分工。

## 成功标准

- 70% 家庭能走完一条 Tonight Route。
- 70% 家长能复述“孩子今晚卡在哪里，我该问哪一句”。
- 60% 孩子知道“今天想让谁陪你”是在选陪伴方式。
- 家长不把老师团理解成学科补课入口。
- 孩子不把老师选择理解成游戏角色扮演。
- 用户能理解系统为什么不直接给答案。
