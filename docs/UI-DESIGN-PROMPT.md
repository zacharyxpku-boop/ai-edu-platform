# 原点学伴 UI Design Prompt

## 目标

把原点学伴做成一款更像头部教育 App 的小程序，不是工具堆，也不是 AI 展示板，而是一个孩子愿意打开、家长愿意相信、投资人一眼能懂主线的学习产品。

## 竞品参考

### Gizmo 要学什么

- 学习材料可以被快速转成可玩的学习包
- 首页像挑战和进度，不像后台
- 游戏化是服务复习，不是表面贴皮
- 每一次输入都能回到卡片、测验、连续打卡、奖励闭环

### Khanmigo 要学什么

- 像真正老师，不像会秒答的机器人
- 先问、再引导、再给最小提示
- 不替写答案，有边界感
- 家长和老师能看懂系统在怎么带学

## 原点学伴的设计立场

- study quest, not dashboard
- learning pack factory, not tool market
- parent proof, not data cockpit
- Socratic tutor, not answer bot
- China family homework triage, not generic edtech

## 一眼要看懂的三件事

1. 今晚孩子先做什么
2. 任意学习材料怎么变成学习包
3. 家长为什么能相信这不是又一个聊天机器人

## 页面角色

### 首页

- 第一屏只讲今晚先做什么
- 要有挑战感、任务感、连续感
- 不能像功能总览页

### 学习包

- 主叙事必须是粘贴材料到生成学习包
- 工具是入口，不是主角
- 输出必须具体到知识卡、测验、复习计划、家长摘要

### 原小点

- 视觉气质安静、可信、像老师
- 明确写出不代写答案
- 每一步都强调孩子先说

### 雷达

- 雷达不是图表展示，而是家长今晚决策页
- 必须回答：当前弱点、今晚先做、几天后如何变好、今晚看什么证据

### 复习

- 更像闯关，不像卡片数据库
- 只推今天最该复习的内容
- 把生命值、连续天、XP、挑战卡做成轻游戏感

### 我的

- 更像家长周报和信任中心
- 展示学习资产、思考证据、同步状态、上架准备
- 少一点配置味，多一点结果感

## 文案规则

- 少说引擎、中台、工厂、资产、benchmark、mode 这类工程词
- 多说今晚先做、为什么先做、做完会留下什么
- 孩子端讲任务和挑战
- 家长端讲证据和减负

## 视觉规则

- 配色延续原点学伴当前米白 + 深绿 + 暖金，但层级更克制
- 卡片不要全都同等级
- 重点区域用深色大底，次级信息收在浅底
- 移动端优先，避免三列高密度数字墙
- 每页至少有一个现在就做的主 CTA

## 这轮改造的验收标准

1. 用户 5 秒内知道产品主线
2. 首页不会再给人乱和功能太多的感觉
3. 学习包页像主产品，不像工具列表
4. 雷达页能给家长行动建议，不再鸡肋
5. 原小点更像老师，不像普通聊天页
6. 复习页更接近 Gizmo 的轻游戏化节奏

## 第三轮截图级评审 Prompt

以产品市场负责人和真机 UI 审稿人的标准逐页检查，不问“功能有没有”，只问“用户能不能立刻行动”。

### 300 客户模拟分层

- 120 个焦虑家长：晚饭后只有 30 分钟，最怕孩子做很多但没效果
- 90 个中小学生：不想读说明，想立刻知道点哪个、做什么、多久结束
- 45 个老师/机构用户：关心是否会代写、是否能沉淀错因和复习证据
- 30 个投资人/合作方：关心是不是独立产品，不是 AI 功能堆
- 15 个审核/合规视角：关心是否夸大提分、是否诱导代写、是否保护未成年人

### 逐页判定标准

首页：
- 首屏必须在 5 秒内说清：先判断今晚最该做什么，再让原小点辅导，再进入复习闯关
- 不展示过多同级入口
- 主 CTA 必须明显

学习包：
- 首屏必须是“粘贴材料 -> 生成学习包”
- 入口列表只能作为辅助，不得压过生成器
- 生成按钮必须比样例/预览更像主动作
- 不允许保留隐藏重复工作台

原小点：
- 必须像老师开场，不像聊天机器人
- 必须明示先让孩子说第一步
- 答案捷径和家长证据要在第一屏可感知

雷达：
- 必须回答家长今晚验收什么
- 雷达图只能做辅助，不得成为主内容
- 每个弱点都要导向行动或证据

复习：
- 必须像 5 分钟闯关，不像卡片管理后台
- 主流程是到期卡、测验、错因修复
- 高级设置必须留在第二层

我的：
- 必须像家长周报和信任中心
- 不应像账号后台
- 同步/AppID/内测信息必须退到高级设置

### 本轮必须修正

1. 学习包页清掉隐藏重复块
2. 生成按钮前置到样例和预览之前
3. 工具入口降级为其他高频入口
4. 首页首屏故事保持但避免压过今日挑战
5. 雷达和原小点继续强化“今晚只看一句证据”

## 第四轮截图级 UI Polish Prompt

以 300 个真实手机用户的第一眼为准，不再问“能力是否完整”，只问“用户是否知道下一步点哪里、为什么值得信任”。

### 家长侧判断

- 第一屏必须像“本周孩子怎么变好”的周报，不像账号后台。
- 家长最需要的不是更多指标，而是一句今晚可验收的话。
- 账号、同步、AppID、内测、商业化、上线清单只能作为高级设置，不得抢主线。
- 证据卡最多突出 3-4 个，其余资产放到第二层。

### 孩子侧判断

- 首页和复习页要像任务/闯关，不像产品说明书。
- 学习包页首屏必须是“粘贴材料 -> 生成学习包”的单一动作。
- 原小点必须先问孩子第一步，避免像普通聊天机器人。

### 本轮验收

1. Profile 第一屏改成家长信任中心：一句结论、一句验收、两个主操作、少量证据。
2. Profile 的同步/上线/内测/商业化等运营信息继续下沉到更多设置。
3. 每页至少有一个明确主 CTA，且标题不超过手机首屏可承受的信息量。
4. 减少同权重卡片，保留“主任务 + 证据 + 下一步”的节奏。

## 第五轮学生真机截图 Prompt

这轮只站在 300 个学生的第一眼，不替家长、投资人或审核人员优化。判断标准是：孩子打开手机后 3 秒内是否知道“现在点哪里开始”，30 秒内是否愿意继续。

### 300 学生分层

- 120 个小学高年级：怕长说明，喜欢明确任务、进度条、奖励反馈。
- 90 个初中生：抗拒家长味和说教味，希望少点字、快点进入错题/复习。
- 45 个临考学生：只关心今天最该补什么，不能被完整能力看板分心。
- 30 个自学型学生：愿意粘贴材料，但要马上看到卡片、小测和复习计划。
- 15 个低动力学生：需要“5 分钟就能结束”的入口，不接受复杂配置。

### 学生侧截图审稿标准

- 首页首屏必须像任务起点，不像说明书；状态信息不超过 3 个。
- 学习包页首屏必须让“生成学习包”成为唯一主动作，样例和导入降级。
- 复习页必须像闯关入口，首屏不能同时出现太多看板、参照和高级词。
- 原小点首屏必须像老师在旁边问第一步，但文案要短，避免压迫。
- 作业录入页必须让学生知道“写三行也能开始”，不要像表单作业。

### 本轮必须修正

1. 首页故事条从三段横排改成更轻的进度带，避免压过今日任务。
2. 首屏大标题字号略降，保留高级感但减少移动端压迫。
3. 学习包输出三列改为主输出 + 两个次输出，降低拥挤。
4. 复习闯关 CTA 改成单主双辅，降低学生选择负担。
5. 原小点首屏缩短信任标签和教师开场，先让孩子开口。

## 第六轮深层产品/UI 审稿 Prompt

这一轮不再只问“挤不挤”，而是问产品是否形成学生愿意重复打开的心理闭环：有明确起点、低启动成本、短反馈、可见进步和下一次回来理由。

### 核心判断

- 学生不为“AI 能力”打开产品，只为“现在少受点苦、快点做对、看到一点进步”打开。
- 家长证据、数据飞轮、竞品参照、同步状态都重要，但它们属于成人层，不应该污染学生主路径。
- Gizmo 的价值不是卡片多，而是“我丢进去东西，马上变成一局可以玩的复习”。
- Khanmigo 的价值不是讲得多，而是“它不会替我写，但能把我卡住的第一步扶起来”。
- 原点学伴的差异不是又一个 AI tutor，而是“今晚只做最关键的一小步，错因进入长期复习”。

### 300 学生真实反应预测

- 如果第一屏有 5 个以上同权重入口，60% 会直接乱点或退出。
- 如果按钮文案像后台功能，40% 会认为这是给家长看的。
- 如果输入框暗示要整理很完整，低动力学生会放弃。
- 如果复习页没有“多久结束”，学生会默认很累。
- 如果原小点首屏像老师训话，学生会抗拒；像陪做第一步，接受度更高。

### 本轮必须修正

1. 所有学生主入口只保留“现在开始 / 5分钟 / 粘贴一段 / 说第一步”这类低阻力语言。
2. 首页 sticky quick dock 第一项必须更大，其他入口降级。
3. 学习包的样例、导入、预览必须弱于生成，不得形成三个同级按钮。
4. 复习页首屏要把“今天只做一局”讲清，不展示过多高级复习概念。
5. 成人/运营/上架/同步词保留在高级层，但默认首屏不出现。

## 第七轮真实截图检测 Prompt

本轮必须产出截图，不允许只做代码推断。若微信开发者工具 CLI 不可用，则使用 Chrome 移动端预览器生成接近小程序第一屏的视觉截图，再按截图逐页修正。

### 截图审稿标准

- 首页：第一眼是否有爆品钩子，学生是否知道“点哪里开始”，首屏是否像任务而不是说明。
- 学习包：是否一眼看出“粘贴一段 -> 生成学习包”，主按钮是否压倒样例/导入。
- 复习：是否像 5 分钟一局，生命值/XP/进度是否形成轻游戏感，不能像数据库后台。
- 原小点：是否像陪做第一步，不像训话老师或普通聊天工具。
- 作业录入：是否低门槛，学生是否相信写三行也能开始。
- 雷达：对学生可以退居二线，对家长必须能看懂今晚先做什么。
- 我的：默认应该是家长信任报告，不是账号配置页。

### 截图失败即修正

1. 首屏主 CTA 不明显，立刻加重。
2. 文案超过两行且不服务当前动作，立刻压缩。
3. 三列小卡或小字密集，改为 1+2、横向滑动或折叠。
4. 辅助入口和主入口同权重，辅助入口降级。
5. 任何成人/后台词出现在学生第一屏，改文案或下沉。
