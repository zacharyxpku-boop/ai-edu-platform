# 原点智学技术壁垒路线图

## 当前定位

原点智学不是通用 AI 私教，也不承诺固定提分。当前产品定位是家庭学习决策系统：把测评、错题和作业清单转成可执行的弱点雷达、作业三分类和原小点短时陪练。

核心闭环：

```text
测评/作业录入 -> 雷达弱点 -> 作业三分类 -> 原小点只处理“必须做”和“关键错因” -> 家庭反馈校准
```

## 已落地壁垒

### 1. 错因 taxonomy

系统不只看“题目错了”，而是沉淀错因标签，覆盖审题、建模、计算、表达、复盘等方向。错因会进入：

- 能力雷达弱点解释
- 作业优先级排序
- 原小点陪练上下文
- 家庭反馈校准数据

### 2. 作业价值排序向量

每项作业都有 `priority_vector`，把错因相关度、弱点匹配、核心任务、迁移训练、复盘价值、低收益任务等因素拆开。这样后续可以从规则排序逐步升级为数据驱动排序。

### 3. 家庭反馈校准

家长可以标记“准/不准”。反馈会保存 `calibration_key`、`priority_vector`、`misconception_tags`，用于后续训练“这个家庭/年级/题型里什么判断更准”。

### 4. 原小点掌握循环

原小点不做泛聊天，固定五步掌握循环：

```text
读题 -> 找条件 -> 写第一步 -> 说错因 -> 复盘
```

当孩子要答案或代写时，系统拒绝并回到“写第一步”。这吸收 Khanmigo 的苏格拉底式引导，也吸收 Alpha School 的短时高密度学习原则。

## 下一阶段

### MVP 验证

目标是 20 个家庭完成连续 2 周验证，重点看：

- 每晚节省多少低收益作业时间
- 必须做任务完成率是否提高
- 孩子能否说清关键错因
- 家长是否愿意每周看复盘

### 数据产品化

当反馈量足够后，进入三层升级：

- 规则引擎：当前已实现，可解释、低成本、稳定
- 校准引擎：用家庭反馈修正排序权重
- 个体模型：按学生长期错因、作业类型和完成表现生成个性化策略

### 小程序上架边界

首版不做 OCR、不做支付、不做课程售卖、不承诺提分。只做手动录入、AI 辅助决策和思路引导，降低审核和合规成本。
