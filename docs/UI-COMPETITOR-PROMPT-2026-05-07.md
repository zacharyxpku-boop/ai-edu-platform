# 原点智学竞品级 UI Prompt

## 设计判定

这一轮不再允许“同一个深绿 hero 换文案”。每个主页面必须拥有不同的产品形态，让截图一眼能看出它承担的任务。

## 竞品转译

- 复习类产品：材料进入后要快速变成卡片和小测，复习像一局轻游戏。
- AI 导学产品：AI tutor 不直接给答案，用追问、提示和第一步引导保护学生思考。
- 学习工具产品：输入框就是产品入口，上传/粘贴后产出作业帮助、笔记卡片、测验和复习计划。

## 原点页面形态

- Home：任务起点。浅色、玩具感、一个今日任务、一个强 CTA，像“先赢一小局”。
- Tools：输入工厂。首屏就是粘贴/输入；工具入口只做辅助，不做工具市场。
- Review：闯关式复习。深蓝紫、进度条、卡片题面、生命值、5 分钟结束。
- Tutor：陪做式导学。聊天气泡、第一步追问、不代写边界、原小点陪伴感。
- Upload：低门槛表单。强调写三行也能开始，不让学生觉得要整理完美材料。
- Radar：家长行动页。雷达图退居二线，首屏回答今晚先做什么、为什么、验收什么。
- Profile：家长信任中心。不是账号后台，而是本周进步、证据分、复习资产和安全轮次。

## 截图失败即修

1. 如果 7 张截图看起来像同一套模板，失败。
2. 如果首屏看不到唯一主 CTA，失败。
3. 如果学生页面出现太多家长/后台/资产/飞轮词，失败。
4. 如果 Tools 首屏不像输入入口，失败。
5. 如果 Review 首屏不像一局可完成的 quiz/flashcard，失败。
