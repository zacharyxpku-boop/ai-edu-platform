# 产品状态与收束路线

日期: 2026-05-24

## 结论

原点智学现在已经不是“功能集合”，而是一个**可解释的家庭晚间作业闭环雏形**：

> 卡住 -> 说出第一步 -> 修卡点/小课堂 -> 轻回访 -> 家长 5 秒复盘 -> 回到首页下一步

但它还不是成熟上线产品。当前最主要的风险不是能力缺失，而是：

1. 首屏仍然有多条并行叙事，容易重新长回“工具集”。
2. 真实 AppID、真机验收、外部验证还没完成。
3. 轻回访、家长报告、社交/游戏化、低龄入口这些端口已经存在，但还需要继续收束，防止各讲各话。

## 现在已经成立的闭环

### 1. AI 私教 / Khanmigo 式引导

- 代码里已经有 `tutor` + `tutor-ladder` 的三问收束边界。
- 明确拦截“直接答案 / 完整过程 / 代写”。
- 作用是帮孩子说出第一步，而不是替孩子做题。

### 2. 小课堂入口

- 首页已经有 `miniLessonResume` 回流。
- `review` / `focus` / `home` 之间能把“小课堂”当成第一步恢复失败时的补口。
- 这个入口现在是补位，不是主叙事。

### 3. 回忆复习 / 游戏化 / 轻社交

- `review`、`tools`、`arcade` 已经把“昨天那一步”变成可回访对象。
- `share-relay` 限制了分享内容，避免完整答案、分数、排行榜和虚假社交。
- 目前这条线是“轻回访”和“主动回忆”，不是社交增长线。

### 4. 家长上传报告 -> 分析 -> 小程序闭环

- `upload` 已经接住作业、测评、错题、报告等材料。
- `learning-report` / `family-report-engine` / `learning-service-pathway` 把材料翻译成今晚动作和后续验证。
- `profile` 负责家长 5 秒复盘，不是报告墙。

## 现在还漏的东西

1. **首页过载**  
   首屏虽然已经有单一主行动，但仍然同时展示 `primaryNextAction`、昨天回访、输入框、能力卡、场景包、统一下一步等多层内容。需要继续压缩，只留“今晚先做什么”。

2. **真实上架前提**  
   现在还是 `touristappid`，不能把体验版/上线说成已完成。

3. **验证证据还不够外部化**  
   代码测试已通过，但还没有 5-10 个真实家庭的使用证据。

4. **轻回访/游戏化/社交的边界还要更硬**  
   现在能跑，不代表不会在后续迭代里长回排行榜、压力、报告墙。

5. **家长端的“5 秒复盘”还要继续去报告化**  
   要继续保证是“一句话 + 一句可问的话”，不是分析面板。

## 产品判断

### 和竞品的差异

如果把竞品理解成“AI 讲题 / 通用陪学 / 家长报告工具”，那原点智学的差异已经比较清楚：

- 我们不是先给答案，而是先收束第一步。
- 我们不是工具箱，而是家庭晚间作业的闭环。
- 我们不是报告墙，而是家长一句话复盘。

### 当前成熟度

- **产品逻辑**：已形成
- **代码闭环**：已形成
- **首屏收束**：部分形成，仍偏重
- **真实上线**：未完成
- **真实家庭验证**：未完成

## 后续实施路线

### 第一阶段: 首屏收束

目标: 把首页彻底收束成“今晚先做什么”。

要做的事:

1. 保留一个主 CTA。
2. 保留一个回流入口。
3. 把能力卡、场景包、统一下一步都降到更深层。
4. 确保首页不会重新长成工具总览。

验收标准:

- 用户 5 秒内能说出今晚第一步。
- 首页不会像功能矩阵。

### 第二阶段: 闭环证据

目标: 把“卡住 -> 第一小步 -> 专注 -> 回访 -> 家长复盘”做成可复用证据。

要做的事:

1. 固化 `first_step_articulated` / `focus_completed_for_step` / `light_revisit_done` / `parent_one_question_read` 等证据名。
2. 让 `upload`、`review`、`focus`、`profile` 使用同一组证据字段。
3. 让报告只翻译证据，不下长期结论。

验收标准:

- 每个端口都能把同一条证据往下游传。
- 不再出现“每页讲一套”。

### 第三阶段: 真实家庭验证

目标: 把闭环从“能跑”变成“能被家庭反复用”。

要做的事:

1. 配真实 AppID。
2. 做真机验收。
3. 跑 5-10 个真实家庭。
4. 看孩子是否愿意说第一步、家长是否少讲答案、次日是否愿意回访。

验收标准:

- 不是“看起来不错”，而是家庭愿意重复用。

## 一句话定位

> 原点智学不是答题工具，不是报告墙，也不是打卡产品；它是中国家庭晚间作业场景里，帮孩子先说出第一步、先坐住一小段、再让家长 5 秒看懂今晚发生了什么的闭环小程序。
