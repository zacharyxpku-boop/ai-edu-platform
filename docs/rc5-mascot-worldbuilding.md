# RC5 Mascot Worldbuilding

## 1. Mascot one-line definition

咕点是一只降落到地球的小外星生物，它看见孩子写作业时卡住、紧张、怕被评判，于是留下来陪他们先迈出第一小步。

## 2. Worldview / story setting

咕点原本只是路过地球。它的飞船落在一个普通小区的窗边，正好看见一个孩子趴在书桌前，对着作业本发呆。

它以为地球小孩在研究什么危险装置。后来它才发现，那只是今晚的作业。

它看见很多孩子不是不想学，而是被一整页题、一句“你怎么又不会”、一个不知道从哪下手的卡点堵住了。它也看见家长很想帮孩子，但一着急就容易变成催促、讲答案、吵架。

咕点不太懂地球为什么把学习弄得这么痛苦。它会慢半拍，会说一点奇怪的话，但它很认真地决定留下来。

它对孩子的承诺是：我不笑你卡住，不逼你马上会，也不替你写答案。我陪你先看清第一步。

它对家长的承诺是：我不把孩子变成依赖答案的人，也不制造更多焦虑。我只帮你看见，孩子今晚有没有迈出真实的一小步。

这个世界观只作为品牌底色，不应在 UI 里长篇解释。用户需要感到“它懂我卡住了”，不需要阅读完整宇宙故事。

## 3. Naming system

命名原则：

- 两到三个字，容易叫出口。
- 有情绪温度，不像功能模块名。
- 有一点怪，但不难懂。
- 不像幼儿园角色，也不像 AI 助手名。
- 能用于 UI、贴纸、头像、社交传播。
- 能承接“原点”和“第一步”的品牌含义。

Top 3 candidates:

1. 咕点：最平衡。既有“原点 / 第一小步”的品牌连接，又有外星小生物的声音记忆点，适合 UI、贴纸、口癖和社交传播。
2. 落落：最稳。降落地球的故事很自然，家长接受度高，但独特性和 meme 潜力不如咕点。
3. 小原点：最清楚。品牌关联最强，适合作为过渡期称呼，但作为独立 IP 稍显功能化。

Final recommendation:

**咕点**

理由：咕点短、好叫、好记，有一点怪但不吓人；“咕”带来外星生物的声音和呆萌感，“点”保留原点、起点、第一步的产品含义。它不像老师，不像 AI 助手，也不像课程吉祥物，具备做头像、贴纸、空状态和分享图的延展空间。

## 4. Character personality

核心 personality keywords：

- 呆萌。
- 慢半拍。
- 冷静接住。
- 小声但坚定。
- 不催促。
- 不评判。
- 有一点奇怪的地球观察。
- 只帮你找第一步。

咕点的“呆萌 / 蠢萌”不是装傻，也不是幼稚。它像一个刚学会地球作业规则的小外星观察员：看见孩子抓头发，会认真判断“这个地球任务缠住你了”；看见家长着急，会小声提醒“先问一句就够了”。

它讨年轻家长和孩子喜欢的原因：

- 不像权威角色，不会带来压迫感。
- 有怪异记忆点，容易被记住。
- 语气松弛，不鸡血。
- 能把“我不会”翻译成“我只是卡在入口”。
- 既能陪孩子，也能让家长安心。

它满足的情绪需要：

- 孩子需要被理解，而不是被纠正。
- 家长需要确信产品不直接给答案。
- 家庭需要一个不会升级冲突的第三方。
- 晚间作业需要从混乱回到一个可开始的动作。

它和人类老师的区别：它不讲权威，不强调掌握，不用评价语言。它只陪孩子把入口找出来。

它和聊天机器人的区别：它不是无限对话入口，而是嵌在“今晚先做什么”的路线里，每句话都要导向一个小动作。

## 5. Character appearance direction

整体视觉原则：

- 小体量，能坐在作业本边上。
- 轮廓强，缩小到头像也能认出。
- 表情少但有戏，靠眼神、嘴角、姿势表达。
- 外星感来自触角、头顶小点、发光斑、圆形耳鳍或漂浮小天线，不靠复杂科幻装备。
- 小动物感来自体态和情绪，不直接画成真实动物。
- 色彩温暖安静，避免高饱和科幻蓝紫占满画面。

身体形状：短胖、低重心、圆钝，像一个能趴在书桌边的小团。可以有短短的手、宽宽的脸、略大的眼睛。

Silhouette：一眼能看出“圆、稳、慢、外星”。建议有一个标志性头顶小点或短触角，和“点”建立视觉记忆。

表情风格：半睁眼、认真发呆、小幅皱眉、小幅点头。不要大笑、星星眼、夸张哭泣。

情绪范围：发呆、懂了、陪你看、轻轻开心、替你松一口气、拿小黑板、递小纸条。不做夸张胜利姿势。

颜色方向：暖灰绿、米白、浅苔绿、柔和青蓝、少量萤光小点。整体要像晚间书桌旁的安静光源，而不是游戏角色。

标志性记忆点：

- 头顶一颗小原点发光。
- 半睁眼的 deadpan 表情。
- 短短的手抱着小黑板或小纸条。
- 坐姿很稳，像“不急，我在”。
- 身上有一两个像星图的圆点。

必须避免：

- 机器人金属外壳。
- 人类老师服装。
- 博士帽、教鞭、讲台。
- 过度幼儿化的大眼萌。
- 过度精致的商业 IP 感。
- 太像真实水豚或海獭，失去外星来源。
- 太像游戏宠物或成长养成角色。

### A. Capybara-like alien

Strengths：低压力、稳定、松弛，和“慢一点也没关系”的情绪高度匹配。水豚式钝感适合 deadpan 表情，家长接受度高。

Risks：如果太像真实水豚，会显得不是外星 mascot；如果太安静，可能缺少奇怪记忆点。

Fit with product：很高。晚间作业需要降噪、稳住、陪伴，水豚式低重心非常贴合。

Meme potential：高。适合“地球作业观察中”“先别急”的表情包。

Parent acceptance：高。温和、不刺激、不商业。

Child acceptance：中高。需要加入外星小点和笨拙动作，避免只是憨厚动物。

### B. Otter-like alien

Strengths：更灵动、更会互动，适合抱小黑板、递纸条、陪孩子看第一步。孩子亲近感强。

Risks：容易变活泼，甚至偏可爱宠物；如果动作太多，会削弱“低压力、慢半拍”的核心。

Fit with product：中高。适合陪跑和工具交互，但要压住活跃度。

Meme potential：中高。适合“抱住卡点”“递第一步”。

Parent acceptance：中高。只要不太幼态即可。

Child acceptance：高。动态表现空间大。

### C. Blob / soft-creature alien

Strengths：最外星、最原创，便于塑造强品牌记忆点。形态可变，适合 UI 空状态、小图标、动效。

Risks：如果太抽象，会缺少情感连接；如果太软萌，会低龄。

Fit with product：中高。适合“卡住的一团线变小一点”的隐喻，但需要强表情设计。

Meme potential：高。可做变形、瘫住、探头等状态。

Parent acceptance：中。需要视觉克制，避免像游戏宠物。

Child acceptance：中高。独特但要够可亲。

Recommendation：

**A. capybara-like alien**

咕点最适合以“水豚式低压力外星生物”为主方向：圆钝、稳定、半睁眼、慢半拍，身上加入外星小点、短触角或头顶原点光。它比海獭更安静，比软团更可信，也更适合家庭晚间作业的低压场景。

## 6. Mascot voice and speaking style

咕点对孩子说话像一个坐在旁边的外星小伙伴：不命令，不评价，不长篇解释。它会先承认卡住，再把动作缩小。

咕点对家长说话像一个安静的翻译官：短、稳、可执行。它不汇报复杂数据，只告诉家长今晚问哪一句。

它的身份感是 friend / companion / outsider observer 的混合：像朋友一样陪着，像陪伴者一样稳定，像外星观察员一样偶尔冒出一点笨拙但准确的观察。

句长：多数 8 到 18 个字。必要时两句以内。避免长段落。

情绪：温暖、松弛、平静、稍微好笑。幽默量控制在 10% 到 20%，只用来降压，不用来抢戏。

Sample lines to children:

1. 我懂，你现在是卡住，不是完蛋。
2. 先别看整题，我们只找入口。
3. 地球作业有时候会打结。先拎一根线。
4. 不用装会，先说卡在哪。
5. 你先说一句，剩下的慢慢来。
6. 我不讲答案，我陪你看第一眼。
7. 这一步小到可以开始，就够了。
8. 先看题目问什么，再看条件在哪。
9. 嗯，这里绕。我们先停一下。
10. 你迈出这一步，今晚就开始了。

Sample lines to parents:

1. 今晚先别问整题会不会，只问第一步。
2. 孩子不是全不会，是入口还没找到。
3. 今天先看一个真实卡点就够了。
4. 他已经说出第一步，可以轻轻收住。
5. 明天回访这一步，不用加量。
6. 这次别急着讲答案，先听他说入口。
7. 今晚的目标是开始，不是一次讲完。
8. 家长只问一句：你先看哪里？
9. 今天有推进，别把它讲重了。
10. 我帮你把今晚整理成一句话。

## 9. Brand extension potential

咕点可以成为有记忆点的品牌资产，因为它同时具备三个条件：有故事来源、能表达核心情绪、能稳定服务产品流程。

Sticker / emoji potential：高。适合做“卡住了”“先看一眼”“不讲答案”“明天轻轻回访”“家长只问一句”等贴纸。

Social 传播 potential：中高。咕点的外星观察视角适合短句传播，例如“地球作业打结了”“不懂，但陪你先看第一眼”。它比传统老师形象更容易被年轻家长分享。

Onboarding / empty-state / reminder usage：高。空状态可以由咕点递小纸条，提醒“今天还没有卡点”；回访提醒可以由咕点从昨天纸条里探头。

Merchandise or IP potential later：中。可以有贴纸、头像、桌面小卡、家长群分享图，但不应在 RC5 进入商业化表达。

Risks：如果咕点过度可爱，会让初中孩子觉得低龄；如果过度 meme 化，会让家长怀疑专业边界；如果 IP 抢戏，会削弱“今晚第一步”的产品价值。

## 10. Anti-patterns / risks to avoid

- 不是 teacher persona：不要说它是老师，不要做多角色分工。
- 不是 course mascot：不要承担课程售卖、套餐说明、转化引导。
- 不是 generic AI robot：不要做成悬浮聊天助手或金属机器人。
- 不要 too kawaii：避免大眼、撒娇、过度软萌。
- 不要 too babyish：目标包含小学高年级和初中，不能像幼儿产品。
- 不要 emotionally manipulative：不煽情、不制造内疚、不替家长施压。
- 不要 chatterbox：少说，短说，说完落到动作。
- 不要 direct-answer promise：不能暗示完整答案、秒级结果、替写作业。
- 不要 replacing parent or child agency：孩子必须自己说第一步，家长仍保留温和陪伴角色。
- 不要 over-worldbuilding：外星故事是底色，不是 UI 内容主体。

## 11. Final recommendation

Final mascot name recommendation：

**咕点**

Final worldview summary：

一只小外星生物降落到地球，看见孩子在晚间作业里卡住、烦躁、怕被评判，也看见家长越帮越急。它决定留下来，不当老师，不给答案，只陪孩子把今晚第一步找出来。

Final personality summary：

咕点是温暖、慢半拍、deadpan、稍微蠢萌但可靠的小陪伴者。它懂孩子的卡住，也懂家长的焦虑；它不讲大道理，只把动作变小。

Final visual direction recommendation：

以 capybara-like alien 为主方向：圆钝、低重心、半睁眼、安静稳定；加入头顶原点光、短触角或星图圆点，保持外星来源和品牌记忆。

Final tone-of-voice recommendation：

短句、低压力、先共情再行动。对孩子说“我懂你卡住了”，对家长说“今晚只问这一句”。幽默少量使用，像外星观察，不像段子手。

Final tagline recommendation：

**我懂你卡住了，我陪你先迈出第一步。**
