## 一、Khanmigo 真实定位（不是想象的版本）

### 不是「免费 AI 学习平台」
他们对 **学生**说：$4/月起的 AI 私教
他们对 **家长**说：「your new parenting hack · 育儿手段」
他们对 **学校**说：District-wide license 集采 + 教师配套培训

**关键洞察**：同一个产品给三种用户三种话术。中国家长视角 = 美国家长视角 ≠ 学生视角。

我们 PoC 期主要打 **家长** 视角（付费方），话术该向「育儿手段」靠拢，不是「学生工具」。

---

## 二、5 句直接能抄的家长话术

按打动家长的概率从高到低排：

1. **「孩子做题它不直接给答案，先问他怎么想」**
   - 原句：Khanmigo doesn't give answers; it helps kids think through problems
   - 我们对应件：粘贴检测 + Think Before Speaking（commit ba073f1 已实现）
   - 落地位：parent-radar 顶部 / welcome.html 卖点列 / 5.4 Demo 30 秒 pitch

2. **「不用你懂数学，老师 24 小时在」**
   - 原句：You don't need to know all the answers—Khanmigo has 20+ parent-tools
   - 中国版改写：「妈妈不用辅导作业，老师替你看着」
   - 直击中国 80 后家长「初中数学早忘了」的真实焦虑

3. **「孩子聊了什么你能看，老师有问题会提醒你」**
   - 原句：You can view your child's chats, get alerts for flagged content
   - 我们当前缺：parent-radar 没有「最近 N 条对话回看」面板（V2 该加）
   - 但有：share_for_mom 一键复制（commit 4d4aaa0）

4. **「这位老师只懂你这一个孩子」**
   - 我们独家差异化（Khanmigo 70 万人用同一个 GPT-4 不可能做到）
   - 6 字段抽取 + 跨会话记忆是技术兑现

5. **「中国课标，不是美式数学」**
   - Khanmigo 用 Common Core，到了中国孩子手里答不出「移项不变号」是哪个考点
   - 我们用人教版 / 北师大版 / 苏科版课标对齐，64 类错题归因走中国教师视角

## 三、Khanmigo FAQ 顺序逆向推（家长心理学路线图）

他们的 FAQ 排序透露设计直觉。他们的递进路径：

```
1. Khanmigo 是什么（解释焦虑）
2. 它能为我孩子做什么（功能列表）
3. 我作为家长有哪些工具（家长侧赋权）
4. 怎么注册 / 给孩子用（操作）
5. AI 教育安全吗（恐惧化解）
6. 多少钱（价格）
7. 孩子怎么激活账户（最后才提学生侧）
```

**关键**：第 5 步「AI 教育安全」放在价格之前——家长恐惧不解决，价格再低不付。

我们的 welcome.html 当前缺这一层。建议 V2 加一个 `/parents` 单独页面按这个顺序铺。

## 四、3 件 Khanmigo 做了我们没做的（V2 借鉴 backlog）

### 4.1 社会证明层级化
他们 hero 下方依次展示：
- 媒体背书 (WSJ / NYT logo)
- 第三方评级 (Common Sense Media 4星)
- 真实家长长评论 (Katie 等具名)

我们当前完全没有第三方背书层。PoC 期 30 学员之后该收集 5-10 条真家长反馈作社证。

### 4.2 安全设计前置（不是事后说明）
他们 hero 下面紧跟「guardrails / monitoring」，把信任前置成产品卖点。我们粘贴检测 / 算术铁律 / 退场处理这些「安全件」都藏在产品内部，没拿出来对家长说。

### 4.3 多孩子账户管理
「最多 10 个孩子账户」让有兄弟姐妹的家庭一个订阅就够。我们当前 welcome 只能注册一个孩子，下次刷新覆盖。多孩子家庭会重复注册，体验断裂。

## 五、3 件 Khanmigo 做不了我们能秒杀的（差异化弹药）

### 5.1 注册门槛
| Khanmigo | 我们 |
|---|---|
| 美国地址 + 18 岁 + 父母授权 + 邮箱验证 + 付费 | 30 秒昵称 + 年级，零隐私收集 |

中国家长 99% 过不了 Khanmigo 的入口门槛。这一刀绝杀。

### 5.2 结构化学习数据可视化
他们家长页**没有**雷达图 / 学情指纹 / 周报这些东西，只给 chat history + alert。
我们 parent-radar 是 KA 没做的——4 维雷达 + 6 字段指纹 + 类比奏效率 + share_for_mom。

### 5.3 中文 K12 语境
- 课标对齐：人教 / 北师大 / 苏科 三套教材 56 本铺开（paths.html）
- 错题归因 64 类：移项不变号 / 漏乘整式项 / 三角函数公式记错（不是「calculation error」）
- 兴趣词典：篮球 / 王者荣耀 / 二次元（不是 baseball / basketball / football）

## 六、不要抄的 3 件

### 6.1 紫色主色
他们用蓝紫调。我们原点橙是 brand asset，不抄不仿。

### 6.2 「Khanmigo」音译式品牌名
中国家长记不住。我们「原点 AI 私教」中文直白可口耳传播。

### 6.3 强调「nonprofit」身份建立信任
中国家长对「非盈利」反应不强烈，反而对「打折」「会员」更敏感。话术换成「PoC 期前 30 名免费」「内测期 9 折」。
