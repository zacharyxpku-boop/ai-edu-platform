# 原点学伴 300 客户模拟反馈摘要

## 结论

高频反馈不是功能不够，而是主线不够聚焦。孩子和家长都更在意第一步、结果和证据，而不是系统有什么能力。

## 孩子侧高频评价

1. 我现在到底先做哪一个
2. 不想看太多按钮，想直接开始
3. 如果是 AI 辅导，不要一上来就像聊天机器人
4. 复习如果像闯关会更愿意点开
5. 材料转学习包这个点很酷，但要更明显

## 家长侧高频评价

1. 雷达不能只是图，得告诉我今晚怎么安排
2. 我关心孩子是不是少走弯路，不是系统分数多高
3. 要看得见证据，比如错因、复述、复习回访
4. 工具太多会让我不知道该点哪个
5. 只辅导必须做是个强差异点，要更突出

## 主要阻塞点

1. 首页信息密度偏高，第一眼主线容易分散
2. 学习包页虽然能力强，但还不够像主产品
3. 雷达页如果不直接导向行动，会被认为可有可无
4. 原小点还需要更强的老师感和边界感
5. 仍有少量英文和工程味词汇破坏成品感

## 本轮修正策略

1. 首页收口到今晚先做什么
2. 学习包页突出粘贴材料到生成学习包
3. 雷达页强化弱点到今晚行动到进步证据
4. 原小点强调只带必须做，不替写答案
5. 清理英文与内部术语

## 第三轮模拟反馈

### 仍然会被吐槽的点

1. 学习包页虽然前置了生成器，但如果还保留隐藏重复块，后续维护会继续混乱。
2. 生成器里“填入样例”排在“生成学习包”前面，会让孩子以为样例才是主动作。
3. “今晚入口”这个标题和首页主线重复，容易让用户以为 tools 页还是工具市场。
4. 家长最需要的是一句可验收的话，而不是更多指标。

### 这轮修正

1. 删除隐藏重复学习包工作台。
2. 把生成学习包作为第一主按钮。
3. 将入口区改为“其他高频入口”，降低工具市场感。
4. 保留雷达和原小点的家长验收句，强化老师式开场。

## 第四轮模拟反馈：Profile 和整体主线

### 300 人会继续吐槽什么

1. 家长看到“我的”页时，仍然会误以为这是账号/配置页，而不是孩子成长报告。
2. 一张大卡里塞入太多证据、资产、建议，会让焦虑家长继续感觉“系统很复杂”。
3. 投资人会看懂数据飞轮，但普通家长不会因为“飞轮”买单，必须先看到孩子今晚能怎么变好。
4. 孩子不关心同步、AppID、上线清单，家长也不应该在主路径里看到这些运营信息。
5. 需要把“Gizmo 式复习成瘾”和“Khanmigo 式不代写”压缩成用户能复述的一句话。

### 第四轮修正策略

1. Profile 第一屏改成“本周进步报告”：一句结论、一句家长验收、两个主操作。
2. 证据卡只展示关键 4 项，学习资产改成更轻的条带。
3. 下一步建议保留，但按钮更像动作卡，不像后台菜单。
4. 高级信息继续收起，默认不打扰孩子和家长的核心路径。

## 第五轮模拟反馈：300 个学生真机进入

### 他们会怎么用

1. 大多数学生先看有没有“开始”按钮，其次才看解释。
2. 如果首页顶部先看到三段故事和很多状态，会跳过文字直接乱点底部入口。
3. 学习包页最吸引人，但学生会担心要输入很多；需要告诉他们“粘贴一段也可以”。
4. 复习页有生命值和 XP 是加分项，但如果卡片/参照/高级设置太多，会像学习后台。
5. 原小点如果开场太正式，会被理解成老师训话；要像“陪你做第一步”。

### 学生侧阻塞点

1. 字太多、卡太多、同级按钮太多。
2. “家长证据”和“数据飞轮”对孩子有价值，但不能放在孩子主路径第一眼。
3. 复习的游戏化已经有雏形，但还要更明确“5 分钟一局”。
4. 作业录入需要给低门槛样例，否则学生会觉得麻烦。

### 第五轮修正策略

1. 首屏减少横向密集信息，用更像进度带/任务卡的方式呈现。
2. 大标题略降字号，避免小屏幕上一个标题占半屏。
3. 主按钮更大，辅助按钮更轻。
4. 学习包、复习、原小点都明确“现在开始一小步”。

## 第六轮模拟反馈：更深一层的产品阻塞

### 300 个学生会怎么评价

1. “我愿意点开始，但别让我先理解你有多少能力。”
2. “学习包挺酷，但样例、预览、导入同时出现时，我不知道哪个才是开始。”
3. “复习如果说一局 5 分钟，我能接受；如果像卡片系统，我会逃。”
4. “原小点如果先让我说一步，我觉得可以；如果讲一堆原则，我会烦。”
5. “家长证据我不反对，但不要一上来给我看。”

### 更深痛点

1. 学生不是反感学习，而是反感不可控、看不到尽头的学习。
2. 学生不是不想用 AI，而是害怕 AI 变成更多作业。
3. 学生不是不需要雷达，而是不应该让孩子承担家长决策页的信息量。
4. 学生愿意被游戏化驱动，但前提是游戏化服务“少做一点也有效”，不是做更多。

### 第六轮修正策略

1. 每页第一屏都要像“一个小局”，而不是“一个系统”。
2. 所有辅助按钮弱化，主按钮视觉重量明显领先。
3. 把“完整、参照、同步、能力”等成人词继续收进高级层。
4. 对低动力学生明确承诺：先做 5 分钟、先粘贴一段、先说一步。

## 第七轮截图审计反馈

### 300 个学生看到截图会先说什么

1. 首页必须先让我感觉“可以开始”，不是“这个系统很复杂”。
2. 学习包如果生成按钮足够大，我愿意试；如果一堆按钮一样大，我会犹豫。
3. 复习页只要告诉我 5 分钟能结束，我愿意点；如果像后台，我不点。
4. 原小点要像有人陪我做第一步，不要像老师训话。
5. 写作业清单不能像填表，最好让我点样例开始。

### 截图审计修正策略

1. 产出每个主页面的移动端 PNG 截图和审计报告。
2. 按截图修正主 CTA、字号、卡片密度、按钮权重和首屏文案。
3. 保留截图产物，后续真机检查可继续对照。
