# RC5 Product Strategy Freeze

## 1. One-line product definition

原点私教是一款面向中国家庭晚间作业现场的微信小程序，帮助孩子和家长在今晚迅速看清“先做什么、卡在哪、第一步怎么说”。

## 2. Core positioning

核心定位：孩子今晚先迈出第一步。

原点私教不把作业变成答案获取，也不把学习变成家长审判。它服务的是一个很窄但高频的家庭时刻：晚饭后，作业摊开，孩子卡住，家长焦虑，双方都需要一个足够小、足够清楚、能立刻开始的下一步。

核心主线应冻结为：

1. 今晚先做什么。
2. 卡在哪。
3. 先看哪里。
4. 第一步怎么说。
5. 明天轻轻回访。
6. 家长 5 秒看懂。

核心用户：晚间陪作业的中国家庭，优先是小学高年级到初中阶段的孩子与主要陪伴家长。

核心用例：孩子遇到作业卡点后，不求完整答案，而是让系统帮他把今晚第一步拆小，并把这一步说出来。

核心 JTBD：当孩子晚上面对一堆作业不知道从哪开始、家长又担心直接讲答案或吵起来时，帮助家庭把混乱收束成一个可执行的第一步。

情绪价值：让家长从“今晚又要崩”回到“今晚先做一小步”，让孩子从“我不会”回到“我知道先看哪里”。

功能价值：承接作业或卡点输入，形成今晚优先步骤、一个真实卡点、小黑板提示、孩子的第一步表达、次日轻回访与家长一句话复盘。

产品必须永远避免成为：

- 直接给答案的作业工具。
- 面向家长炫耀数据的报告型产品。
- 用刺激机制包装学习的产品。
- 老师管理、班级管理或学校后台。
- 商业课程售卖页。
- 泛 AI 聊天壳。

## 3. User segmentation

主要决策者：母亲或主要陪伴作业的家长。她关心的不是功能数量，而是今晚能不能少吵一点、孩子能不能自己开口说出下一步、这个工具会不会把孩子带向抄答案。

主要使用者：孩子。孩子需要感到这是帮他脱离卡住状态，而不是又多了一个监督者。界面需要把问题变小，语言需要允许孩子承认“我卡住了”。

间接受益者：另一个家长、晚间辅导老师、周末复盘者。他们不需要复杂过程，只需要知道今天是否产生了一个真实的第一步。

非当前核心用户：学校管理者、老师运营团队、内容编辑团队、课程销售团队。这些角色可能出现在未来商业路径中，但不应进入当前 RC5 产品界面。

## 4. Parent perspective

中国家长，尤其是晚间高频陪伴作业的母亲，5 秒内能理解的价值必须是：今晚不用先讲大道理，也不用先找答案，先帮孩子迈出第一步。

产品解决的痛点：

- 孩子说“不会”，但家长不知道他到底卡在哪。
- 家长想帮，又怕变成直接讲答案。
- 晚间时间紧，作业堆叠，家庭情绪容易升级。
- 家长想知道今天有没有真实推进，而不是看一堆指标。

产品降低的焦虑：

- 降低“我是不是又要陪到很晚”的焦虑。
- 降低“孩子是不是完全没学会”的焦虑。
- 降低“AI 会不会直接替孩子写作业”的焦虑。
- 降低“我不懂这题就没法陪”的无力感。

会增加信任的设计信号：

- 明确说只看第一步，不生成完整答案。
- 每次只处理一个真实卡点。
- 让孩子自己说出第一步，而不是让系统替他说。
- 家长页只给一句可问的话，不制造复杂判断。
- 小黑板像提示板，不像解题器。

会让家长立刻关闭的信号：

- 暗示自动出答案、秒级完成、替孩子写。
- 首屏像测评、排名、成绩分析或商业课程入口。
- 大量内部术语、模块名、能力展示。
- 让家长感觉产品在替代教育责任，而不是降低今晚摩擦。
- 让孩子看起来被评价、被审讯、被贴标签。

危险的文案或 UI 感觉：

- 过强的效率承诺。
- 过强的数据仪表盘感。
- 过强的游戏刺激感。
- 过强的课程转化感。
- 过强的老师分工感。

## 5. Child perspective

孩子是否愿意使用，取决于它是不是像“帮我从卡住里出来”，而不是“又一个大人检查我”。

当前方向的优势：

- “先看哪里”比“你错在哪里”更低压力。
- “第一步怎么说”把输出降低到一句话，门槛足够小。
- 只修一个真实卡点，避免把孩子拖进长流程。
- 老师陪伴语气如果保持轻，会有陪伴感，而不是命令感。
- 小黑板只提示观察点，有助于避免直接答案依赖。

需要警惕的阻力：

- 如果首页像任务中心，孩子会觉得又多了一份作业。
- 如果 Review 像考后分析，孩子会回避。
- 如果 Tools 像玩法合集，孩子可能偏离真实卡点。
- 如果 Profile 被孩子看到时像家长报告，孩子会感到被监控。
- 如果系统频繁追问，孩子会觉得被审问。

儿童体验原则：

- 每次只要求一个小动作。
- 允许孩子用自己的话说。
- 不把“不会”写成失败。
- 不用刺激性成就体系替代真实进步。
- 把小黑板做成“我陪你看第一眼”，而不是“我来讲完整题”。

## 6. Market positioning

相对 AI 作业答案工具：原点私教应站在相反方向。答案工具满足“快拿结果”，原点满足“今晚开始学”。它的价值不在生成更完整答案，而在防止家庭把 AI 变成抄作业通道。

相对错题本：错题本偏长期归档和题目复习，原点偏晚间现场的即时收束。错题本回答“以后怎么复习”，原点回答“今晚先从哪里开始”。

相对辅导类 App：辅导 App 通常以课程、讲解、练习体系为中心，原点以家庭作业现场和亲子协作为中心。它不争夺“谁讲得更完整”，而争夺“谁能让孩子今晚先动起来”。

相对家长学习报告：报告产品给家长看结果，原点给家长看一句可行动的复盘。当前阶段不应把家长页做成复杂分析页。

相对游戏化学习产品：游戏化产品用外部刺激拉动使用，原点应依赖真实晚间任务拉动使用。它的复访理由是“昨天那个卡点今天轻轻看一眼”，不是追求刺激。

相对家庭教育陪伴产品：原点更具体、更场景化。它不泛谈亲子沟通，而是把沟通落到作业卡点、第一步表达和家长一句话。

需要另行市场研究的问题：

- 中国家庭愿意为“非答案型 AI 作业陪伴”支付多少。
- 家长对“不直接给答案”的真实接受度与转化阻力。
- 不同年级、城市、学科下的高频晚间卡点分布。
- 微信小程序内的自然留存与订阅转化表现。
- 学校、教培、社区渠道是否愿意为该产品背书或分发。

## 7. Commercialization potential

当前 RC5 不应在 UI 内加入商业化入口，但可以评估未来路径。

| 路径 | 与当前产品匹配度 | 主要风险 | 需要的证据 | 是否应出现在当前 UI |
| --- | --- | --- | --- | --- |
| 家长订阅 | 中高。高频晚间场景天然适合家庭持续使用。 | 家长可能认为这只是提示工具，不值得长期付费；也可能担心孩子依赖 AI。 | 7 日、30 日家庭留存；家长是否愿意为少吵、少卡、可回访付费；孩子是否自发打开。 | 否。RC5 先证明价值，不放商业入口。 |
| 学校试点 | 中。可作为家庭作业支持工具补充学校任务。 | 学校会担心答案合规、数据安全、老师负担和家校边界。 | 合规说明、学生不抄答案证据、家长满意度、老师负担不增加。 | 否。当前不做学校后台。 |
| 课后服务线索 | 中。卡点可反映真实学习需求。 | 容易让产品变成导流页，破坏信任。 | 家长明确表达进一步帮助意愿；卡点与服务匹配的转化数据。 | 否。不能干扰当前家庭路线。 |
| 高阶家庭学习计划 | 中高。积累卡点后可形成家庭级计划。 | 过早做会变重，回到报告和计划墙。 | 多周卡点记忆有效性；家长是否需要轻量计划；孩子是否不反感。 | 否。只保留轻复盘，不做计划销售。 |
| 线下教育服务转化 | 中。可承接高意向家庭。 | 线下转化会改变产品气质，家长可能感到被营销。 | 高意向用户画像、转化路径、服务质量与信任闭环。 | 否。RC5 不出现线下转化入口。 |
| B2B2C 家校渠道 | 中。适合规模分发。 | 决策链长，需求会拉向管理后台和数据报表。 | 试点学校反馈、家庭使用率、合规审查、渠道经济模型。 | 否。当前不能被渠道需求带偏。 |

商业化结论：有潜力，但现阶段最值钱的资产不是收费入口，而是证明“晚间第一步路线”能形成真实复用。

## 8. Investor view

潜在 wedge market：晚间作业陪伴中的“卡住第一步”场景。它足够高频、足够痛、足够家庭化，也足够区别于泛 AI 解题。

重复使用循环：

1. 今晚输入作业或卡点。
2. 系统生成一个可执行第一步。
3. 孩子说出第一步。
4. 形成明天轻回访。
5. 家长看到一句复盘。
6. 第二天回到真实作业场景。

留存逻辑：不是靠内容库或刺激机制，而是靠家庭每天都会遇到的作业现场，以及逐步积累的卡点记忆。

支付意愿假设：如果产品能稳定减少亲子冲突、缩短卡住时间、保护孩子不依赖答案，家长可能为“晚间稳定性”付费。但这需要真实用户验证，不能从产品结构直接推导。

可能商业化路径：家庭订阅、家校试点、课后服务合作、家庭学习计划、线下教育转化、渠道分发。以上都不应进入当前 RC5 UI。

为什么不只是 prompt wrapper：

- 它围绕晚间家庭流程组织，而不是围绕聊天框组织。
- 它限制 AI 不给完整答案，形成可信边界。
- 它沉淀 todayFocus、miniActionText、blackboardHint、reviewCard、growthMemory 等学习证据。
- 它把家长、孩子、回访放在同一条闭环里。
- 它的价值来自场景流程与数据记忆，而非单次回复。

投资人需要看到的证据：

- 孩子是否愿意主动完成“第一步怎么说”。
- 家长 5 秒是否能说清产品价值。
- 连续 7 天是否有家庭自然复用。
- 是否显著减少直接问答案、直接抄答案行为。
- 卡点记忆是否让后续回访更有效。
- 家长是否愿意为稳定晚间作业体验付费。
- 与答案型工具相比，是否有明确留存和信任优势。

## 9. Product moat and risks

可能壁垒：

- 家庭晚间工作流：如果流程足够顺，用户会把它当作晚间作业固定入口。
- 卡点记忆：长期记录孩子常见卡法，比单次问答更有价值。
- 亲子互动数据：孩子怎么表达第一步、家长怎么复盘，是通用解题器难以自然获得的数据。
- 中文教育语境：作业、家长陪伴、学校任务、晚间时间压力高度本土化。
- 反答案工具信任：如果边界稳定，家长会把它和直接答案工具区分开。
- 回访循环：明天轻轻看一眼，可以形成持续关系。

当前壁垒的不足：

- 真实使用证据不足，所有留存和付费判断仍是假设。
- AI 输出质量和边界稳定性尚未经过大量真实作业验证。
- 小黑板提示如果做重，容易被竞品复制成“分步提示”。
- 微信小程序入口轻，用户迁移成本不高。
- 若 UI 继续保留旧功能痕迹，定位会被稀释。
- 若未来商业化过早出现，会破坏“我不是来卖课或给答案”的信任。

P0/P1 产品风险：

- P0：被用户理解为直接答案工具。
- P0：孩子觉得被监督，拒绝使用。
- P1：家长页变成复杂报告，5 秒价值消失。
- P1：Tools 偏离轻回访，变成泛练习集合。
- P1：深层页面残留旧定位，影响审核与真机体验一致性。

## 10. UI redesign implications

Home 必须沟通：今晚先从哪一步开始。首屏要让家长和孩子马上知道下一步是“发作业或说卡点”，老师选择只能提供陪伴感，不能抢主 CTA。

Upload 必须避免：不能像拍照搜题入口，不能承诺自动识别或直接出答案。它应像“把今晚卡住的地方交给我看看”，并明确可以用文字说。

Diagnosis 必须感觉像：三问把混乱收成今晚第一步。不要做成测评、判分或能力分析；应让孩子愿意回答“我先看哪里”。

Review 必须帮助孩子说：我今天卡在哪、我先看哪里、我的第一步是。完成感来自孩子说出来，而不是系统讲完。

Tools 必须成为：明天轻轻回访。它不应是玩法集合，而应是对昨天真实卡点的轻触达。

Profile 必须展示：家长 5 秒复盘。最重要的信息是一句话、一个可问的问题、孩子今天是否说出了第一步。不要展示复杂分析墙。

Radar / Tutor / Arcade / Module 的视觉语言必须被收束：如果保留深层入口，也必须从“能力模块”转成“今晚路线的辅助页面”。不能让用户以为产品主线变成测评、游戏、报告或老师分工。

必须移除的视觉语言：

- 仪表盘式数据墙。
- 游戏化奖励与刺激性进度。
- 商业课程入口感。
- 直接答案工具感。
- 老师团队分工陈列感。
- 内部 key、枚举、阶段名、来源标识。

## 11. Variant design brief

产品定位：原点私教是一款微信小程序，服务中国家庭晚间作业场景。它不直接给答案，而是帮助孩子看清今晚先做什么、卡在哪、先看哪里，并说出自己的第一步；家长只需要 5 秒看懂今天有没有真实推进。

目标用户：小学高年级到初中孩子，以及晚间陪作业的家长，尤其是希望减少冲突、避免答案依赖、让孩子自己开口说出下一步的母亲。

必需屏幕：

- Home：今晚先从哪一步开始，包含作业/卡点输入入口、轻量老师陪伴选择、当前第一步状态。
- Upload：支持文字说明与手动上传入口，但不承诺自动识别，不做答案结果页。
- Diagnosis：用三问收束今晚第一步，语气轻，不像测评。
- Review：帮助孩子确认卡在哪、先看哪里、第一步怎么说，并在必要时出现小黑板提示。
- Tools：围绕明天轻轻回访，不做泛练习集合。
- Profile：家长 5 秒复盘，只看一句话和一个可问的问题。
- Deep pages：若出现 Radar / Tutor / Arcade / Module 等旧页面入口，必须弱化模块感，服从今晚路线。

情绪基调：温暖、克制、安静、可信、低压力。像一位懂晚间作业现场的陪伴者，不像考试系统、售课系统或娱乐平台。

视觉方向：

- 第一屏以“今晚先做什么”为中心。
- 使用路线、便签、小黑板、轻提示等具象隐喻。
- 保持信息密度低，每屏一个主动作。
- 老师形象有陪伴感，但不要变成功能分类入口。
- 家长信息使用短句，不使用复杂图表。
- 孩子操作区要大、清楚、少判断词。

必需文案主题：

- 今晚先做什么。
- 卡在哪。
- 先看哪里。
- 第一步怎么说。
- 明天轻轻回访。
- 家长 5 秒看懂。
- 不直接给答案，只陪你看清第一步。

禁止作为用户可见语言出现：

- 闯关。
- XP。
- 知识关卡。
- 报告墙。
- 快测。
- 雷达。
- 弱点。
- 带学面板。
- 付费。
- 服务方案。
- 秒解。
- 答案已生成。
- 拍照出答案。
- 老师分工式学科标签。

业务与市场约束：

- 当前 RC5 不出现商业化入口。
- 当前 RC5 不做学校后台。
- 当前 RC5 不承诺 OCR 或自动解题。
- 当前 RC5 不把产品做成泛聊天壳。
- 当前 UI 重建只服务真实设备 smoke test 和核心路线表达。

亲子信任约束：

- 对家长：明确边界，不替孩子写，不制造复杂焦虑。
- 对孩子：不羞辱、不贴标签、不审问。
- 对家庭：每次只推进一个小动作。
- 对 AI：只提示第一步该看哪里，不讲完整题。

## 12. Clear final judgment

PRODUCT_STRATEGY_READY_FOR_UI_REBUILD = YES

判断说明：当前产品战略已经足够清晰，可以进入 Variant UI 重建。UI 重建的目标不是扩展能力，而是把“今晚先迈出第一步”变成 5 秒可感知的家庭体验。

但该 YES 只适用于 UI 重建，不适用于商业化上线、功能扩张或渠道试点。下一阶段必须继续冻结产品边界：不加新功能、不加商业入口、不做答案承诺、不做管理后台。先用真机 smoke test 验证家庭路线是否被看懂，再决定是否进入真实家庭小范围试用。
