# 原点智学小程序上架与商业化计划

## 当前判断

首版目标不是做全学科 AI 私教，而是验证家庭学习决策闭环：

```text
录入作业/错题 -> 雷达弱点 -> 作业三分类 -> 原小点只带必须做和关键错因 -> 家长反馈校准
```

上架前不再增加 OCR、支付、课程售卖或全学科策略库。所有新增能力必须服务于审核通过、30 秒跑通体验和 20 个家庭内测。

## 上架前必须完成

1. 获取真实小程序 AppID，并执行：

```bash
npm.cmd run miniapp:appid -- wx你的AppID
```

2. 微信后台配置 request 合法域名：

```text
https://yuandianzhixue.com
```

3. 运行完整检查：

```bash
npm.cmd run miniapp:fullcheck
npm.cmd run miniapp:review
```

4. 微信开发者工具导入 `miniprogram/`，真机验证路径：

```text
今日 -> 30 秒体验样例 -> 生成雷达 -> 点击必须做 -> 原小点执行 -> 标记准/不准
```

## 审核定位

对外定位：家庭学习效率工具。

禁止口径：

- 不说 AI 私教
- 不说保证提分
- 不说自动识别试卷
- 不说课程售卖
- 不说替写作业

审核说明重点：

- 用户手动录入学习任务
- AI 只生成学习建议和思路引导
- 照片仅本地留档
- 未成年人需监护人同意

## 首批内测目标

招募 20 个家庭，连续使用 7-14 天。

核心观察指标：

- 家长是否愿意每天录入作业
- 三分类是否被标记为“准”
- 孩子是否愿意进入原小点完成一项必须做
- 家长是否愿意每周看复盘
- 是否出现明确付费意愿

## 商业化形态

首版不急于在小程序内开支付。先用内测服务验证付费。

免费体验：

- 每日一次作业三分类
- 基础弱点雷达
- 原小点引导第一项必须做

家庭版候选：

- 29-49 元/月
- 每日多次作业取舍
- 每周家长复盘
- 错因趋势和家庭校准记录
- 数学/英语高频题型策略

深度陪跑候选：

- 199-399 元/月
- 每周人工或半人工复盘
- 个性化学习任务策略
- 家长群答疑和内测反馈通道

## 题型策略库时机

现在只保留最小 6 类：

- 数学计算题
- 数学应用题
- 数学错题复盘
- 英语单词记忆
- 英语日常对话
- 英语简单写作

等 20 个家庭产生真实输入后，再按高频作业类型扩展。

策略库结构：

```text
年级 -> 学科 -> 题型 -> 常见错因 -> AI 引导方法 -> 掌握证据 -> 家长复盘话术
```

这才是长期壁垒，不是散乱提示词集合。
