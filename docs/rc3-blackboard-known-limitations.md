# RC3.1 Blackboard Known Limitations

## 1. 本地证据字段

`blackboardHint` / `blackboardUsedAt` 当前只是本地学习证据，用来说明这次卡点修复是否看过小黑板提示结构。

它们目前不改变后端 API，不改变同步协议，也不作为跨设备学习档案的可靠来源。

## 2. 模板型提示

当前原点小黑板是模板型提示，不是真正的学科理解。

它根据 `issueType` 输出四类固定结构：
- 列式关系；
- 读题审题；
- 步骤断点；
- 概念公式。

它不读取完整题目语义，不生成完整解法，不判断最终结果。

## 3. miniActionText 不做学科正确性判断

当前仍只验证 `miniActionText` 是孩子说出的有效第一步证据。

系统不判断这句话在数学、语文、英语或其他学科上是否正确。本轮目标是保证孩子没有跳过“先说第一步”。

## 4. 当前不接 Qwen API

RC3.1 不接 Qwen API，不接 Qwen-VL，不做图片识别，不做拍题搜题，不做完整题目讲解。

小黑板只作为本地提示层，帮助孩子先看第一步。

## 5. 未来接 Qwen 的产品边界

如果后续接 Qwen，应作为“原点小黑板能力层”，不是千问套壳。

必须遵守：
- 只生成第一步提示；
- 不生成完整答案；
- 不代写完整过程；
- 不绕过 miniActionText；
- 不绕过 reviewCard；
- 不改变今晚路线主线；
- 不改变 companionPreference；
- 不把老师团做成功能分工或学科分工。
