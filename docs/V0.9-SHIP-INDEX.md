# 原点智学 v0.9 收尾入口

当前阶段从“继续堆功能”切换为“上架准备 + 真实内测取证”。本文件是唯一推荐入口，旧文档可作历史参考，但不要直接拿旧文案提交审核或对外融资。

## 当前产品冻结口径

原点智学 v0.9 是面向中国家庭晚间学习场景的学习效率与决策工具：

```text
测评/作业录入 -> 雷达弱点 -> 作业三分类 -> 原小点只辅导必须做和关键错因 -> 复习卡/测验/修复 -> 家长周报 -> 内测证据
```

对外不要说：

- 不说保证提分。
- 不说替代老师。
- 不说作业代写。
- 不把首版包装成课程售卖。
- 不把 OCR、支付、真实好友社区当作首版卖点。

可以说：

- 帮家长判断今晚哪些任务最值得做。
- 帮孩子把关键错因沉淀成复习卡和复盘证据。
- 帮家庭减少盲目刷题、平均用力和低价值作业消耗。
- AI 只做学习建议、思路引导和复习组织，最终判断由家长/学生/老师确认。

## 上架前 Go / No-Go

Go 条件：

- `scripts/verify.ps1` 通过。
- 微信开发者工具可导入 `miniprogram/`。
- 真机能完成：首页 -> 作业录入 -> 雷达 -> 必须做 -> tutor -> review -> profile 周报。
- 审核文案不包含保证提分、代写、课程售卖、自动 OCR 主张。
- AppID 已替换，不再是 `touristappid`。
- 微信后台 request 合法域名已配置。

No-Go 条件：

- 没有真实 AppID，却准备上传。
- 使用未审核的高风险承诺文案。
- 试图在首版加入支付、课程交易、自动识别图片或复杂社交。
- 没有隐私/未成年人保护说明。

## 内测前 Go / No-Go

Go 条件：

- 至少 10 个家庭入组，每个家庭有一个明确弱学科或高焦虑作业场景。
- 每晚只测一个主链路，不要求用户探索全部功能。
- 已准备反馈记录：节省时间、家长信心、必须做完成、复习回访、孩子是否抄答案。
- 已说明产品是学习效率工具，不承诺固定分数结果。

No-Go 条件：

- 让家庭把产品当全能 AI 私教。
- 不记录失败样本。
- 只收集好评，不收集“哪里不准、哪里烦、哪里不想回来”。

## 当前真实阻塞

- 小程序正式上传：需要真实微信 AppID。
- 生产云同步：需要后台域名、服务端环境变量、数据库生产配置。
- 真实 AI 内容引擎：需要模型 API key。
- 真实提分证据：需要 7-14 天以上家庭内测数据。

除上述阻塞外，当前代码和材料已经进入 v0.9 收尾状态。
