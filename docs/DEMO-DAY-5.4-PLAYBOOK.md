## 2. 现场 5 分钟演示（3 个动作）

### 动作 A · 让现场孩子打开 mastery-loop（90 秒）
- 你拿手机扫码 → 短链 `/start` 带 `?student_id=00…001`
- 让孩子答一道 `x + 5 = 12`（≈10 秒）
- 系统判对 → 难度上调 → 孩子答 `5x - 8 = 2x + 7`
- 出师瞬间「炫耀给爸妈看」金句弹出

**台词**：「这 25 分钟系统会自动调难度。每答一题它都在更新对孩子掌握度的认知。」

### 动作 B · 切到 tutor 演示「记得我」（90 秒）
- 同一手机切 `/tutor`
- 让孩子打：「你还记得我之前哪里卡过吗」
- 老师第一句应当含：「上次咱们在『一元一次方程移项忘记变号』那卡过」（来自 seed + embedding）

**台词**：「ChatGPT 每个新对话都是白纸。我们存了这孩子过去 30 天的卡点指纹。」

### 动作 C · 切到 parent-radar 给家长看（90 秒）
- 切 `/radar`
- 顶部绿色面板「孩子刚出师 2 分钟前」自动跳出（动作 A 写进 localStorage 的金句）
- 雷达图 + 学习指纹面板：「视觉型 / 焦虑 / 类比奏效率 67%」

**台词**：「妈妈打开看到的不是 PDF 报告，是 AI 已经识别出她孩子是视觉型，老师下次自动多画图。」

## 3. 不要演示的 3 件（翻车红线）

| 别做 | 因为 |
|---|---|
| 现场观众随手出题考算术 | DeepSeek 算术 corner case 会出错，prompt 防御压不住所有长尾 |
| 「雷达图实时刷新」（mastery-loop 答完跳雷达看变化）| V1 雷达图走 NCDM mock 数据，不读 student_states 实时值 |
| 「让两个家长用同一手机同时操作」 | 同 IP 速率限制 30/分钟会触发 429，孩子看到错误码 |

## 4. 高频问题 + 提前备好的答案

### Q1: 「跟 ChatGPT 区别在哪？」
- 中国课标对齐：人教版 / 北师大版 / 苏科版
- 跨会话隐性信号 6 字段（卡点 / 误区 / 类比奏效 / 情绪 / 认知风格 / 兴趣）
- 64 类中国教师视角的错题归因（不是 美式 calculation error）
- 中国 K12 师生对话语料壁垒（一年累积成稀缺数据）

### Q2: 「数据从哪来？」
诚实答：「PoC 期开始累积。我们今天 30 学员就是第一波。」不要说「已经有大量数据」。

### Q3: 「凭什么提分 0.5 SD？」
诚实答：「目标 0.4-0.5 SD，Khanmigo 公开 0.23 SD 是基线，我们要争取做到一倍。这 4 周 PoC 拿数据，5.31 看真实成绩。如果做不到，我们公开承认。」

### Q4: 「孩子作弊怎么办？粘贴答案直接提问」
现场可以演示：让孩子复制一道题进 tutor，按发送，前端立刻红边框 + ⚠️。tutor 第一句不会讲题，只反问：「这题看起来是直接复制的——你看到第一反应是什么？」

### Q5: 「便宜吗？」
- 当前成本：DeepSeek + Qwen 合 ¥3.5/学员/月
- Khanmigo $4/月 ≈ ¥28
- ChatGPT Plus ¥150+/月
- 三四线城市 ¥99/月卖也有 25 倍差价空间

### Q6: 「跑了多久？」
诚实答：「主体工程 1 个月。今天是首批真用户进场。」不要伪造历史。

### Q7: 「你们多少人？」
诚实答：「核心 3 人。我 + 乙方 + 丙方。」不要膨胀团队。
